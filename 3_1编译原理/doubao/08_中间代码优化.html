中间代码优化

优化是在保证语义正确的前提下，让程序运行更快、占空间更少。这一章以基本块为最小单位，讲清三种核心技术：常表达式节省（编译期算好）、公共子表达式节省（相同结果只算一次）、循环不变式外提（循环外算一次），并介绍值编码、循环定值表等支撑方法。

01

代码优化概述

OVERVIEW

提高源程序运行速度要经过几个阶段的优化：用户对源程序做算法层优化（数据结构、算法选择），编译器前端对中间代码优化，后端对目标代码优化（寄存器、目标指令）。本课程关注中间代码优化。

  • 优化角度：执行效率（时间）、存储（空间）；
  • 意义：程序一次编译、多次执行，优化有性价比；实时控制、导航等领域对效率要求高。
第一原则
优化最重要的原则是一定不能出错，可能出错就不优化。保证正确的前提下，再在一定程度上提高效率，而非追求“最优”。
02

中间代码优化的分类

CATEGORY
范围内容特点
局部优化基本块上的优化：常表达式节省、公共子表达式节省最小单位，成本低，常用
循环优化循环不变式外提（重点）、削减运算强度循环操作随层数倍增，是重点
全局优化全局数据流分析代价高、效果不明显，特殊系统才用
03

常见的编译优化种类

TECHNIQUES

数学优化：可不计算的直接删去四元式，高强度运算转低强度。如 a−0=a、a*1=a 直接删；2*a 转 a+a（机器用加法模拟乘法，更快）；a² 转 a*a。

表达式短路：or 运算前项已知 true，结果必为 true，后项略过；and 运算前项已知 false，结果必为 false，后项略过。

消除无用语句：if 条件恒 true，则 else 分支不可能执行，可删。

寄存器优化：目标机寄存器的分配与剥夺策略，与目标机相关。

中间变量优化（空间）：两个临时变量的活动区不相交，可共用同一存储单元，本质是存储空间优化。

目标代码优化：减少指令个数，如两分量都在寄存器中可直接计算，不必存内存。

04

基本块的定义与特点

BASIC BLOCK

基本块是程序中一组顺序执行的语句序列，只有一个出口和一个入口：入口是第一条语句，出口是最后一条语句。

  • 执行时只能从入口进入、出口退出；内部语句要么全执行，要么全不执行，不能中间转出或转入；
  • 可基于源代码、中间代码、目标代码划分。
为什么在基本块上优化
基本块内顺序执行，变量的值怎么获得、怎么传播都能判定。若有额外入口（goto 跳入），变量值就无法确定；基本块封闭后性质可判定，优化才安全。
05

基本块的划分原则

PARTITION
  1. 整个四元式序列的第一个四元式为入口；
  2. 遇转移性四元式，结束当前块，该四元式作为出口，下一条作为新块入口；
  3. 遇标号性四元式，结束当前块，该四元式作为新块入口；
  4. 遇对地址引用型变量赋值的四元式，结束当前块并作为出口。

转移性（生成目标代码时必产生跳转）：JMP、CALL、RETURN、ENDPROC、ENDFUNC、THEN、ELSE、DO、ENDWHILE。

标号性（定位，不产生跳转）：LABEL、ENTRY、WHILE、ENDIF，标记循环或条件语句位置。

地址引用型变量能改变原变量的值（如 *y=10），为保证性质可判定需在此断块。

06

基本块划分实例与程序流图

EXAMPLE

源程序含赋值、if 条件、while 循环，转成四元式后按标号和转移断块：

B1：(ASSIGN,1,_,y) B2：(LABEL,...,L) (AND,A,B,t0) (THEN,t0,...) B3：(ASSIGN,0,_,x) B4：(ELSE,...) (ASSIGN,0,_,y) B5：(ENDIF,...) (+,x,1,t1) ... (-,y,1,t2) B6：(WHILE,...) (ADDI,x,y,t3) (GT,t3,0,t4) (DO,t4,...) B7：(-,x,1,t5) (ASSIGN,t5,_,x) B8：(ENDWHILE,...) (ASSIGN,0,_,z)

程序流图是以基本块为节点的有向图，节点间有向边代表控制流，了解即可。

07

常表达式节省

CONSTANT FOLDING

常表达式是编译过程中能算出常量值的表达式。处理思想：若运算型四元式 (w,A,B,T) 两分量都取常数，计算 A w B 并用值代替，删掉原四元式。

例：m 总取常数 10，a=m+10、b=a+m、c=a+b−d 优化为 a=20、b=30、c=50−d。

7.1 常量定值表 ConstDef

表元素 (Var,Val)：若有 (V,c)，表示变量此时一定取常数 c，V 被更改前出现的 V 都可替换为 c。

  1. 块入口置 ConstDef 为空；读当前四元式，用 ConstDef 代换分量得新四元式；
  2. 运算型 (w,A,B,t)：A、B 都是常数则算值 v，填 (t,v)，删除当前四元式；
  3. 赋值型 (ASSIGN,A,_,B)：A 是常数则填 (B,A)（已有则改值）；A 非常数则删除 B 的登记。
08

公共子表达式节省

COMMON SUBEXPR

两个四元式 (w1,a,b,t1)、(w2,c,d,t2)，若 w1=w2 且 V(a)=V(c)、V(b)=V(d)，则等价。基本块中多个等价四元式，除第一个外其余是可节省的公共代码 ECC。

抛开表面看本质
形式相同未必等价（中间变量被重新赋值），形式不同未必不等价（赋值后两变量同值）。所以用值编码标识“值”而非名字。

8.1 基于值编码的方法

对每个值确定一个编码，使具有相同值的运算分量编码相同。

  • 值编码表：分量已有编码直接用，没有则新建；
  • 性质：相同常量编码相同、不同常量编码不同；变量被赋值就得到新编码，直到再被赋值；
  • 映象码：四元式各部分用值编码表示，映象码相同即公共表达式；
  • PAIR 表：(ti,tj) 表示 tj=ti，节省时用 ti 替换 tj。
  1. 块入口置 ValueNum、UsableExpr、PAIR 为空；
  2. 运算型：先做 PAIR 替换，若 UsableExpr 有相似代码则删除并填 (ti,tj)，否则给结果新编码并加入；
  3. 赋值型：令结果编码等于右部编码。

例 a=b*c+b*c：第二个 b*c 映象码与第一个相同，节省；下标地址计算中此类重用最常见。

09

循环不变式外提

LOOP HOISTING

变量 x 的值在循环中不改变即循环不变量；表达式 (w,a,b,t) 两分量都是循环不变量，即循环不变式。外提就是把它提到本层循环入口处，循环里只引用结果。

循环识别：基于文本（扫描 WHILE/DO/ENDWHILE，成本低）或基于程序流图（开销大）。

9.1 两遍扫描

  • 第一遍建定值表 LoopDef：运算型把结果 t 记入，赋值型把左部 b 记入；
  • 第二遍外提：运算型若 A、B 都不在 LoopDef 中，即不变式，提到循环入口，并把 t 从 LoopDef 删去。
i:=1; while i<=100 do z:=i*k*5; a:=2*k+2*k*2; i:=i+1; // 2*k、(2*k)*2 等与 i 无关，外提到循环入口

9.2 外提安全性

  • 除法不外提：可能除零，如 if(y≠0) 内 1/y，外提脱离保护；
  • 赋值不外提：循环可能 0 次，外提至少执行 1 次，改变结果；
  • 非良性循环不外提：含过函调用或间接变量赋值，副作用无法构造准确定值表，整个循环都不外提；
  • 分量是间接变量的运算不外提：指针本身不变，但指向地址里的值在变；若只取指针本身做地址加则可外提。

9.3 外提策略与多层循环

外提必经代码没问题；非必经代码若循环一次不执行，外提反成多余计算。多层循环从最内层开始、逐层向外提，LoopDef 也嵌套，用栈记住每层开始。矩阵乘法中下标变量地址外提收益巨大，是主要外提对象。

三种技术的综合应用

INTEGRATION
a:=0; j:=(a+1)*5; while j<100 do a:=a+A[3]; if a<10 then k:=0 else k:=x*y+x*y/5; j:=j+1;

先划分基本块，再依次应用：①常表达式节省，(a+1)*5 直接得 j=5；②公共子表达式节省，两个 x*y 合并；③循环不变式外提，A[3] 地址、x*y 提到循环外。

(:=,0,_,a) (:=,5,_,j) (AADD,A,2,t6) (*,x,y,t9) (WHILE,...) ... (+,a,t6,t7) ... (/,t9,5,t11) (+,t9,t11,t12) ...

章末速查

SUMMARY
优化分类：局部（基本块）、循环（重点）、全局。
基本块：单入口单出口，内部全执行或全不执行。
划分四原则：首条入口、转移断块、标号断块、间接赋值断块。
常表达式：两分量都是常数，编译期算值，靠 ConstDef。
公共子表达式：映象码相同即等价，靠值编码与 PAIR。
循环外提：两遍扫描建 LoopDef，除法/赋值/非良性/间接分量不外提。
