## 1. 为什么生成中间代码


### 1.1 便于分析与优化

语法和类型确认之后，还要把程序交给优化与目标代码生成。直接操作复杂源码不便跟踪每一步计算，而直接生成机器指令又会过早绑定机器细节，因此先使用适合分析的内部表示。

**中间表示 IR**是源程序与最终指令之间的内部表示。源程序含嵌套语法和名字规则，目标指令又含机器细节；把计算拆成简单操作后，容易找重复表达式、传播常量、计算地址依赖和移动安全操作。

课件 `r=5;c=2*3.14*r` 中，已知 r 未被改变时可把后面结果折叠为 31.4。数组循环中，行首地址计算可能重复；IR 让这些操作显式出现。优化目标是改善代价并保持行为，不等于只减少源代码行数。

### 1.2 便于前后端复用

前端把语言规则转换到共同 IR，多个后端再实现到不同指令系统，能复用大量工作。课件用机器型号说明移植，但是否属于不同指令系统应看具体架构；不能仅因商品型号不同就断言指令集完全不同。

IR 可尽量减少机器细节，也可能保留类型大小、异常等目标相关信息。因此“中间代码完全与任何机器无关”不是所有实现的要求。编译器也可不单独保存 IR 而直接生成目标代码，本课程为清楚讲优化与代码生成采用四元式。

## 2. 记号与常见表示

同一个表达式可以保存成运算顺序、树结构或简单指令序列。下面固定例子比较这些表示，先认清结构如何保留，再进入本章重点的四元式。

### 2.1 本章记号

| 记号 | 含义 |
| --- | --- |
| `(op,a,b,r)` | 操作码、第一输入、第二输入、结果字段 |
| `-` | 空字段，不是减法操作 |
| t1、t2 | 编译器生成的临时结果 |
| C、id | 常量 Token、标识符 Token |
| E、T、P | 表达式、项、基本成分 |
| Es、Ts | 表达式/项的后续部分 |
| Sem | 语义属性栈，区别于语法分析栈 |
| `#动作#` | 动作标记，非输入 Token；边界 # 另指结束 |
| ARG | 四元式参数结构，可为常数、标号、地址 |
| Low/Up、Di、Si、α | 下界/上界、第 i 维长度、步长、基本元素大小 |

### 2.2 逆波兰式与栈求值

中缀写法要靠括号和优先级确定顺序。把操作符放到其操作数之后，就能用从左到右的栈处理直接恢复计算次序，这就是后缀表示的用途。

**逆波兰式/后缀式**把操作数放前、操作符放后。a+b\*c 为 `a b c * +`，(a+b)\*c 为 `a b + c *`；无须括号，结构由操作符出现顺序和目数决定。

从左到右，操作数压栈，二元操作先弹右操作数，再弹左操作数，运算结果压回。课件 `b c d * +`：

| 读入 | 栈（左底右顶） |
| --- | --- |
| b | b |
| c | b,c |
| d | b,c,d |
| \* | b,t1=c\*d |
| + | t2=b+t1 |

顺序在减除中尤其重要：`a b -` 是 a-b。完整表达式最终应只剩一个值，途中缺操作数或最后多值说明后缀式不合法。

### 2.3 AST 与 DAG

后缀式突出执行次序，树则更直观地展示谁由谁组成。如果还要表示两处使用共享同一个计算结果，就需要允许多个引用指向同一结点。

**抽象语法树 AST**保留有意义的操作与结构，省去不影响含义的文法辅助层；不要求每个结点和孩子都机械对应一条原产生式，后者更接近完整分析树。

**有向无环图 DAG**允许多处引用同一个计算结点。`c:=a*b+a*b` 的 AST 有两个乘法子树，DAG 可共享一个 a\*b 结点，再让加法两输入指向它。

共享的前提是两次计算输入值一致且操作没有需要重复执行的副作用。`f()+f()` 若 f 改变状态，不能仅因文本相同就共享。课件 DAG 用来说明表达式共享，详细安全判断在优化章展开。

### 2.4 三元式与四元式

为了逐条分析和移动计算，可以把表达式拆成小操作。每步的结果还要供后续引用；三元式用位置编号引用，四元式给结果单独命名。

**三地址代码**把一条复杂表达式拆成简单操作，通常最多有两个输入和一个结果；“地址”是广义参数，并非每个字段必为物理内存地址。常数、标号、空项也可出现。

课件 `a:=b*c+b/d`：

| 三元式编号与内容 | 四元式 |
| --- | --- |
| 1 `(*,b,c)` | `(*,b,c,t1)` |
| 2 `(/,b,d)` | `(/,b,d,t2)` |
| 3 `(+,(1),(2))` | `(+,t1,t2,t3)` |
| 4 `(:=,(3),a)` | `(ASSIG,t3,-,a)` |

三元式用位置编号引用结果，插入/移动后需维护引用；四元式显式临时名不依赖位置，便于移动。

## 3. 四元式字段与操作码

选用四元式后，必须先规定每种操作怎样解释四个字段。否则同样把一个名字写在 RESULT，可能被误读成结果值、赋值目标或跳转目的地。

### 3.1 不是每条都按两个值输入一个值输出

一般运算 `(ADDI,x,y,t)` 表示 t=x+y。ASSIG 的第一项是源、RESULT 是目标；JMP 的 RESULT 是标号；ENTRY 的字段存入口、大小和层数。每种 op 都须明确协议。

| 操作族 | 课件操作码 | 含义 |
| --- | --- | --- |
| 算术 | ADDI/F、SUBI/F、MULTI/F、DIVI/F、MOD | I 整数，F 实数；MOD 取余 |
| 逻辑 | AND、OR | 对布尔值组合 |
| 比较 | EQ、NE、GT、GE、LT、LE | 等、不等、大、大等、小、小等 |
| 输入 | `(READI/F,-,-,x)` | 读值到对象 x |
| 输出 | WRITE | 输出指定对象值 |
| 转换 | `(FLOAT,x,-,t)` | 整数 x 转 real 到 t |
| 赋值 | `(ASSIG,x,-,y)` | y:=x |
| 地址加 | `(AADD,base,offset,t)` | 把位移加到对象/中间地址，t 保存地址 |
| 标号 | `(LABEL,-,-,L)` | 定义代码位置 L |
| 跳转 | `(JMP,-,-,L)` | 无条件转 L |
| 入口 | `(ENTRY,L,Size,Level)` | 子程序元信息与入口位置 |
| 调用 | `(CALL,f,flag,result)` | 调用，可能有结果 |
| 返回/出口 | RETURN、ENDFUNC、ENDPROC | 交付结果与结束控制 |
| 参数 | VALACT、VARACT、ActualFuncACT、FormalFuncACT | 传值、对象地址、实在/形式过函信息 |
| 条件 | THEN、ELSE、ENDIF | 记录条件分支结构 |
| 循环 | WHILE、DO、ENDWHILE | 记录测试开始、退出条件和回边 |

源课件 15 把 WRITE 对象放 RESULT，22 放 ARG1。正文统一为 `(WRITE,x,-,-)`；后端必须按同一协议取字段。CALL 的 true/false 在课件用于类别区分，但未完整规定布尔编码含义，例子保留 true，不凭空断言 true 就表示“有返回值”。

### 3.2 ARG 的三类内容

**数值类**直接保存常量；**标号类**引用普通标号或子程序入口；**地址类**引用变量/临时结果的访问属性。地址类可引用持久符号项，也可复制 `(Level,Off,Access)`。

课件临时量用 `(-1,编号,Access)`，-1 是“后续要给临时量分配位置”的类别约定，不是某个真实过程层。输出后端前须把临时编号映射到寄存器或存储位置。

## 4. 语法制导与统计 b 的完整例子

已经知道代码要表示什么，还需决定在分析的哪个位置生成它。语法制导把处理动作放到相应结构中；先用课件的计数任务观察动作怎样随匹配顺序执行。

### 4.1 动作嵌入结构

**语法制导翻译**在分析识别到某结构时执行相关语义子程序。动作可以统计、检查类型、构树或生成代码；不是只限编译器。

LL(1) 中动作可写在右部适当位置，遇动作执行、不读输入。课件 LR 方案在归约时执行右部末尾动作；这是其简化约定，通用 LR 工具也可通过改写等支持中间动作，不能称 LR 理论上绝不允许。

### 4.2 文法、表与动作

课件 `S→AB、A→aA|b、B→bB|c` 生成 `a*b+c`。要数句子里 b 的个数：

```text
S→#Init# A B
A→aA | b #Add#
B→b #Add# B | c #Out_Val#
```

| 非终结符 | a | b | c | # |
| --- | --- | --- | --- | --- |
| S | Init A B | Init A B | Error | Error |
| A | a A | b Add | Error | Error |
| B | Error | b Add B | c Out_Val | Error |

动作两侧的 # 用于区分语义符号，与输入结尾的 # 按位置区别。课件 15 第 21 页的动作程序如下：

```text
Init() { m = 0; }
Out_Val() { printf("%d", m); }
Add() { m++; }
```

Init 清零，Add 每执行一次加一，Out_Val 输出结果。动作不参与 FIRST/PREDICT 的输入类别，原文法选择保持。Add 放在匹配 b 后面，避免未真正读到 b 就计数。

### 4.3 abbbc 的全过程

下表栈顶在左，与本章后面的 Sem 左底右顶记法分开注明：

| 待处理栈 | 剩余输入 | 动作与 m |
| --- | --- | --- |
| S # | abbbc# | 展开 Init A B |
| Init A B # | abbbc# | Init，m=0 |
| A B # | abbbc# | A→aA |
| a A B # | abbbc# | 匹配 a |
| A B # | bbbc# | A→b Add |
| b Add B # | bbbc# | 匹配 b |
| Add B # | bbc# | m=1 |
| B # | bbc# | B→b Add B |
| b Add B # | bbc# | 匹配 b |
| Add B # | bc# | m=2 |
| B # | bc# | B→b Add B |
| b Add B # | bc# | 匹配 b |
| Add B # | c# | m=3 |
| B # | c# | B→c Out_Val |
| c Out_Val # | c# | 匹配 c |
| Out_Val # | # | 输出 3 |
| # | # | 接受 |

统计任务只须一个 m；表达式生成则要保存多个中间属性，于是需要语义栈。

## 5. 语义栈、类型检查与属性保存

计数例只需保存一个 m，表达式却要暂存多个操作数的类型和值或位置，直到运算结构完整。语义栈保存这些已处理成分的属性，供动作取用。

### 5.1 Sem 的元素

**语义栈 Sem**每项保存 `(Type,ARG)`，必要时再含可写性等属性。它记录已处理成分对应的值或位置；语法栈记录接下来还要分析哪些文法符号，职责不同。

Push(id/C) 查符号或常量描述后压属性；GenCode(ω) 取右、左两项，检查操作、转换必要输入、生成临时 t，弹两项再压结果。ASSIG 则取左位置和右值，生成存储后弹掉语句所占项。

### 5.2 类型转换要有规则

对 int+real，若语言允许整数提升，先 FLOAT 整数再 ADDF。两个 int 用 ADDI，两个 real 用 ADDF。不相容结构要报错，不能“类型不同就 FLOAT”。real→int 若允许还需另一个规定的转换，FLOAT 并不能完成它。

课件 15 的 3.5+i 若 i:int，完整代码应是 `(FLOAT,i,-,t1)`、`(ADDF,3.5,t1,t2)`；原单条 ADDF 未显式表达转换。赋值、下标、条件、实参、返回值都要各按规则检查。

### 5.3 属性必须活到使用结束

IR 引用的类型、地址等属性必须保存到后续使用完成；不能引用已经被覆盖的局部表项。I/F 后缀虽记录了运算类型，数组尺寸和参数属性仍须保留。

地址临时量的槽里保存地址值；普通加法通过它读元素，AADD 使用地址值继续累加，ASSIG 左部通过地址写对象。先弄清操作上下文，才不会把地址数值和对象值混用。

## 6. 表达式翻译

现在用语义栈处理完整表达式。生成顺序必须同时遵守乘除优先、括号和结合性，因此不能只照单词出现顺序遇到操作符就立即生成运算。

### 6.1 完整动作文法

消除左递归后，课件编号为：

```text
(1) E→T Es
(2) Es→ε
(3) Es→+ T GenCode(+) Es
(4) Es→- T GenCode(-) Es
(5) T→P Ts
(6) Ts→ε
(7) Ts→* P GenCode(*) Ts
(8) Ts→/ P GenCode(/) Ts
(9) P→C Push(C)
(10) P→id Push(id)
(11) P→(E)
```

E 管加减，T 管乘除，P 管基本项，使乘除先完成。虽然 Es/Ts 递归向右，动作在下一次递归前生成，因此 `x-y-z` 实现 `(x-y)-z` 的左结合。改动作位置到递归后会改变语义顺序。

### 6.2 集合与预测表

令 F={C,id,(}，Q={),#}：

| 非终结符 | FIRST | FOLLOW |
| --- | --- | --- |
| E | F | Q |
| Es | {+,-,ε} | Q |
| T | F | {+,-}∪Q |
| Ts | {\*,/,ε} | {+,-}∪Q |
| P | F | {\*,/,+,-}∪Q |

| 行 | C | id | ( | ) | + | - | \* | / | # |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E | 1 | 1 | 1 | — | — | — | — | — | — |
| Es | — | — | — | 2 | 3 | 4 | — | — | 2 |
| T | 5 | 5 | 5 | — | — | — | — | — | — |
| Ts | — | — | — | 6 | 6 | 6 | 7 | 8 | 6 |
| P | 9 | 10 | 11 | — | — | — | — | — | — |

P 的三条 PREDICT 分别 C/id/(；Es 空规则只在 Q；Ts 空规则在 +、-、Q，其余单运算符分支各选自己的符号。— 报错，不是任意空分支。

### 6.3 x+y\*z 的动作次序

假设全为 int：Push x；看到 + 前 Ts 取空，Es 展开 +T；Push y；T 内看到 \* 展开 \*P；Push z；GenCode(\*)；Ts 取空；GenCode(+)；Es 取空；输入结束。

| 关键动作 | Sem（左底右顶） | 新代码 |
| --- | --- | --- |
| Push x | x:int | 无 |
| Push y | x:int,y:int | 无 |
| Push z | x:int,y:int,z:int | 无 |
| GenCode(\*) | x:int,t1:int | `(MULTI,y,z,t1)` |
| GenCode(+) | t2:int | `(ADDI,x,t1,t2)` |

运算动作先弹右 z，再弹左 y，二者顺序用于 SUB/DIV 更须保持。加法右边 T 没完成时不能抢先算 x+y。

### 6.4 混合类型的课件例

`X*2+A*(i+1)/(j+1)`，X/A:real，i/j:int：

```text
1 (FLOAT,2,-,t1)
2 (MULTF,X,t1,t2)
3 (ADDI,i,1,t3)
4 (FLOAT,t3,-,t4)
5 (MULTF,A,t4,t5)
6 (ADDI,j,1,t6)
7 (FLOAT,t6,-,t7)
8 (DIVF,t5,t7,t8)
9 (ADDF,t2,t8,t9)
```

括号内部先做整数运算，到了与实数参与的乘/除才提升。按左结合先算 A\*(i+1) 再除，不能改为 A\*((i+1)/(j+1)) 的整数除法。j+1 若运行时为零涉及动态检查，类型正确不保证除法总有合法结果。

## 7. 数组地址计算

普通变量已有一个位置，多维数组元素的位置还随下标变化。要先把每维下标换成相对位移，再按该维步长累加，才能知道应读写哪个元素。

### 7.1 行优先与步长

**行优先**让最后一维变化最快，相邻最后维元素连续存储。声明 `A:[L1..U1]…[Ln..Un] of T`，令 `Di=Ui-Li+1`、α=Size(T)，第 i 维前进一格跳过的存储量叫**步长 Si**：

```text
Sn=α
S_i=D_(i+1)×S_(i+1)         i 从 n-1 到 1
Size(A)=D1×S1=α×D1×…×Dn
addr(A[i1]…[in])=base(A)+Σk=1..n (ik-Lk)Sk
```

Σk 是逐项求和，与字母表 Σ 无关。下标 i+1 表示下一维，例如 S_1=D_2×S_2，不是把 D_i 加 1。减下界把下标转成从零计数的位移，乘步长把位置数转成地址单位。索引在合法范围内、尺寸与地址单位统一是公式前提。

这里 Si 表示第 i 层一个成分的大小。使用其他记号体系的公式时，应先对齐 Si 的含义，再比较公式。

### 7.2 课件 [1..3][1..4]，int 占 4 字节

这里课件特意改用字节单位，α=4，D1=3、D2=4，S2=4、S1=16，总 48 字节。A[3][2] 位移 `(3-1)×16+(2-1)×4=36`。

| 行 | 各元素相对地址（字节） |
| --- | --- |
| A[1] | 0、4、8、12 |
| A[2] | 16、20、24、28 |
| A[3] | 32、36、40、44 |

后面课件例恢复 int=1 教学单位，不能把本例的 4 偷带到所有题目。

### 7.3 逐维累加的四元式

每维生成三条基本操作：`SUBI index,Low`、`MULTI 位移,Si`、`AADD 当前基址,位移`。处理一维后，得到成分地址与成分类型，下一维继续沿类型的 ElemType 下降。

对 `a:[1..10][1..5]int`，int=1，`a[i+1][j*i-2]`：

```text
1 (ADDI,i,1,t1)           第一维下标
2 (SUBI,t1,1,t2)          减第一维下界
3 (MULTI,t2,5,t3)         每行占 5
4 (AADD,a,t3,t4)          选中行的地址
5 (MULTI,j,i,t5)          第二维下标的前半
6 (SUBI,t5,2,t6)          完成 j*i-2
7 (SUBI,t6,1,t7)          减第二维下界
8 (MULTI,t7,1,t8)         每个 int 占 1
9 (AADD,t4,t8,t9)         元素地址
```

t4 保存行地址，不是行第一个整数；t9 保存最终元素地址。C 的各维下界 0 时减 0 可省略，是其布局约定带来的简化。

## 8. 下标的语法制导翻译

上节已经给出地址公式，分析器还需在每读完一对方括号时知道当前是哪一维、下一步处理什么类型。下面把逐维计算接到文法动作与 Sem 属性上。

### 8.1 下标文法与 AddNext

简单下标串可写 `V→id Push(id) A、A→Init [E] AddNext B、B→[E] AddNext B|ε`。扩展成允许普通变量，则 A 增加 ε。

AddNext 取 Sem 顶部索引与其下方当前数组信息：检查索引类型、当前 Type 是数组；取该层 Low 与成分 Size；生成减下界、乘步长、地址加；弹两项，压 `(ElemType,新地址)`。Init 的维数计数用于说明进度，不应代替逐层类型检查。

`A[B[i]][j]` 会嵌套进行下标翻译，单个全局 k 会被内层覆盖。因此实现应给每个下标引用自己的上下文栈，或直接让 Sem 保留当前成分类型。完成内层后恢复外层，不能把外层第二维误算成内层下一维。

### 8.2 扩展表达式的完整编号

保留 6.1 的 1—8 号规则，后半改为：

```text
(9) P→C Push(C)
(10) P→V
(11) P→(E)
(12) V→id Push(id) A
(13) A→ε
(14) A→Init [E] AddNext B
(15) B→ε
(16) B→[E] AddNext B
```

由于 E 出现在括号和方括号内，Q 改为 `{),],#}`，FIRST(E/T/P) 仍为 F；V 的 FIRST 为 {id}，A/B 为 `{[,ε}`。

| 符号 | FOLLOW |
| --- | --- |
| E、Es | Q |
| T、Ts | {+,-}∪Q |
| P、V、A、B | {\*,/,+,-}∪Q |

PREDICT：1/5 为 F；2 为 Q；3/4 为 +/-；6 为 {+,-}∪Q；7/8 为 \*/；9/10/11 为 C/id/(；12 为 id；13/15 为 {\*,/,+,-}∪Q；14/16 为 [。这些候选同左部互不相交。

| 行 | C | id | ( | ) | + | - | \* | / | [ | ] | # |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E | 1 | 1 | 1 | — | — | — | — | — | — | — | — |
| Es | — | — | — | 2 | 3 | 4 | — | — | — | 2 | 2 |
| T | 5 | 5 | 5 | — | — | — | — | — | — | — | — |
| Ts | — | — | — | 6 | 6 | 6 | 7 | 8 | — | 6 | 6 |
| P | 9 | 10 | 11 | — | — | — | — | — | — | — | — |
| V | — | 12 | — | — | — | — | — | — | — | — | — |
| A | — | — | — | 13 | 13 | 13 | 13 | 13 | 14 | 13 | 13 |
| B | — | — | — | 15 | 15 | 15 | 15 | 15 | 16 | 15 | 15 |

### 8.3 `a[i][j]` 的类型与地址变化

假设 a:[1..10][1..5]int，int=1：

| 分析进度 | Sem 关键内容 | 生成 |
| --- | --- | --- |
| 匹配 a，Push | (二维数组,a) | 无 |
| 选择 A 的 [ 分支，Init | 外层引用上下文 | 无 |
| 在第一对括号内分析 i | (二维数组,a),(int,i) | 无 |
| 匹配 ]，AddNext | (一维长度5数组,t3) | SUBI i,1→t1；MULTI t1,5→t2；AADD a,t2→t3 |
| B 再遇 [，分析 j | (一维数组,t3),(int,j) | 无 |
| 再匹配 ]，AddNext | (int,t6，元素地址) | SUBI j,1→t4；MULTI t4,1→t5；AADD t3,t5→t6 |
| B/Ts/Es 在 # 取空 | 保留最终元素属性 | 无 |

在索引 i 或 j 后见 ]，其 V 后的 A 要取 ε，Ts/Es 也取 ε，才回到外层匹配 ]。课件若在第二维示意处重复第一维 i 的片段，应按第二次实际索引 j 与当前成分类型计算，不能重复生成第一维步长 5。

如果只写 a[i]，留下的是一维数组成分，不应无条件当作 int 使用；如果再写第三维，当前已经是 int，就应报“不可再下标”。

## 9. 赋值语句

表达式生成一个待使用的值，赋值左边却要提供可写的位置。两边即使都由变量和下标组成，使用其属性的方式也不同；最后一步才把右值存入左位置。

### 9.1 左边提供位置，右边提供值

`S→V := E Assig`：先生成 V 的必要地址，再生成 E；Assig 检查左边可写和赋值兼容，按允许规则转换右值，再生成 `(ASSIG,right,-,left)`。

简单 x 左部无须额外取值；数组地址 t 是左位置，不能先把数组旧值读出来当目标。赋值不返回普通表达式值时，动作弹掉左右属性。

### 9.2 课件 `a[i][j]:=x+y*3`

```text
1 (SUBI,i,1,t1)
2 (MULTI,t1,5,t2)
3 (AADD,a,t2,t3)
4 (SUBI,j,1,t4)
5 (MULTI,t4,1,t5)
6 (AADD,t3,t5,t6)
7 (MULTI,y,3,t7)
8 (ADDI,x,t7,t8)
9 (ASSIG,t8,-,t6)
```

1—6 求左元素地址，7—8 求右整数值，9 通过 t6 所保存地址写对象。不同类型只在语言规定转换合法时生成转换，不能把任意类型差异都转换成实数。

## 10. 条件与循环语句

顺序四元式还不能表达“只执行一个分支”或“反复检查条件”。条件和循环标记保存这些控制关系，让后端能够定位入口、出口并生成跳转。

### 10.1 if 标记的含义

带 else：条件计算→THEN t→真分支→ELSE→假分支→ENDIF。THEN 在条件假时跳到假分支，ELSE 在真分支末尾跳过假分支并定位它的入口，ENDIF 定位共同出口。没有 else 时假分支直接跳 ENDIF。

ThenIf 检查 Sem 顶条件是否按教学语言为 bool，生成 THEN 并弹条件；ElseIf 生成 ELSE；EndIf 生成 ENDIF。

课件动作结构：`S→if E then ThenIf S ElsePart EndIf`，`ElsePart→else ElseIf S|ε`。提取共同前缀后仍有悬空 else 二义问题，要规定 else 与最近未匹配 then 结合，或使用无二义文法；不能因此宣称改写后自动 LL(1)/LR。

### 10.2 while 必须回到条件之前

`S→while StartWhile E do DoWhile S EndWhile`。StartWhile 生成 WHILE，位于条件计算之前；DoWhile 检查 bool、生成 DO t、弹条件；EndWhile 生成 ENDWHILE。

```text
WHILE             每轮从这里重新计算
E 的计算 → t
DO t              t 假就退出
循环体
ENDWHILE          跳回 WHILE，并定位出口
```

若 WHILE 放到条件计算之后，回边可能只重新使用旧 t，不再读取被循环体更新的变量，改变循环行为。

### 10.3 一维数组课件例的全部代码

A:[1..5]int，a:=1，while a<=10，若 a<>b 则 A[a]:=A[b]+2，否则 a++，每轮 b++；int=1：

```text
1 (ASSIG,1,-,a)
2 (WHILE,-,-,-)
3 (LE,a,10,t0)
4 (DO,t0,-,-)
5 (NE,a,b,t1)
6 (THEN,t1,-,-)
7 (SUBI,a,1,t2)
8 (MULTI,t2,1,t3)
9 (AADD,A,t3,t4)
10 (SUBI,b,1,t5)
11 (MULTI,t5,1,t6)
12 (AADD,A,t6,t7)
13 (ADDI,t7,2,t8)
14 (ASSIG,t8,-,t4)
15 (ELSE,-,-,-)
16 (ADDI,a,1,t9)
17 (ASSIG,t9,-,a)
18 (ENDIF,-,-,-)
19 (ADDI,b,1,t10)
20 (ASSIG,t10,-,b)
21 (ENDWHILE,-,-,-)
```

t7 作为算术操作数读 A[b]，t4 作为赋值目标写 A[a]。标记暂不填具体跳转地址，后端会回填。

原片段没有初始化 b，且 a<=10 不保证 a/b 在 1..5；a 只在相等分支增加，也不保证必终止。这里忠实给结构翻译，不声称源例能安全正常执行；若要运行，应补初始化与合法范围规则，而不能把它们悄悄改进 IR。

## 11. 调用与过程函数声明


### 11.1 先算实参，再传实参

调用 `f(E1,E2,…)` 包含三个工作：计算每个实参表达式；按形参规定把值、地址或函数信息放到被调用者参数区；转到被调用者入口。**实参**是调用处给出的对象，**形参**是函数声明中的接收名字。数目一致只是第一项检查，还要检查参数类别、类型和引用参数是否确实有可传递的对象地址。

值参数 VALACT 传对象的值；变量参数 VARACT 传对象的地址。ActualFuncACT 传一个直接声明函数的入口及所需环境，FormalFuncACT 转传从形式函数参数取得的函数信息。后两者的运行时实现与第六章的环境保存有关，不能只把函数名字当普通整数复制。

课件的动作安排可写为：

```text
Call → id CallHead ( ParamList ) CallTail
ParamList → ExpList | ε
ExpList → E EvlParam NextList
NextList → , ExpList | ε
```

CallHead 查符号表，确认 id 可调用，保存被调用对象并把此次调用的实参数目设为 0。EvlParam 保存一个 E 的类型与 ARG 信息，增加计数。CallTail 对照形参表检查，然后生成各个传参指令和 CALL；若调用的是函数，还把结果临时变量压入 Sem，供外围表达式继续使用。

嵌套的 `f(g(x),h(y))` 需要**调用上下文栈**：开始 g 时保存 f 当前的计数和实参表，结束 g 后恢复 f。用一个全局计数器会把内外层参数混在一起。同样，应先完成可能包含调用的实参计算，再安放外层参数；否则内层调用可能覆盖外层刚写入的待调用区。

### 11.2 普通变量与已经是引用参数的实参

设 f 的第一个形参为 int 值参数、第二个为 int 变量参数，调用 `f(X+1,Y)`，X 是普通变量，而 Y 本身已经是引用参数。用课件的 int 大小 1 单位，参数区首偏移为 d：

```text
(ADDI,X,1,t1)
(VALACT,t1,d,1)
(VARACT,Y,d+1,1)
(CALL,f,true,t2)
```

VALACT 复制 t1 的整数值。VARACT 必须传 **Y 所指对象的地址**：Y 的形参槽里已经存着地址，不能传 Y 槽自身地址，也不能误传该地址指向的整数值。true 是这里沿用的课件 CALL 标志；实函数与形式函数的分支由调用对象类别确定，各后端的布尔编码应统一，不能只凭 true 字样推断实际机器行为。

### 11.3 ENTRY、返回结果与声明的位置

声明的中间代码结构是：`ENTRY(入口标号,活动记录大小,静态层次)` → 过程体或函数体 → ENDPROC / ENDFUNC。入口标号是运行时跳转位置；大小、层次供空间分配和环境设置使用。大小应由参数、局部对象和临时变量布局求得，不能预先随意填常数。

嵌套声明的内层函数代码可以先排在文件里，但外层的 ENTRY 应定位到外层可执行语句的入口。调用外层必须跳到该入口，不能顺序落入内层函数体。整个程序同样需要明确的主程序入口或跳过声明代码的转移安排。

课件例：过程 Q(x:real) 有局部 u:real，内含函数 f(k:real):real，其体为 `f:=k+k`；Q 的体为 `u:=f(50); y:=u*x`。用符号化的入口和偏移表示：

```text
(ENTRY,Lf,Sizef,Levelf)
(ADDF,k,k,t0)
(ASSIG,t0,-,f的结果槽)
(ENDFUNC,-,-,-)
(ENTRY,LQ,SizeQ,LevelQ)
(FLOAT,50,-,t1)
(VALACT,t1,Offk,2)
(CALL,Lf,true,t2)
(ASSIG,t2,-,u)
(MULTF,u,x,t3)
(ASSIG,t3,-,y)
(ENDPROC,-,-,-)
```

real 大小 2 是该课件的存储约定。50 是整数常量，传给 real 形参前要转换。Pascal 风格的 `f:=…` 写函数结果槽，并非给代码入口改值。片段没有给 y 的声明和完整布局，因此这里只说明翻译结构，保留 Size、Level、Off 等符号，不能据此给出 y 的确切抽象地址。

## 12. 二维数组综合练习

下面把数组寻址、条件与循环放进同一课件例子。先分清哪些四元式计算地址、哪些读写元素、哪些控制执行顺序，再核对完整序列。

### 12.1 从源语句确定每一类动作

课件 17 第 19 页设 A:[1..5,1..10]int，int 占 1 单位：

```text
a:=1; b:=1;
while (a<5) and (b<10) do
begin
  if a<>b then A[a,a+1]:=A[b,b+1]+2
  else a:=a+1;
  b:=b+1
end
```

第一维跨度为 10，第二维跨度为 1。先计算左元素地址，保存到 t10；再计算右元素地址 t17，读该元素并加 2，最后写入左对象。不要把左边的 AADD 结果解释为数组元素当前值。

### 12.2 全部 32 条四元式

```text
1  (ASSIG,1,-,a)
2  (ASSIG,1,-,b)
3  (WHILE,-,-,-)
4  (LT,a,5,t0)
5  (LT,b,10,t1)
6  (AND,t0,t1,t2)
7  (DO,t2,-,-)
8  (NE,a,b,t3)
9  (THEN,t3,-,-)
10 (SUBI,a,1,t4)
11 (MULTI,t4,10,t5)
12 (AADD,A,t5,t6)
13 (ADDI,a,1,t7)
14 (SUBI,t7,1,t8)
15 (MULTI,t8,1,t9)
16 (AADD,t6,t9,t10)
17 (SUBI,b,1,t11)
18 (MULTI,t11,10,t12)
19 (AADD,A,t12,t13)
20 (ADDI,b,1,t14)
21 (SUBI,t14,1,t15)
22 (MULTI,t15,1,t16)
23 (AADD,t13,t16,t17)
24 (ADDI,t17,2,t18)
25 (ASSIG,t18,-,t10)
26 (ELSE,-,-,-)
27 (ADDI,a,1,t19)
28 (ASSIG,t19,-,a)
29 (ENDIF,-,-,-)
30 (ADDI,b,1,t20)
31 (ASSIG,t20,-,b)
32 (ENDWHILE,-,-,-)
```

10—16 是左边寻址；17—23 是右边寻址；24 在 ARG 的间接属性指导下读取 t17 所指对象；25 写 t10 所指对象。若 IR 的实现要求显式 LOAD/STORE，应在相应位置展开，语义一致即可。四元式中能否省掉乘 1、常数计算等属于下一章优化。

### 12.3 翻译正确与源程序合法分开检查

`b<10` 保证 b+1 不超过第二维上界 10，却不能保证 b 作为第一维下标不超过 5；例如 a=2、b=6 会访问 A[6,7]，越界。这里的源程序也只在 else 分支增加 a。合法运行需要另行规定检查或调整源程序。

该例的两个比较没有副作用，用 AND 求二者布尔值可以表达条件；一般语言若规定短路求值，遇到 `p<>0 and A/p>1`、函数调用等就必须用条件跳转保证第二项仅在需要时执行，不能机械生成会提前计算两项的 AND。

## 13. 综合应用：历年题的函数、传参、二维数组与循环一起翻译


**来源：**期末题第4页第六题。f1(int\* a,int b)声明c，先c=10，再按`*a>=10`返回`20*b/c+20*b`或`20*b/c`。main声明`int a[100][500]`和i,j，令i=2、j=f1(&i,5\*i)，循环执行`a[10][j]=10*j/(5*i);j=j+1`直到j>=500。

**教学假设：**int、地址、每个临时量各占1单位，无对齐，行优先，各维下界0；管理区和参数/局部区的起点是off。两个函数的Level按课件C模型写0。f1的a是指针槽，使用`*a`表示所指整数；同名main.a是数组，两者并非同一对象。

RETURN 沿原课件格式把返回值放 RESULT；CALL 沿用课件例子的 true 标志。课件未充分解释 true/false 的编码含义，仍需教师确认；本题由符号项确定 f1 是实在函数。

### 13.1 先算符号与临时量，再回填入口大小

| 函数 | 参数与局部槽 | 临时槽 | ENTRY的Size |
| --- | --- | --- | --- |
| f1 | a=off，b=off+1，c=off+2 | t1…t7在off+3…off+9 | off+10 |
| main | 数组a=off，50000单位；i=off+50000，j=off+50001 | t8…t20在off+50002…off+50014 | off+50015 |

Size是从AR首地址计算的总长度，不只是局部区长度。off尚未给数值，保留符号；这里不额外引入存& i的临时量，VARACT i直接产生对象地址并写目标参数槽。它是课件“传地址”的IR动作；源语言C仍按值传递这个指针，而不是拥有Pascal的var语法。

### 13.2 未优化的完整四元式序列

```text
01 (ENTRY,Lf1,off+10,0)
02 (ASSIG,10,-,c)
03 (GE,*a,10,t1)
04 (THEN,t1,-,-)
05 (MULTI,20,b,t2)
06 (DIVI,t2,c,t3)
07 (MULTI,20,b,t4)
08 (ADDI,t3,t4,t5)
09 (RETURN,-,-,t5)
10 (ELSE,-,-,-)
11 (MULTI,20,b,t6)
12 (DIVI,t6,c,t7)
13 (RETURN,-,-,t7)
14 (ENDIF,-,-,-)
15 (ENDFUNC,-,-,-)
16 (ENTRY,Lmain,off+50015,0)
17 (ASSIG,2,-,i)
18 (MULTI,5,i,t8)
19 (VARACT,i,off,1)
20 (VALACT,t8,off+1,1)
21 (CALL,Lf1,true,t9)
22 (ASSIG,t9,-,j)
23 (WHILE,-,-,-)
24 (LT,j,500,t10)
25 (DO,t10,-,-)
26 (SUBI,10,0,t11)
27 (MULTI,t11,500,t12)
28 (AADD,a,t12,t13)
29 (SUBI,j,0,t14)
30 (MULTI,t14,1,t15)
31 (AADD,t13,t15,t16)
32 (MULTI,10,j,t17)
33 (MULTI,5,i,t18)
34 (DIVI,t17,t18,t19)
35 (ASSIG,t19,-,t16)
36 (ADDI,j,1,t20)
37 (ASSIG,t20,-,j)
38 (ENDWHILE,-,-,-)
39 (ENDPROC,-,-,-)
```

26—28求第10行基址；29—31求该行第j元素地址。t13、t16保存地址；35通过t16写数组元素，不能把t16的地址值覆盖掉。32—34计算待写入的整数值。34是整数除法，不能只因数学上可约分就改变求值顺序及溢出行为。

RETURN与ENDFUNC采用共同退出段：RETURN交付结果后跳到该退出流程；不会执行真分支后再落入else，也不会回收两次AR。ELSE/ENDIF只是结构标记，后端按回填规则安排跳转；若不用共同退出段，也可在两个RETURN处分别发完整返回序列。

### 13.3 用给定执行路径检查值与地址

main.i=2，所以t8=10。调用f1时a槽保存i的对象地址、b=10；\*a=2使条件假；c=10，20\*b/c=200/10=20，于是j=20。循环j=20…499，共480次，`5*i=10`，每次值为10\*j/10=j，最终j=500。

例如首轮数组位移`10*500+20=5020`，写入a[10][20]=20；末轮位移5499，写入a[10][499]=499。a[其他位置]未被这些语句赋值，不能称全数组已经初始化。此路径上的下标0≤10<100、20≤j<500，合法。数值检查只针对原题给定路径，不能由此认定任意实参f1都没有溢出或非法指针。

第8章使用同一编号和字段协议展示三项优化，第9章则用更小的while例详细展开回填。这样改变一条IR时，能够解释它对后续阶段的影响。

## 14. 知识联系与复习


### 14.1 生成代码时的检查顺序

1. 查声明和类型，确定操作是否合法。
2. 给每个表达式结果记录 Type、ARG，以及 ARG 表示值还是对象地址。
3. 按语法动作顺序产生代码，必要时插入合法类型转换。
4. 对数组逐维扣下界、乘跨度、累加偏移，区分寻址与读写。
5. 对控制语句把标记放在正确位置；循环回到重新求条件之前。
6. 对调用保存独立上下文，检查实参与形参，完成传参和返回结果处理。

这一章从语法和类型产生 IR；第八章在语义不变的前提下减少重复工作，第九章把 IR 变成具体的加载、存储和跳转。

### 14.2 自检题与答案

**1. 后缀 `ab+c*` 表示什么？** `(a+b)*c`。遇 + 弹 b、a，计算 a+b；再读 c，遇 \* 计算前一结果乘 c。

**2. 三元式为什么在移动代码时麻烦？** 引用依赖指令编号，移动后要调整引用；间接三元式把执行次序与三元式表分开，四元式则用显式结果名。

**3. int+real 为什么要先 FLOAT？** 类型规则要求两个操作数按 real 运算，不能仅改临时变量类型而不转换整数表示。

**4. AADD 为什么不等于读数组元素？** 它求地址。只有随后按间接操作数读取或写入时才访问那个元素。

**5. while 的开始标记为何在条件表达式之前？** 回边必须重新计算条件，才能看到循环体对变量的更新。

**6. 引用参数 Y 继续传给引用形参时传什么？** Y 槽中存储的对象地址，不是槽地址，也不是对象值。

**7. 语法动作出现 ε 是否等于没有任何工作？** 不等于。动作可由不消耗输入的产生式触发，仍会查表、操作语义栈或发射代码。

## 15. 自测与答案


| 题号 | 学习任务 | 检查能力 |
| --- | --- | --- |
| 1 | a[100][500]按int=1计算a[10][20]的位移，改int=4字节后呢？ | 保持地址单位一致 |
| 2 | t16里有地址800，Mem[800]=7。把9赋给该数组元素应该改哪个单元？ | 区分槽、地址和值 |
| 3 | 对real x和int i翻译x\*(i+1)，转换应发生在整数加法前还是后？ | 按类型与结构生成 |
| 4 | 按语义栈翻译a-b-c，动作如何安排才能保持左结合？ | 跟踪语义栈和动作次序 |

### 15.1 答案与理由

1. 行跨度500，位移10×500+20=5020单位；int改为4字节后是20080字节。两个数描述同一元素，但单位不同，不能将500单位步长与字节基址混合。
2. 写Mem[800]=9，t16的槽中仍保存800。把t16槽写为9会破坏地址，之后读写的是错误位置。
3. 先ADDI i,1→t1，再FLOAT t1→t2，最后MULTF x,t2→t3。这遵守括号内部i+1的整数运算语义；并非任意把整棵树所有整数都提前改实数。
4. 读a压左值，读b后生成t1=a-b并压结果，读c后生成t2=t1-c。每个动作先弹右再弹左，且动作在后续递归前执行，不能变成a-(b-c)。
