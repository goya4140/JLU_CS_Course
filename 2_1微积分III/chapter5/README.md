# 第5章 第二型积分

[课程首页](../README.md) · [整章连续阅读](../05_第二型积分_教程.md)

从做功与通量理解定向积分，先会直接计算，再依据条件选择 Green、Gauss 或 Stokes 公式。

本章按教材的 5 个 Section 组织。先阅读本节教程，再进入对应作业；作业共 28 题，每题包含原题、1—2句话的知识点说明和解题过程。

## Section 学习路线

| Section | 学习目标 | 平时作业 |
|---|---|---|
| [5.1 第二型曲线积分](section1.md) | 理解做功、路径方向及两型曲线积分之间的关系。 | [作业解读 · 5题](homework1.md) |
| [5.2 Green公式及其应用](section2.md) | 掌握平面边界与区域的转换，处理补线、奇点、路径无关与全微分。 | [作业解读 · 10题](homework2.md) |
| [5.3 第二型曲面积分](section3.md) | 理解通量与曲面定向，掌握合一投影、参数法和两型曲面积分的关系。 | [作业解读 · 7题](homework3.md) |
| [5.4 Gauss公式及其应用](section4.md) | 通过散度把封闭面的通量化为体积分，处理补面与奇点。 | [作业解读 · 4题](homework4.md) |
| [5.5 Stokes公式](section5.md) | 通过旋度联系空间闭曲线和所张曲面，并核对右手方向。 | [作业解读 · 2题](homework5.md) |
