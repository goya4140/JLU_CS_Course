# 第5章 第二型积分

[课程首页](../README.md) · [整章连续阅读](../05_第二型积分_教程.md)

从做功与通量理解定向积分，先会直接计算，再依据条件选择 Green、Gauss 或 Stokes 公式。

本章按教材的 5 个 Section 组织。先阅读本节教程，再进入对应作业；作业共 28 题，每题包含原题、1—2句话的知识点说明和解题过程。

## Section 学习路线

| Section | 学习目标 | 平时作业 |
|---|---|---|
| [5.1 第二型曲线积分](section1.md) | 从做功与两型关系理解方向，掌握参数法、选变量与对称性。 | [作业解读 · 5题](homework1.md) |
| [5.2 Green公式及其应用](section2.md) | 理解 Green 的条件和方向，掌握补线、挖洞、投影、路径无关与全微分。 | [作业解读 · 10题](homework2.md) |
| [5.3 第二型曲面积分](section3.md) | 从通量与两型关系理解有向面积元，掌握分项投影、对称性和合一投影。 | [作业解读 · 7题](homework3.md) |
| [5.4 Gauss公式及其应用](section4.md) | 理解散度与封闭面通量，掌握直接体积分、补面和挖洞。 | [作业解读 · 4题](homework4.md) |
| [5.5 Stokes公式](section5.md) | 理解旋度与右手定向，通过选择简单所张曲面计算空间闭路积分。 | [作业解读 · 2题](homework5.md) |
