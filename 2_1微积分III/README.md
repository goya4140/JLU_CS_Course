## 怎样读

首次学习按“具体模型 → 微元 → 公式 → 完整例题 → 方法选择 → 自测”阅读。已经学过的同学可先做自测，再查对应讲解。正文包含24个编号例题、13道章末自测与6道真题推导，配29张 SVG 数学图与知识地图，其中26张由 Matplotlib 按方程绘制。

[打开图文阅读版](https://goya4140.github.io/JLU_CS_Course/2_1%E5%BE%AE%E7%A7%AF%E5%88%86III/index.html ':ignore')。页面提供章节与段落导航，不设闯关、学习进度或强制交互；公式、字体与图均在本目录内，可断网阅读。Markdown 是内容源，HTML 是由同一份内容生成的阅读版。

新增图文演示从分段质量、弧长、投影面积等具体例子起步，再连接到路径、通量、散度与旋度。配图采用矢量格式，放大后保持清晰；每幅图旁都有读图步骤与数值解释，阅读版可打开矢量原图。

## 课程资料站的一部分

本课程属于 JLU_CS_Course 的“大二上”课程资料，与站内其他课程使用相同的学期与章节组织方式。Markdown 版用于站内导航与搜索，图文阅读版提供连续讲解、知识地图与完整例题。

课程内容借鉴 [StudyMate](https://github.com/Miaotofu01/Study-Mate) 的依赖路线、分节讲解与配图思路，由本项目重新编写正文与图形。原始教材、课件和试卷未随教程发布；来源文件与覆盖范围见资料依据页。真题解答为教程推导，课程要求以任课教师通知为准。
