## 怎样使用

首次学习从4.1开始，按Section顺序阅读概念、图示和完整例题，再进入本节“作业解读”。每道作业只包含**原题、对应知识点（1—2句话）、解题过程**，保留第一次、第二次、第三次作业的批次与原题号，共42题。

复习时从章末的方法总结与自测定位薄弱点，再进入对应Section；综合训练使用 [期末题型、六道真题推导与复习路线](06_期末题型与复习路线.md)。现有图文讲解、配图和章末自测均保留，整章连续阅读入口仍可使用。
