# JLU CS Course · 2024

面向吉林大学 2024 级计算机相关专业学生的课程资料整理项目。

本仓库希望把分散在课堂笔记、复习提纲、习题解析、实验资料和 PDF 中的内容，按“学期—课程—章节”重新组织成一套可检索、可持续维护的学习地图。它既记录本科阶段的课程培养路径，也为平时学习、期末复习和后续课程衔接提供统一入口。

> 本项目由学生维护，不代表吉林大学官方培养方案或课程要求。课程名称、学分、开课学期与考核方式可能随年级、专业方向和教学安排调整，请始终以教务系统及任课教师通知为准。

## 仓库的目的

- **建立课程地图**：把各学期课程放回完整培养路径中，说明先修关系和知识衔接。
- **沉淀复习资料**：整理课程笔记、核心考点、典型题目与实验内容，降低重复搜集资料的成本。
- **改善阅读体验**：将零散文件整理为结构化 Markdown，并通过在线站点提供统一导航和搜索。
- **持续共同维护**：在尊重版权和课程要求的前提下，鼓励勘误、补充与结构优化，让资料随学习进度逐步完善。

### 专业选修方向

培养方案中的专业选修大致可以归入以下几条方向线：

- **人工智能与数据**：人工智能基础、机器学习、深度学习、数据挖掘、知识图谱、计算机视觉、大数据技术与应用等。
- **软件开发与平台**：Java、Web 程序设计、前端开发、Java EE、Android、iOS、C#、Windows 程序设计、.NET 架构与设计等。
- **系统与高性能计算**：Linux 实践、多核程序设计、GPGPU 异构高性能计算、面向 AI 的计算系统等。
- **硬件与嵌入式**：CPU 实验、计算机硬件设计 II、微机接口、单片机、计算机控制技术、嵌入式相关课程等。
- **安全与数据库**：安全编程、数据库安全、数据库应用技术、企业级数据库性能调优等。

选课时可结合先修课程、兴趣方向和学分要求规划，不必把课程列表理解为固定的推荐顺序。

## 当前已整理课程

目录名前两位表示“学年_学期”，例如 `2_2` 表示大二下学期。

### 大一下

- [离散数学 I](1_2离散数学I/)：集合、关系、映射、图论、数理逻辑，以及证明与计算题专项。
- [面向对象程序设计](1_2面向对象程序设计/)：提供第 2–19 章的讲解版、考前速记版与模拟题解析，适合系统学习和期末冲刺。

### 大二上

- [数据结构](2_1数据结构/README.md)：完整自学笔记、C++ 参考实现与交互演示。
- [微积分 III](2_1微积分III/README.md)：第一型与第二型积分的图文教程，包含知识地图、完整例题、自测解答与期末真题推导；[图文阅读版](https://goya4140.github.io/JLU_CS_Course/2_1%E5%BE%AE%E7%A7%AF%E5%88%86III/index.html ':ignore')。

### 大二下

- [操作系统](2_2操作系统/)：进程与线程、调度、同步互斥、死锁、存储管理、文件系统和 I/O 管理。
- [算法分析与设计](2_2算法分析与设计/)：分治、贪心、动态规划、回溯、分支限界和 NP 问题。
- [微机系统](2_2微机系统/)：8086、Pentium、汇编语言、存储管理、输入输出及可编程接口。
- [计算机系统结构](2_2计算机系统结构/)：性能分析、Cache、指令级并行、数据级并行和线程级并行。
- [概率论](2_2概率论/)：随机事件、随机变量、数字特征、极限定理、参数估计和假设检验。

### 大三上

- [数据库系统](3_1数据库系统/00_学习导航.md)：第 1–7 章学习资料，覆盖数据库基本概念、关系模型与关系代数、SQL、ER 建模、规范化、事务与并发控制。
- [编译原理](3_1编译原理/00_学习导航.md)：第 1–9 章学习资料，覆盖词法分析、语法分析、语义分析、运行时存储管理、中间代码生成与优化、目标代码生成。

更适合按课程浏览的入口见 [课程总览](课程总览.md)；大二下集中复习可直接进入 [大二下课程总览](大二下课程总览.md)。

## 如何使用

1. 先通过培养路径了解课程之间的前后关系，再进入当前学期的课程目录。
2. 平时学习按章节阅读；期末复习优先查看总览、考点大纲和习题精讲。
3. 使用阅读站左侧目录和搜索框定位知识点，图片或 PDF 较多的内容可结合原始文件查看。
4. 对资料中的结论、考试范围和评分方式进行二次核对，以教材、教师通知和教务系统为准。

## 贡献与维护

欢迎提交勘误、补充笔记或改进目录结构。新增内容时请尽量遵循以下约定：

- 课程目录使用“学年_学期 + 课程名”，章节文件使用数字序号开头。
- 文件名应清楚描述内容，避免使用“最终版”“最新版”等容易失效的命名。
- 上传前请移除个人隐私、答案水印和无权公开的教学资料，并注明必要的来源。
- 新增或移动 Markdown、PDF 后，运行 `python3 tools/generate_sidebar.py` 更新侧边栏。
