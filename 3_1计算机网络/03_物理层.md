## 3.1 物理层功能

### 3.1.1 物理层传什么

物理层把比特变成电、光或无线信号，在通信介质上发送，再从信号中恢复比特。**一个比特是0或1，线路上传播的是承载它的物理信号。**

它需要约定信号状态、一个比特或码元持续多久、怎样接线、控制信号按什么顺序变化等。它不依据目的IP选择路径，也不负责保证一整份文件可靠送达。

### 3.1.2 接口的四种特性

| 特性 | 要约定什么 | 理解例子 |
| --- | --- | --- |
| 机械 | 连接器尺寸、针脚位置、接合方式 | 插头能否正确插入 |
| 电气 | 电压等信号范围 | 哪种电压可被接收端识别 |
| 功能 | 各触点或信号的用途 | 哪根线传数据，哪根表示就绪 |
| 规程 | 操作和信号变化的先后关系 | 请求发送、得到允许、再发数据 |

**理解例子：**两台设备插头一样，但一台输出电压超出另一台的允许范围，仍不能直接连接。“能插上”只解决了部分机械兼容问题。

课件还列出线路配置、传输方向、拓扑、编码等相关问题。物理层尽量给上层提供统一的比特传输能力，但具体距离、干扰与接口条件仍会限制这项能力。

## 3.2 传输介质

### 3.2.1 导向与非导向介质

**导向介质**把信号约束在线缆或光纤中，如双绞线、同轴电缆、光纤。**非导向介质**让电磁波在空间传播，如无线电、微波和红外通信。

选择介质要综合速率、距离、损耗、干扰、施工和维护条件。**衰减**指信号变弱，**干扰**指其他信号或设备影响传输。频率越高不意味着在任何环境里都传得更远。

### 3.2.2 发送时间与传播时间

| 时间 | 含义 | 公式 |
| --- | --- | --- |
| 发送时间 | 把整份数据依次送上链路 | `t_send=L/R` |
| 传播时间 | 信号沿介质走到另一端 | `t_prop=d/v` |

L是数据长度（bit），R是比特率（bit/s），d是距离（m），v是传播速度（m/s）。

**理解例子：**1000 m线路，按`2×10⁸ m/s`传播，传播时间为5 μs。发送1000 B数据，100 Mbit/s下需80 μs，1 Gbit/s下需8 μs。接口速率提高十倍，改变的是发送时间，不会自动改变那5 μs传播时间。

### 3.2.3 双绞线、差分与屏蔽

双绞线把两根导线绞在一起，通常配合**差分传输**：接收端比较两线电压的差，而不是只看某一根线对地的电压。

外界干扰如果在两线上叠加得近似相同，取差时就能抵消一部分，这种共同作用叫**共模干扰**。绞合让两线沿路径所受影响更接近。

**理解例子：**两线电压原为1.2 V、0.2 V，差为1 V；都加上0.3 V干扰后变成1.5 V、0.5 V，差仍是1 V。实际两线受扰不完全一致，因此不能消除全部噪声。

| 类型 | 含义 |
| --- | --- |
| UTP | 非屏蔽双绞线 |
| STP等屏蔽结构 | 增加金属屏蔽以抑制干扰，效果还依赖施工、接地等条件 |

课件还使用S/UTP、S/STP等屏蔽记法，可理解为对整体屏蔽和线对屏蔽方式的区分，具体要按线缆规范辨认。

### 3.2.4 双绞线以太网名称

| 标准例子 | 标称速率 | 本课关注的线对使用 |
| --- | --- | --- |
| 10BASE-T | 10 Mbit/s | 两对线 |
| 100BASE-TX | 100 Mbit/s | 两对线 |
| 1000BASE-T | 1000 Mbit/s | 四对线，各对可双向传输 |

名称中的`BASE`表示基带，`T`表示双绞线。线缆类别、设备接口、编码和距离必须一起考虑，不能仅凭外观判断速率。

常见上述铜缆以太网信道按约100 m设计，这包括相应布线组成和条件，不是所有铜缆技术的统一距离上限。

第14页的参数表同时列线对数、并行通道、频率带宽、编码等。量纲上“通道数×Hz×bit/s/Hz”能得到bit/s，但各标准是否扣编码开销、按哪个方向统计，口径不完全相同，不能机械套每一行。

### 3.2.5 T568A、T568B线序

两种线序的主要区别是橙、绿两对交换位置。

| 引脚号 | T568A | T568B |
| --- | --- | --- |
| 1 | 白绿 | 白橙 |
| 2 | 绿 | 橙 |
| 3 | 白橙 | 白绿 |
| 4 | 蓝 | 蓝 |
| 5 | 白蓝 | 白蓝 |
| 6 | 橙 | 绿 |
| 7 | 白棕 | 白棕 |
| 8 | 棕 | 棕 |

按连接器引脚编号读取。观察正面、背面时左右会变，不能只记图片中颜色的左右方向。

**8P8C**指8个位置、8个触点，日常通常把以太网这类连接器叫RJ45。成对关系很重要，不是任意八根线一一接通就满足标准。

- **直通线**：两端采用相同线序。
- **传统交叉线**：一端A、一端B，把传统10/100 Mbit/s接口的收发线对互换。

传统MDI接口用1、2发送，用3、6接收；MDI-X交换这两个角色。交叉的目的，是让一方发送连接另一方接收。支持自动交叉的接口可自行调整，因此课件规则不能无条件推广到所有千兆或其他接口。

### 3.2.6 同轴电缆与总线网络

同轴电缆由中心导体、绝缘层、外围屏蔽导体和外护层组成，内外导体围绕同一轴线。

课件用早期10BASE2、10BASE5以太网说明总线连接。多个站点共享主干，总线两端需要匹配终端吸收信号，减少**反射**，即信号在不匹配端点返回线路的现象。

共享主干意味着带宽和访问机会要协调，一个接头或端接故障可能影响整个网段。这里学习历史设计原理，同轴电缆本身的用途并不限于这两种以太网。

### 3.2.7 光纤、全反射与传播模式

光纤主要包括**纤芯**和**包层**。纤芯折射率较高，包层较低；在射线模型中，满足入射角条件的光在边界发生**全反射**，被导引在纤芯内传播。

**折射率**描述光在材料中传播及折射的特性。这里先抓住“材料与边界条件共同导引光”，不需要把所有光路想成简单直线。

**模式**是光纤中可传播的光场形式，不是应用消息的数量。

| 类型 | 特点 | 主要影响 |
| --- | --- | --- |
| 多模光纤 | 允许多个传播模式 | 各模式到达时间不同，脉冲可能展宽 |
| 单模光纤 | 在规定波长下只传播一个模式 | 避免模间色散，适合长距离大容量 |

**色散**指一个脉冲的不同成分到达时间不同，原来较窄的脉冲被拉宽。多模的模间色散可能使相邻脉冲重叠；单模仍可能有其他色散与损耗，不能认为完全没有失真。

课件给出的多模芯径约50～60 μm、单模更细，是典型概述；具体光纤需要看标准与产品参数。单模不意味着只能传一个比特流，它仍可配合波分复用承载多路通信。

### 3.2.8 光电转换与匹配

发送端通过LED或激光器把电信号转换为光，接收端通过光敏器件把光转换回电信号。

互连时需要匹配波长、光纤模式、连接器和光功率条件。**功率预算**可理解为“发送功率扣掉沿途损耗后，接收方是否还能可靠识别”。

光纤抗电磁干扰，适合大容量和较长距离；接头清洁、弯曲和施工质量仍影响传输。课件的“贵、维护难”是概括性取舍，不能据此判断所有产品的现实价格。

### 3.2.9 无线电、微波、卫星与红外

| 方式或因素 | 理解 |
| --- | --- |
| 定向传播 | 天线把能量主要集中到某个方向 |
| 全向传播 | 在相应方向范围内覆盖多个终端 |
| 地面微波 | 通常依赖视距，即两端间基本可直视的传播路径 |
| 卫星中继 | 信号经卫星转接，覆盖与延迟取决于轨道和路径 |
| 红外 | 可用于较近距离的光无线通信，易受遮挡影响 |

反射路径可能让同一信号经多个方向到达，叫**多径传播**，它会影响接收波形。墙体、障碍物和同频设备也影响质量。

课件第24页把视距传播和电离层反射并列画出。电离层反射主要适用于相应短波频段，不宜认为普通地面微波也靠这条路径。不同卫星轨道的延迟不同，不能用一种卫星链路代表全部。

### 3.2.10 无线局域网组件

**无线网卡**负责终端无线收发；**AP**把无线终端接入分布系统，通常再连接有线局域网。“分布系统”指连接无线接入点等组件的网络部分。

AP、路由器和调制解调器的职责不同，只是家庭设备可能把它们集成在一台机器里。无线接入正常与能否跨网络通信，仍要分别判断。

## 3.3 物理接口

### 3.3.1 DTE与DCE

| 缩写 | 名称 | 传统模型中的角色 |
| --- | --- | --- |
| DTE | 数据终端设备 | 产生、处理、使用数据，如电脑 |
| DCE | 数据电路终接设备 | 将终端接入通信线路，如调制解调器 |

```text
DTE ─ DCE ─ 通信网络 ─ DCE ─ DTE
```

DTE—DCE接口既传数据，也传就绪、请求、允许等控制信号。标准化让不同厂商的设备能按共同规则配合。

这是功能模型，现代设备可以把多个角色集成在内部。课件第29页图中DCE的英文误写成DTE的展开式，应理解为Data Circuit-Terminating Equipment。

### 3.3.2 EIA-232 / RS-232

EIA-232是课件介绍的传统串行接口，常称RS-232。

课件数据线规则：正电压表示数据0，负电压表示数据1；图中接收有效区域为+3～+15 V和−3～−15 V。靠近零的区域不能用于可靠判决。控制线则有单独的“开/关”规则，不能套用数据0、1的含义。

这说明“高电压代表1”不是通用规律。RS-232也不能直接按普通数字电路的信号电平连接。

课件的固定线缆距离只是其教学描述，实际距离依赖速率、负载和收发器，需查看具体设备规范。

### 3.3.3 异步字符格式

**异步串行传输**按字符发送。每个字符用起始位告诉接收端开始，再按约定时间采样；字符之间可以有不固定的空闲间隔。

```text
起始位 | 数据位 | 可选校验位 | 停止位
```

异步不意味着字符内部没有时序。双方仍要约定速率、数据位数、校验方式和停止位数。

- **8N1**：8数据位、无校验、1停止位，另外还有1起始位，共10位。
- **8E1**：8数据位、偶校验、1停止位，加起始位共11位。

**理解例子：**9600 bit/s、8N1，假定连续发送，无额外空闲：

```text
最多字符数 = 9600/10 = 960字符/s
有效数据率 = 960×8 = 7680 bit/s
数据效率   = 8/10 = 80%
```

停止位不是应用数据；标称9600 bit/s不能直接理解成9600字节/s。

### 3.3.4 数据线、控制线与规程

以下针号对应课件的DB25接口，方向以DTE为参照。

| 针号 | 信号 | 含义 |
| --- | --- | --- |
| 2 | TxD | DTE发送数据 |
| 3 | RxD | DTE接收数据 |
| 4 | RTS | DTE请求发送 |
| 5 | CTS | DCE允许DTE发送 |
| 20 | DTR | DTE报告就绪 |
| 6 | DSR | DCE报告就绪 |
| 8 | CD | 载波检测 |
| 22 | RI | 振铃指示 |
| 1、7 | 保护地、信号地 | 屏蔽及信号参考 |
| 24、15、17 | 相应时钟信号 | 用于同步模式的发送或接收定时 |

可把课件规程读成：准备、报告就绪、请求并获准发送、传输、撤销相应状态。具体控制过程依设备和模式不同，不是每种RS-232连接都执行同一拨号流程。

九针接口使用的是部分功能重新安排，针号与DB25不同，不能取DB25的前九针直接套用。异步通信通常不需要额外同步时钟线，实际也未必使用全部握手信号。

### 3.3.5 USB与差分信号

USB是通用串行总线。课件以USB 2.0和USB 3.x说明供电与信号线的区别。

| 信号组 | 课件中的作用 |
| --- | --- |
| VBUS、GND | 供电与地 |
| D+、D− | USB 2.0差分数据线 |
| SuperSpeed发送、接收差分对 | USB 3.x新增的高速通道，可分别收发 |

USB 3.x不是整个接口只有四根线；课件的“四线用于传输”指新增高速收发差分线，供电及相应兼容信号仍需考虑。

课件速率例子：低速1.5 Mbit/s、全速12 Mbit/s、USB 2.0高速480 Mbit/s。若仅换算：

```text
480 Mbit/s ÷ 8 = 60 MB/s
```

这是未扣协议开销的换算值，不能当作每次文件传输的实际速度。本节讲接口原理，课件中的版本年份和命名表不作为当前产品参数表。

### 3.3.6 DSL、ADSL与DMT

**DSL**是数字用户线路，利用电话铜线传输数据。传统电话系统只使用几kHz的话音频段，不代表铜线只能传这点频率范围。

**ADSL**是非对称数字用户线路，上下行分配不同的传输能力。下行从网络到用户，上行从用户到网络；早期接入业务常给下载分配更多资源。

```text
用户终端 ─ ADSL用户设备 ─ 铜线 ─ 局端设备/DSLAM ─ 网络
                         │
                    分离话音与数据频带
```

**分离器**通过滤波把低频话音和高频数据分开。ATU-R是用户侧ADSL收发设备，ATU-C是局端对应设备；DSLAM是数字用户线路接入复用器，汇聚多条用户线路。

**DMT，离散多音调调制**把可用频带分成多个窄子信道，分别按质量承载数据，再合成总数据流。某些频点质量较差，可以少分配或不分配数据。

课件给256个、间隔4312.5 Hz的子信道，频谱跨度约：

```text
256×4312.5 = 1 104 000 Hz = 1.104 MHz
```

这是频谱跨度，不能直接当作bit/s。不是每个子信道都承载用户数据，部分用于保护或控制。

第46页同时写“256个”和“6～256”等编号，存在端点计数歧义，具体上下行划分还依ADSL制式。这里保留原理，不把编号范围当作已核实标准。

课件还列VDSL、HDSL、SDSL，用于说明距离、速率与对称性的不同取舍；未提供完整参数，学习时不自行补成统一速率表。

## 3.4 物理层互连设备

### 3.4.1 中继器

中继器对收到的可判决信号进行再生，再发往另一段介质，扩展物理覆盖。它不按IP或MAC地址选择路径，也不理解应用内容。

再生可以恢复标准信号形状，但若已经把0误判为1，它不能凭空知道原始数据。**恢复信号与纠正数据错误是两件事。**

连接的网段必须满足相应物理层及介质访问要求，不能把任意不同技术的线路用中继器直接拼在一起。

### 3.4.2 集线器与共享冲突域

集线器可看作多端口中继器。一个端口收到的信号会传播到其他相应端口，而不是只发往目标主机。

**冲突域**是同时发送可能互相碰撞的范围。传统半双工以太网中，多台主机接在同一集线器上，仍共享冲突域和带宽。

**理解例子：**A发给B的信号也到达C、D端口；C同时发送可能产生冲突。换成二层交换机后，设备可以按端口和MAC地址分别处理，差别将在第四章展开。

中继器扩展会增加传播时间和竞争站点，受冲突检测时限等约束，不能无限串接。共享范围增大也会扩大信号可被观察的范围。

## 3.5 公式速查与自测

### 3.5.1 公式速查

| 项目 | 公式 | 注意 |
| --- | --- | --- |
| 发送时间 | `L/R` | L用bit，R用bit/s |
| 传播时间 | `d/v` | 距离与介质决定 |
| 差分电压 | `V_diff=V₊−V₋` | 理想共同干扰相减抵消 |
| 串口字符率 | `线路比特率/每字符总位数` | 包含起始、校验、停止位 |
| 串口数据效率 | `数据位数/每字符总位数` | 未计额外空闲 |
| bit/s换成B/s | `除以8` | 换算不等于实际吞吐量 |

### 3.5.2 自测

1. 插头形状相同，是否保证能通信？还需核对哪些特性？

4. 差分两线都增加0.2 V，理想电压差怎样变化？
5. 单模光纤是否只能承载一路应用？

### 3.5.3 把物理故障与上层故障分开

距离过长、线序错误、光功率不足、电压不兼容，先检查物理连接和接口。链路正常但无法跨网访问，还需检查IP地址、路由和应用，不能仅凭指示灯判断整个通信过程。
