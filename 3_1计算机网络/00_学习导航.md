## 怎样使用这些笔记

首次学习按正文顺序阅读：先弄懂名词对应的东西，再看它怎样工作。遇到计算，先自己完成中间步骤，再对照例子。复习时使用章末速查与自测；自测答案折叠保存，便于先独立作答。

补充例子用于解释课件省略的推理，不冒充原题。课件旧技术按课程范围介绍；涉及协议版本、历史数据或原题矛盾的内容，就近注明条件与核对结果。图示以文本结构图、时序图和表格为主。

计算题建议按四步作答：写明模型与已知量 → 统一单位 → 列式并保留关键中间结果 → 解释答案和适用条件。bit 是位，B 是字节，1 B=8 bit；Hz、Baud、bit/s 分别描述频率、码元速率、比特速率。通信速率的 k、M 通常按十进制倍数理解，存储容量按题设口径计算。

## 跨章节容易混淆的概念

| 概念 | 先问自己什么 | 区别 |
|---|---|---|
| 发送时延 / 传播时延 | 数据是还没发完，还是正在路上？ | L/R 是送上线的时间，d/v 是信号走过距离的时间 |
| 检错 / 可靠交付 | 是判断错没错，还是处理丢失和重复？ | CRC、校验和用于检错；序号、确认、恢复机制处理交付 |
| 流量控制 / 拥塞控制 | 谁来不及处理？ | 前者保护接收端；后者适应网络资源能力 |
| MAC / IP / 端口 | 要找到本链路接口、跨网目的地，还是应用端点？ | 三者属于不同层次的标识 |
| 路由选择 / 转发 | 是决定路线，还是处理当前分组？ | 前者形成路径信息；后者使用已有信息送出分组 |
| ACK 数值 | 这里确认的是帧还是字节？ | 链路层例子需先声明标号约定；TCP ACK 表示下一期待字节 |
| 帧 / 分组 / 报文段 | 当前站在哪一层看？ | 各层的数据单元不同；首部与载荷也相对当前层而言 |
| 面向连接 / 可靠 | 是有没有先建立逻辑关系，还是交付有哪些保证？ | 两个不同维度，不能互相替代 |
| 连接 / 应用会话 | 是传输通道，还是用户的一段交互？ | HTTP 会话可跨多个连接，连接复用不自动记录登录状态 |
