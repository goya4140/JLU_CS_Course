CHAPTER 3 · PHYSICAL LAYER

物理层：0 和 1 真正跑在线缆、
光纤和空气里的那一层

物理层是整个协议栈的最底层。它不关心你在看视频还是发邮件，只负责一件事：怎么把数据链路层交下来的一串比特，变成实实在在的电压、光信号或电磁波，从这台机器送到那台机器。这一章我们就来认识那些真正"跑腿"的介质、插头和设备。

先建立一个整体印象：物理层在忙什么

课件一句话定位：物理层负责如何把计算机连接到通信媒体上，数据传输的单位是比特（Bit）。它把数据链路层交下来的 L2 数据，逐比特地送上传输介质，再原样送到对端。

要把这件事干成，物理层得回答一组很实际的问题：线路怎么配置、数据通信什么模式、拓扑长什么样、信号怎么编码、接口怎么定、用哪种介质。课件把这些归纳成它要解决的六个方面：线路配置、数据通信模式、拓扑结构、信号、编码、接口、介质。

物理层的四个特性（必背）

物理层的所有标准，归根到底就是在规定下面这四件事：

特性规定什么举例
机械特性接口插头的尺寸、各管脚位置DB25 有 25 针、RJ45 是 8P8C
电气特性传输线上电压应在什么范围RS-232 电压 ±15V，±3V 以内算无效
功能特性某根线上某一电平代表什么意义哪根是发送数据、哪根是请求发送
规程特性不同功能事件出现的先后顺序先就绪、再建立连接、再传数据
用"插插头"来理解四个特性

机械特性＝插头长什么样、几个脚；电气特性＝每个脚电压多高才算数；功能特性＝哪个脚是供电、哪个脚传数据；规程特性＝插上去之后先做什么、再做什么。四个特性凑齐，不同厂家的设备才能插上就用。后面 EIA-232 那一大段，就是这四个特性的一次完整展开。

模块 1 有线介质：双绞线、同轴电缆、光纤

信号跑在线缆里的三种方式

信息最终要变成信号才能传输，传输介质分两大类：导向传输媒体（有线）和非导向传输媒体（无线）。这一模块先讲有线的三种主力。

双绞线：网线为什么要两两扭在一起

双绞线由两两扭绞的铜导线组成，分屏蔽和非屏蔽：UTP 非屏蔽双绞线没有金属屏蔽层；STP 屏蔽双绞线有屏蔽层，抗干扰更好（还有 S/UTP、S/STP 等屏蔽结构变体）。两两扭绞的目的，就是用差分抵消电磁干扰。

线序 568A 与 568B

EIA/TIA 布线标准规定了两种线序。记住关键区别：568B 把橙线放在 1/2、绿线放在 3/6；568A 则是绿线在 1/2、橙线在 3/6（蓝、棕两对位置不变）。

RJ45 插头与直连/交叉线

以太网用的连接器叫 8P8C（RJ45）：8 个位置、8 个触点。百兆以太网只用 1、2、3、6 四根线——1、2 是 TX 发送，3、6 是 RX 接收，靠差分信号减少干扰；千兆以太网或 PoE 供电则四对全用。

  • 直连线：两端线序相同（都 568A 或都 568B），用来连不同类设备（电脑↔交换机）。
  • 交叉线：一端 568A、另一端 568B，用来连同类型设备（电脑↔电脑）。

同轴电缆

由内到外是：内层导体、第二层绝缘体、第三层网格导线、最外层塑料外皮。历史上用于总线型拓扑网络，分两种：细缆 10Base2 和 粗缆 10Base5。

光纤：光在里面"反复全反射"

光纤结构从内到外：纤芯（高折射率）→ 包层（低折射率）→ 保护层。工作原理：光在纤芯里不断发生全反射地向前传播——因为纤芯折射率比包层高，光射到界面时全被反射回来，跑不出去。

单模光纤多模光纤
芯径约 1～10 μm，细约 50～60 μm，粗
传输模式只传一个基模同时传多个模式
脉冲形状输入脉冲几乎原样输出，色散小多模式光路径不同，输出脉冲被展宽
适用大容量、长距离通信短距离

优点：抗干扰、传输速率高、距离长；缺点：价格贵、安装维护困难、费用高。光信号和电信号之间要靠光电转换设备匹配：发送端用发光二极管 LED 或注入激光二极管 ILD，接收端用光敏元件/光敏二极管。

为什么多模会"展宽"？课件图说：一束光里走了多条路径（多个模式），有的走直线、有的反复斜反射，到达终点时间有先有后，一个输入脉冲就被拉宽成模糊的一团。芯径越细、只允许一条路径（单模），脉冲就越不容易糊，才能跑远距离高速率。
模块 2 无线介质：信号跑在空气里

微波、卫星与红外

无线传播不用线缆，主要信号有三种：地面微波、卫星微波、红外线。传播方式分两类：定向（信号集中朝一个方向发射，像探照灯）和全向（信号向四周发散，像灯泡）。

地面微波：视距传播

地面微波靠视距传播——收发天线之间要"看得见"中间不能挡。频率高、方向性强，所以需要每隔一段距离建一个中继站接力。它和靠电离层反射的短波广播是两种不同的传播方式。

卫星微波：天上的中继站

把微波中继站搬到天上。卫星通信可以是点对点的通信线路（两个地面站之间），也可以是广播式的通信线路（一颗卫星向一大片区域广播）。它覆盖范围极大，但有传播延迟。

红外与 WLAN

红外也是常见的无线介质（电视遥控器就是）。在无线局域网场景里，常用的组件包括无线接入点等，把无线信号接入有线网络。

有线 vs 无线的取舍：有线（双绞线/同轴/光纤）稳定、速率高、抗干扰，但要布线；无线（微波/卫星/红外）灵活、免布线，但易受环境和遮挡影响。实际网络常常两者混用——室内用 Wi-Fi，骨干用光纤。
模块 3 物理接口：DTE/DCE 与 EIA-232

电脑和网络之间，隔着一个"翻译官"

DTE 与 DCE：谁是用户、谁是接线员

DTE（数据终端设备）是具有数据处理和收发能力的设备（比如你的电脑）。DCE（数据电路端接设备）是能通过网络收发模拟或数字信号的设备（比如调制解调器）。DTE 一般不直接连网络，而是通过一台 DCE 通信；DTE 和 DCE 的连接就叫 DTE—DCE 接口。这个接口上既有数据信息也有控制信息。

为什么要把接口标准化

你想让任何公司生产的电脑都能插进任何一家的调制解调器，就必须对 DTE—DCE 接口做统一规定。这些标准，就是我们说的"物理层协议"。最经典的例子就是 EIA-232。

EIA-232（老 RS-232）：物理层协议的活化石

EIA-232 由电子工业协会 EIA 于 1962 年制定，早期叫 RS-232。典型连接：电脑（DTE，用 Male DB25 插头）通过接口电缆连调制解调器（DCE，Female DB25 插座），再接到电话线。下面按四个特性拆开看。

机械特性：DB25

用 DB25 连接器：数据 4 根、控制 11 根、定时 3 根、其他 7 根；电缆长度不能超过 25 米。

电气特性：电平范围

数据用非归零电平编码 NRZ-L：0 对应正电平、1 对应负电平，电压范围 −15V～+15V。注意有个"无效区域"——电压绝对值在 3V 以内算不定（无效），必须 >+3V 或 <−3V 才算数。控制信号同理：正电平＝开（ON），负电平＝关（OFF）。

别和 TTL 电平混淆：RS-232 用的是 ±15V 大摆幅，而且负电压代表逻辑 1、正电压代表逻辑 0——正好和常见的 TTL 电平相反。早期串口烧坏设备，很多就是因为没注意这个极性。

异步串行传输的帧结构

每个字符包含：7 或 8 bit 数据位、1 bit 起始位、1 bit 停止位、1 bit 校验位。

功能特性：引脚都管什么

DB25 引脚很多，但记住最常用的几根就够日常理解：

连线号代号方向功能
2BA / TxDDTE→DCE发送数据
3BB / RxDDCE→DTE接收数据
4CA / RTSDTE→DCE请求发送（发数据前请求许可）
5CB / CTSDCE→DTE清除待发送（允许发送）
6CC / DSRDCE→DTEDCE 准备好（如调制解调器是否在线）

其余引脚还有同步时钟（15/17/24）、测试回环（18/21）、辅助信道（12/13/14/16/19）等，用到再查即可。

规程特性：握手五步

同步全双工通信按五步走：步骤 1 准备 → 步骤 2 就绪 → 步骤 3 建立 → 步骤 4 数据传输 → 步骤 5 清除。每一步哪些信号线变高、哪些变低都有讲究，载波在建立阶段打开、清除阶段关闭。

实际只用了子集

大多数用户用不上全部 25 针。比如异步串行通信不需要同步时钟线，只需要 2、3、4、5、6、7、8、20、22 这 9 根——计算机上那个 9 针串口，其实就是 EIA-232 的一个子集。

USB 的线和引脚

USB 2.0：2 线供电（VBUS 和 GND）＋2 线差分信号传输。引脚：1=VBUS（红/橙，+5V）、2=D−（白/金）、3=D+（绿）、4=GND（黑/蓝）。USB 3.0 又加 4 线（SSTx+、SSTx−、SSRx+、SSRx−）做全双工。

差分信号：为什么抗干扰强

发送方同时发两根线，一根是信号、另一根是它的反相信号。路上的噪声会同时叠加到两根线上，接收方做减法（两根相减）——共有的噪声被减掉，两个信号的差才是真正的数据。这就是 USB、网线都用差分信号的原因，也是双绞线要两两扭绞配合的道理。

DSL：在普通电话线上跑宽带

DSL（数字用户线路）的灵感来自一个浪费：常规电话线路在局端被滤波器把带宽限到 4 kHz（只够打电话），但 3 类 UTP 的实际带宽远大于 4 kHz。如果把这个限制做成"按需可调"，多出来的带宽就能用来跑宽带。

类型上行下行
ADSL 非对称64k～1 Mbps1～8 Mbps
VDSL / HDSL / SDSL更高/对称等不同变体

ADSL 接入模型

用户侧是 ATU-R（ADSL 远程传输单元，即 ADSL Modem），本地局端是 ATU-C，中间靠 DSLAM（数字用户线路接入复用器）把数据接到交换机；电话信号则经滤波器接到程控交换机。这样打电话和上网能同时进行、互不干扰。

DMT 离散多音调调制

ADSL 把本地可用带宽（约 1.1 MHz）切成 256 个 4312.5 Hz 的独立子信道：信道 0 留给传统电话，信道 1～5 保留，信道 6～256 里 1 个上行控制、1 个下行控制，其余传数据。一般 80～90% 信道分给下行、10～20% 分给上行——这就是"非对称"的由来：下载快、上传慢，符合大家上网的习惯。

模块 5 物理层互连设备：中继器与集线器

把信号"续命"，把网段"拼长"

物理层的网络设备就两类：中继器、集线器。它们作用于信号的电气部分，重新产生信号，从而扩展局域网覆盖的地理范围。注意一个前提：所连接的局域网必须具有相同的物理层和 MAC 协议——中继器不懂地址，只会再生电气信号。

中继器：给衰减的信号"充电"

信号在线上跑得越远越弱、越歪。中继器把收到的弱信号重新生成成干净的新信号再发出去，于是多个局域网段（L1、L2、L3、L4……）可以一段段接起来。它不以任何方式改变网络功能，纯粹跑在物理层。

用中继器扩展后，带来两个问题

  • 性能：更多站点挤到同一介质上，流量变大，局域网整体性能下降。
  • 安全性：更多站点共用同一介质，安全防护更困难。
记住：中继器/集线器只是"把信号再生放大"，它们不隔离冲突、不隔离流量——所有接进来的设备仍在同一个冲突域里。想要隔离，得用上一层的网桥/交换机，那是数据链路层的事。

最后：把物理层这一层装进脑子

定位：物理层是分层体系结构的最底层，数据单位是比特；为设备间通信提供传输介质及互连设备，尽量为上层提供透明、可靠的传输环境。

四个特性：机械（插头尺寸管脚）、电气（电压范围）、功能（电平含义）、规程（事件顺序）。

两类介质：导向（双绞线 UTP/STP、同轴、光纤——靠纤芯/包层折射率差全反射，分单模长距和多模短距）；非导向（地面微波视距、卫星广播、红外；分定向/全向）。

接口标本：EIA-232（RS-232）DB25、±15V、负电压表 1、常用 9 针子集、五步握手；USB 几代速率从 1.5 MB/s 到 2.5 GB/s，靠差分信号抗干扰；ADSL 用 DMT 把 1.1MHz 分成 256 个子信道、下行占大头。

互连设备：中继器、集线器——只再生信号、扩展距离，不隔离流量，要求两端物理层和 MAC 协议相同。
