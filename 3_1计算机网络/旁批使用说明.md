# 个人离线旁批使用说明

> 历史功能说明：本次发布的网页提供章节搜索与明暗外观切换，未启用旁批功能。以下说明仅适用于曾提供旁批功能的旧版网页。

适用范围：第 1～7 章 HTML 学习资料。直接在浏览器中打开任意一章即可使用，无需联网或安装软件。

## 添加与阅读

- **文字高亮** ：用鼠标选中正文，在浮条中点击“高亮”。有浅黄、浅绿、浅粉三种颜色。
- **文字旁批** ：选中文字后点击“写旁批”；点击已有高亮，也可打开编辑。
- **段落批注** ：点击右上角“旁批”，再点击“段落批注”，然后点选正文段落。支持 Tab 选择、Enter 确认、Esc 取消。
- **收起侧栏** ：点击侧栏右上角的关闭按钮，或按 Esc。窄屏时点击遮罩也可收起。
- **查找笔记** ：侧栏支持“全部”“有笔记”“仅高亮”“待定位”筛选；点击“定位原文”返回对应段落。
- **编辑与删除** ：输入后约 0.35 秒自动保存，移出编辑框时也会保存。删除后可在短时提示中撤销。

## 保存与备份

旁批自动保存在当前浏览器的本地存储中，**不会写回 HTML 文件** 。刷新或正常关闭后，可在相同浏览器、相同文件地址继续阅读。

首次使用时，请添加一条笔记并刷新页面，确认当前浏览器允许保存。若保存受阻，侧栏会明确提示；此时须在关闭前导出备份。

使用“导出备份”下载 JSON 文件，使用“导入备份”恢复。备份包含本页能读取到的全部章节旁批；导入后，当前章只显示本章笔记。重复导入会跳过相同内容，同一条笔记存在不同修改时会另存一条，便于比较。

**直接双击本地 HTML 时，各章的存储可能分开，请逐章导出，并在需要时逐章导入。** 换浏览器、移动或重命名文件、清理浏览器数据前，应先导出。不要把浏览器存储当作唯一备份；无痕窗口中的保存也不适合长期使用。

## 正文更新后的定位

系统会根据原文摘录、前后文字和所属小节重新定位。正文改写、摘录重复或匹配依据不足时，显示“待定位”，保留笔记与原文摘录。

点击该笔记的“重新关联”，再选择正确原文并点击“关联原文”，即可恢复关联。该操作保留原有笔记内容。

动态速查、分步演示、波形图等交互控件暂不作为旁批目标，可对其附近的说明段落批注。

## 已验证范围

2026-10-21：在 Windows 的 Edge 独立测试环境中，七章桌面布局及窄屏布局通过 313 项浏览器检查；包含正常关闭浏览器后恢复、存储受阻提示、导入冲突与失效定位。窄屏检查使用浏览器模拟尺寸，未在实体手机或其他浏览器上验证。
