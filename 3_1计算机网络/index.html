计算机网络学习资料

这门课可以沿着一次访问理解：应用提出请求，传输层找到端点并按需要恢复数据，网络层选择逐跳出口，链路层组织帧并协调共享，物理层实际传信号。学习时从基本对象进入信号与链路，再回到跨网与应用，避免只按名词背诵。

课程共七章，各章均提供概念解释、例题推导、综合应用、自测与速查。网页中的分步演示帮助观察过程，可以离线阅读。

每章如何学

先读共同场景，把所有符号和单位说清；再按阶段顺序学正文模块。计算时遮住结果，自己写出已知量和中间值。综合题会把本章多个机制串起来，自测答案折叠保存。复习时先用排错表识别遗漏的条件，再通过速查链接回完整解释。

不要求记住每个旧技术参数。遇到帧长、时隙、编码极性、窗口轮次和协议版本，先在题设中确定模型，再计算。遇到图形题，应先明确拓扑、方向、编号及单位；条件不完整时，不能仅凭术语猜出结果。

跨章节比较

容易混淆的内容 判断对象与范围 怎样联结
发送与传播 L/R 计排上线，d/v 计走过线路 单链路末位到达是两者相加，实际另计处理排队
检错与可靠交付 CRC、校验和判关系；序号、确认、重传恢复 校验是可靠机制的一部分，无法单独证明必达
链路 ARQ 与 TCP 前者例中按帧，后者按字节 确认语义可类比，编号与作用范围不能照搬
MAC、IP、端口 当前链路接口、跨网目标、应用端点 一次跨网包可同时有目的主机 IP 与网关 MAC
流量与拥塞控制 接收端能力与网络能力 TCP 上限共同受 rwnd/cwnd 约束，还需扣在途量
复用与交换 一段链路资源区分与多段链路之间转送 可以同时存在，不是两种互斥网络
HTTP 会话与连接 应用身份状态与传输通道 Cookie 可跨连接，连接复用不自动保存登录状态
缓存、租约、映射 DNS/HTTP 内容、DHCP 地址、NAPT 转换状态 期限和更新规则各自决定，不能当自动永久同步
