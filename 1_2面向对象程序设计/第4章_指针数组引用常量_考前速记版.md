# 第四章 指针、数组、引用、常量（考前速记版）

## 知识结构速览

```
第四章
├─ 指针：Type* p=&exp；nullptr★★★；*p解引用；p+n按sizeof(T)跳；a[k]=*(a+k)
├─ 数组：Type a[N]={...}；指针数组int*a[5] vs 数组指针int(*p)[5] ★★★

```

## 1. 指针

| 写法 | 说明 |
|---|---|
| `Type * var [= 地址];` | 基本定义 |
| `int * p = 0;` | 早期写法，不推荐 |
| `int * p = NULL;` | C++98，本质是整数0 |
| `int * p = nullptr;` ★★★ | C++1z推荐，类型安全，不与int重载混淆 |

- 解引用 `*p`：取/改指针所指内容。
- 指针运算公式（★考点）：`p+n` 等价于 `(T*)((char*)p + sizeof(T)*n)`；`a[k]` 等价于 `*(a+k)`。

---

## 2. 数组

| 写法(C++98) | 写法(C++1z) |
|---|---|
| `int a[5]={1,2,3,4,5};` | `int a[5]{};` |
| `int* b=a;` | `int* b=a;` |
| `int* c=&a[0];` | `int* c=&a[0];` |

数组名会退化为指向首元素的指针，`b`、`c`等价。

### 指针数组 vs 数组指针 ★★★（高频考点）

| | 指针数组 | 数组指针 |
|---|---|---|
| 写法 | `int * array[5];` | `int (*p)[5];` |
| 本质 | 数组（元素是指针） | 指针（指向整个数组） |
| 判断依据 | `[]`优先级高，先看array是数组 | 括号强制先看`*p`，p是指针 |

例：
```cpp
int a[4]={1,2,3,4};
int * b[4] = {&a[0],&a[1],&a[2],&a[3]};  // b:指针数组
int (*p)[4] = &a;                         // p:数组指针
cout<<(*p)[3]<<endl;   // 输出4
```

## 3. 引用（左值引用）

语法：`Type & 变量 = 已存在的变量/对象;`

★★★ 三大规则：
1. 是别名，不是新变量
2. 必须绑定已存在的对象
3. 必须初始化（不可先声明后赋值）

### 与值传递/指针传递对比

| | 值传递 | 指针传递 | 引用传递 |
|---|---|---|---|
| 能否修改实参 | 不能 | 能 | 能 |
| 调用方写法 | `f(a,b)` | `f(&a,&b)` | `f(a,b)` |
| 函数体内写法 | `a` | `*pa` | `a` |

★★★ **引用的价值**：修改与不修改函数接口的调用方写法可以保持一致（都是`test(paper)`），指针则需`test(&paper)`区分。

### 指针 vs 引用 核心差异表

| 维度 | 指针 | 引用 |
|---|---|---|
| 取值方法 | 需要`*`解引用 | 直接用变量名 |
| 初始化 | 可先声明后赋值 | 必须立即初始化 |
| 存在性/可变性 | 可为空、可中途改指向 | 必须绑定已有对象，绑定后不可变 |

## 4. 常量

- **文字常量**：`100`, `3.14`, `true`, `'C'`, `"..."`
- **魔法数字问题**：无命名的字面量导致代码难读、难维护 → 需要命名常量

### #define 宏

| 缺点 | 优点 |
|---|---|
| 纯文本替换，**无类型检查** | 条件编译 `#ifdef/#else/#endif`；字符串化`#`；拼接`##`；`#@`取字符；预定义宏`__LINE__ __FILE__ __FUNCTION__` |

```cpp
#define STR(x) #x        // STR(123) → "123"
#define VAR(x) n##x       // VAR(2) → n2（变量本身）
#define TOCHAR(x) #@x    // TOCHAR(2) → '2'
```

### const命名常量 vs 宏

| | #define | const |
|---|---|---|
| 类型检查 | 无 | 有 ★ |
| 作用域/调试 | 预处理阶段替换，不进符号表 | 正常变量，可调试 |

### 枚举 ★

| C++98: `enum Color{RED=...}` | C++1z: `enum class Color{RED=...}` |
|---|---|
| 值可直接用`RED`，会泄漏到外部作用域 | 必须`Color::RED`，作用域更安全 |

### 常量折叠
`const`全局量在编译期被折叠为字面值，因此可以安全放在头文件中被多个.cpp包含，不会引发重复定义。

---

## 5. const 和指针 ★★★（最重要考点）

**判断口诀**：
- `*` **左边**有 `const` → **内容不可改**（`*p=x`非法）
- `*` **右边**（紧邻指针名）有 `const` → **指向不可改**（`p=&y`非法）
- 右边有const的（常指针）**必须初始化**

| 写法 | 内容可改 | 指向可改 | 必须初始化 |
|---|---|---|---|
| `T * p;` | ✓ | ✓ | 否 |
| `const T * pt;` | ✗ | ✓ | 否 |
| `T * const pt = exp;` | ✓ | ✗ | **是** |
| `const T * const pt = exp;` | ✗ | ✗ | **是** |

### 综合判断表（v、m均为非const普通变量时）

| 语句 | pv(普通指针) | pv2(const T*) | pv3(T* const) | pv4(const T* const) |
|---|---|---|---|---|
| `p = &m;`（改指向） | ✓ | ✓ | ✗ | ✗ |
| `*p = m;`（改内容） | ✓ | ✗ | ✓ | ✗ |

附加限制：若v或m本身是const变量，则不能用**普通（非const）指针**去指向它们（编译错误），即"指向常量的指针"必须用`const T*`接收const变量地址。

---

## 6. 字符串 ★★★

```cpp
char * str = "This is a string!";
// 等价于（因字符串字面量存在只读内存段）
const char * str = "This is a string!";

char str[] = "This is a string!";  // 拷贝到可写数组，能改
```

| | `char* str="..."` | `char str[]="..."` |
|---|---|---|
| 本质 | 指向只读内存的指针 | 内容拷贝，栈上可写数组 |
| 能否改内容 | 不能（等价const char*） | 能 |

标准库字符串：`#include <string>`，用`std::string`更安全（自动内存管理，支持运算符重载）。

---

## 7. const 和引用 ★★★

```cpp
int val = 100;
const int & myval2 = val;
myval2 = 100;   // 错误，const引用不可写
```

★★★ **关键规则**：
- `T&`（普通引用）**只能绑定非const的左值**
- `const T&`（常量引用）**可以绑定一切**：普通变量、const变量、甚至字面量/临时值（编译器自动生成临时对象承接）

```cpp
const int & bb = 1;   // 合法！
int & bb = 1;          // 非法！1不是左值
```

### 函数参数判断（`void f(int a1, int & a2, const int & a3)`）

| 调用 | 合法性 | 原因 |
|---|---|---|
| `f(1,2,3);` | ✗ | a2是普通引用，不能绑字面量2 |
| `f(1,var,var);` | ✓ | var非const，都能绑 |
| `f(1,cvar,cvar);` | ✗ | a2不能绑const变量cvar |
| `f(1,var,cvar);` | ✓ | a2绑var合法；a3是const引用可绑cvar |
| `f(1,cvar,var);` | ✗ | a2不能绑cvar |
| `f(var,var,var);` | ✓ | 全部合法 |
| `f(cvar,var,cvar);` | ✓ | 值传递a1无所谓；a2绑var；a3(const引用)绑cvar |

**核心规律**：设计"只读参数"时优先用`const T&`——不产生拷贝、兼容性最好（能接收任意实参）。

## 速记 Checklist

- [ ] 空指针优先写 `nullptr`，不写 `NULL`/`0`
- [ ] `p+n` 按 `sizeof(T)` 跳跃；`a[k]` 就是 `*(a+k)`
- [ ] `int*a[5]`是指针数组（数组），`int(*p)[5]`是数组指针（指针）——看`[]`还是`()`先结合
- [ ] 引用三规则：别名 / 必须绑定已有对象 / 必须初始化
- [ ] 引用的价值：让"改/不改"参数的调用写法保持一致，无需取地址/解引用
- [ ] `#define`无类型检查，但有条件编译、字符串化(`#`)、拼接(`##`)、`__LINE__`等特殊能力
- [ ] `const`常量优于宏：有类型检查；`enum class`比`enum`作用域更安全
- [ ] const和指针口诀：**`*`左边const管内容，`*`右边const管指向**；右边有const（常指针）必须初始化
- [ ] `char* str="字面量"`等价`const char* str=...`；`char str[]="字面量"`是可写拷贝
- [ ] `T&`只能绑非const左值；`const T&`能绑一切（含字面量/临时值）——只读参数优先用`const T&`
