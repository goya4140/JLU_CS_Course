## 6.1 类型的抽象 ★

| 要点 | 结论 |
|---|---|
| ADT定义 | 数学模型 + 可施加其上的操作集合（类型名/数据集/关系/操作集） |
| 三大特性 | 与具体表示无关、与现实世界无关、任意性和无穷性 |
| ★★★ 核心考点 | **同一实体因关注点不同，可抽象出不同结果**（例：地球-人口经济 vs 地球-天体运动；Person关注age vs 关注knowledge/fatigue） |

---

## 6.2 类型的表示及定义 ★

| ADT概念 | C++对应 |
|---|---|
| 数据 | 数据成员 |
| 操作/行为 | 成员函数（一个行为可由1个或多个操作/函数共同完成） |

★★★ C++ 用 `class` 表示类型的抽象，这个过程叫"类的定义"。

---

## 6.3 类定义 ★★★

**基本语法**：
```cpp
class <类名> { ... };   // 结尾分号不能漏！
```

- 成员定义顺序随意
- 类通常放入头文件（.h）
- class 默认 `private`，struct 默认 `public`（唯一本质区别）

### 包含警戒 vs 前置声明 —— 高频易混点 ★★★

| 对比项 | 包含警戒（Include Guard） | 前置声明（Forward Declaration） |
|---|---|---|
| 写法 | `#ifndef X_H` `#define X_H` `...内容...` `#endif` | `class Bone;` |
| 解决什么问题 | 同一头文件被**多次#include**导致的重复定义 | 类之间**互相#include**导致的循环定义；降低文件间依赖 |
| 使用场景 | 每个 .h 文件都必须加 | 类里只用到另一个类的**指针/引用**（不需要知道其内部细节/大小）时用 |
| 反例后果 | 缺失 → 一个.cpp间接两次include同一.h → "重复定义"编译错误 | 缺失（互相#include）→ 死循环包含，编译失败 |
| ★判断标准 | — | 只用指针/引用 → 前置声明够用；用到**对象本体**（如作为数据成员）→ 必须#include完整定义 |

## 6.4 类的成员

### 6.4.1 数据成员 ★★★

| 类型 | 举例 | 合法性 |
|---|---|---|
| 普通类型 | 指针、数组、引用 | 合法（引用类型不推荐用作数据成员） |
| enum / const 类型 | `const int mAge=30;` | 合法，可类内初始化 |
| static 类型 | 见下表 | 看条件 |
| **递归自身对象** | `Dog mParter;` | ❌ **非法**（大小无法确定） |
| 自身类型指针 | `Dog * mpParter;` | ✅ **合法**（指针大小固定） |

★★★ 高频考点：**class/struct 不能递归定义自身对象，但可以用自身指针**

### static 数据成员类内初始化规则 ★★★（易错点）

| 写法 | 合法性 | 原因 |
|---|---|---|
| `static const int sV=50;` | ✅ 合法 | 同时满足 **const + 整型** |
| `static int mK=60;` | ❌ 非法 | 缺 const |
| `static const float scvv=2.5;` | ❌ 非法 | 不是整型 |

**记忆口诀：静态成员类内初始化 = const + 整型，缺一不可**

### 6.4.2 成员函数

行为的具体实现（例：IntList的add/preAdd/at/setInt；Car的start/speedUp/brake/hit；Bottle的pour/getUsed）。无特殊考点，重点在于能把自然语言问题（如分油问题）转化为类的数据成员+成员函数设计。

## 6.5 类和对象 ★★★

| 概念 | 定义 |
|---|---|
| 类 | 类型的定义（图纸） |
| 对象 | 类的实例化结果（实物） |
| 关系 | 对象必有类型；一个类型可实例化 **0个或多个**对象 |

**实例化语法**：
```cpp
[class] ClassName ObjectName;               // 栈对象
[class] ClassName * pObj = new ClassName;   // 堆对象（指针）
```

### 对象访问方式速查表 ★★★（必考）

| 变量声明方式 | 运算符 | 示例 |
|---|---|---|
| `My obj;`（直接对象） | `.` | `obj.f(20);` |
| `My & obj2 = obj;`（引用） | `.` | `obj2.f(99);` |
| `My * p1 = &obj;`（指针） | `->` | `p1->f(5);` |

**记忆技巧：是不是指针决定用 `.` 还是 `->`；对象本身和引用都用 `.`，指针用 `->`**

## 6.6 对象的存储 ★★★（必考）

| 因素 | 是否影响对象大小 |
|---|---|
| 非静态数据成员的个数、类型 | ✅ 有关（主要因素） |
| 成员函数个数 | ❌ 无关 |
| 静态数据成员多少/类型 | ❌ 无关（全类共享一份，不属于对象） |
| 访问控制（public/private） | ❌ 无关 |
| 是否含虚函数 | ✅ 有关（多出虚函数表指针） |
| 编译器字节对齐设置 | ✅ 有关 |

★★★ **对象大小一定非0**（即使无数据成员，也至少分配1字节）

## 速记 Checklist

- [ ] ADT = 数学模型 + 操作集合；同一实体不同关注点→不同抽象结果
- [ ] C++用class表示抽象：数据→数据成员，行为→成员函数
- [ ] 类定义语法 `class{...};` 结尾分号不能漏
- [ ] 头文件必须写包含警戒 `#ifndef/#define/#endif`，防止重复定义
- [ ] 只用到指针/引用时用前置声明 `class Xxx;`，防止循环包含、降低依赖
- [ ] class默认private，struct默认public
- [ ] 数据成员**不能**递归含自身对象（`Dog mParter;`非法），**可以**含自身指针（`Dog* mpParter;`合法）
- [ ] static数据成员类内初始化必须同时满足 **const + 整型**
- [ ] 对象=类的实例化；一个类型可实例化0个或多个对象
- [ ] 访问方式：对象/引用用 `.`，指针用 `->`
- [ ] 对象大小只与**非静态数据成员**、是否含虚函数、字节对齐有关，与成员函数个数/静态成员/访问控制无关
- [ ] 对象大小**恒非0**
