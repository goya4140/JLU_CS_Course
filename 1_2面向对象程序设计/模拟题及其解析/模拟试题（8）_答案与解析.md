# 《C++ 面向对象程序设计》模拟试题（8）：答案与解析

> 原卷 5 页；答案采用标准 C++17。扫描造成的全角标点和明显字符误识别已校正。

## 一、单选题（20 分，每题 2 分）

1. **关注重要属性而忽略非本质细节称为？** A 封装 B 隐藏 C 抽象 D 覆盖。  
   **答案：C。**抽象提取本质特征；封装是把数据和操作组织在一起并隐藏实现。
2. **最能体现对象与类关系？** A 书和图书馆 B 林肯和总统 C 母亲和女儿 D 学生和研究生。  
   **答案：B。**林肯是“总统”这一类的一个具体实例；D 是类与派生类。
3. **相同操作可能有不同实现称为？** A 复用 B 继承 C 多态 D 名字空间。  
   **答案：C。**
4. **`C public B`、`B public A`，C 成员能访问？**  
   **答案：C，B 和 A 中的保护成员。**继承链上的 `protected` 对派生类可见，`private` 不可直接访问。
5. **哪个类不需要显式拷贝构造？** A 管理堆内存的字符串 B 员工号不可重复 C 至多一个实例的日志 D 含书籍对象数组的图书馆。  
   **答案：D。**值成员数组可逐元素调用 `Book` 的拷贝；A 要深拷贝，B 要生成新编号或禁拷贝，C 应禁拷贝。
6. **静态成员函数 `A& f(A& a)` 不能返回？** A `a` B A 型静态成员 C `*this` D 局部引用变量 `A& b=a`。  
   **答案：C。**静态成员函数没有 `this`。D 返回的是被引用对象而非局部引用变量的存储，安全。
7. **关于对象存储，正确的是？**  
   **答案：B。**非静态数据是对象的一部分，对象本身可位于自动、动态或静态存储区。成员函数代码不逐对象存储；静态数据也不在对象内；基类非静态成员也是派生对象的一部分，故 D 错。
8. **运行时多态通过？** A 静态联编 B 虚函数 C 内联 D 运算符重载。  
   **答案：B。**
9. **`class A { public: void fun(B&); };` 最可能的 A、B 关系？**  
   **答案：A，依赖。**B 只作为操作参数出现。
10. **关于抽象类正确的是？**  
    **答案：B。**抽象类不能实例化但可以有数据成员、构造函数和已实现函数；各动态类型通常各有虚表。

## 二、判断正误（20 分）

1. **`(*this).x` 可访问数据成员 x——对。**等价于 `this->x`。
2. **自定义赋值函数应先判断自赋值——通常对。**尤其是“先释放再复制”的资源类；复制并交换写法可天然安全。
3. **可重载多个构造函数——对。**只要参数列表可区分。
4. **静态对象成员会在所属类析构时析构——错。**静态成员不属于具体对象，通常在程序结束时析构。
5. **A 的友元可访问 A 及其派生类私有成员——错。**只能访问 A 授权的成员，友元权不继承。
6. **虚基类所有成员函数都是虚函数——错。**“虚基类”解决共享基类子对象，和成员函数是否虚无必然关系。
7. **复用已有类应优先继承而非组合——错。**通常组合优先；只有稳定的 `is-a` 子类型关系才选公有继承。
8. **异常不能解决编译错误和逻辑错误——对。**异常处理运行期异常情况。
9. **构造函数为常函数时只能创建常对象——错。**构造函数不能声明为常成员函数。
10. **成员按初始化列表书写顺序初始化——错。**先虚基类、直接基类，再按成员声明顺序，最后执行构造函数体。

## 三、回答题（20 分，每题 4 分）

### 1. 多文件包含关系有什么问题，如何改进

题中 `mymain.cpp` 包含 `file1.h`、`head.h`，`head.h` 又包含 `file1.h`、`file2.h`，且被重复包含；`head.h` 中还定义 `int data=10`。

- 每个头文件添加 include guard 或 `#pragma once`，避免同一翻译单元重复定义。
- 头文件只包含自身声明所必需的最少依赖，可前置声明时不要包含完整头。
- 不在普通头文件定义具有外部链接的 `int data=10`；头中写 `extern int data;`，一个 `.cpp` 中定义 `int data=10;`（或 C++17 使用 `inline int data=10;`）。
- 不让头文件依赖包含顺序；每个头应可独立编译。

### 2. 写出至少三种不修改本对象和实参的虚函数原型

```cpp
virtual void func(FOO value) const;          // 不修改原对象；形参是副本
virtual void func(const FOO& value) const;   // 不修改实参，且避免复制
virtual void func(const FOO* value) const;   // 不经指针修改所指对象
```

按值版本可修改局部副本，但不会修改实参对应对象。指针版本应约定/检查空指针。

### 3. 自定义名字空间的好处

隔离同名标识符、组织模块 API、表达库的归属、减少全局名字污染，并允许通过限定名或选择性 `using` 控制引入范围。头文件中一般不写全局 `using namespace`。

### 4. 如何定义至多一个实例的类

```cpp
class Singleton {
    Singleton() = default;
public:
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
    static Singleton& instance() {
        static Singleton s; // C++11 起线程安全初始化
        return s;
    }
};
```

私有构造阻止外部创建，删除复制阻止复制出第二个对象，静态接口返回唯一局部静态对象。

### 5. Goose、Carp、Shoal、Swim 的关系

增加抽象 `Animal`；`Goose` 和 `Carp` 是 `Animal` 子类。游泳不是分类层次本身，可定义 `SwimBehavior` 策略，由鹅、鲤鱼组合不同游法；或定义小接口 `Swimmable`。`Shoal` 聚合多个 `Carp`/可进一步抽象为 `Fish`，鱼群不是鱼的子类。

## 四、公交车收入（8 分）

题表按扫描可辨数据为：A 上 40；B 上 50、下 20；C 上 30、下 15；D 上 30、下 15；E 全体下车。满载 80，票价每次上车 2 元。B 站想上 50 人时只能上 50（A 后 40、下 20 后余 20）；C/D 也按容量截断。

```cpp
#include <algorithm>
#include <iostream>
class Bus {
    const int capacity;
    int passengers = 0;
    int income = 0;
public:
    explicit Bus(int maxCapacity) : capacity(maxCapacity) {}
    void Up(int num) {
        int accepted = std::clamp(num, 0, capacity-passengers);
        passengers += accepted; income += accepted*2;
    }
    void Down(int num) {
        if (num < 0) passengers=0;
        else passengers -= std::min(num, passengers);
    }
    void ToStation(int nUp, int nDown) { Down(nDown); Up(nUp); }
    int GetIncome() const { return income; }
};
int main() {
    Bus bus(80);
    bus.ToStation(40,0);
    bus.ToStation(50,20);
    bus.ToStation(30,15);
    bus.ToStation(30,15);
    bus.ToStation(0,-1);
    std::cout << bus.GetIncome() << '\n';
}
```

按以上可辨表格计算，上车人数依次为 40、50、15、15，共 120 人次，收入 **240 元**。若原扫描表中 B/C 行的不可辨数字与此不同，只需替换 `ToStation` 参数，类实现不变。

## 五、程序运行结果（10 分）

### 1. 构造、复制、静态计数与按值传参

扫描代码的关键点是：构造和拷贝构造均调用 `Show()`；`Func(A a)` 按值再次复制，并输出 `a.mVal++`；析构也调用 `Show()`。按原程序语句顺序逐对象跟踪 `mVal` 与静态 `count` 即可。由于扫描页中 `Show()` 内 `count` 的自增符号以及构造函数参数后的字符无法可靠辨认，无法唯一确定数值序列。**此处不虚构唯一输出**；应以原 PDF 第 7 页放大核对源字符后代入。确定的调用顺序为：

```text
a 构造的 Show
b 拷贝构造的 Show
c 构造的 Show
Func 形参拷贝构造的 Show
Func 输出并递增形参 mVal
形参析构的 Show
c、b、a 依次析构的 Show
```

### 2. 虚函数与非虚函数

恢复代码中 `Base::vg()` 内依次调用 `vf()`、`nvh()`；`Derived` 覆盖 `vf()` 并隐藏 `nvh()`。`Base* p=new Derived;` 的三次调用结果：

```text
Derived::vf()
Base::vg()
Derived::vf()
Base::nvh()
Derived::vf()
Base::nvh()
Derived::vf()
```

其中 `p->vf()` 动态分派；`p->vg()` 执行 Base 版本，其内部虚调用 `vf` 到 Derived，而非虚 `nvh` 固定为 Base；`p->nvh()` 也静态绑定 Base，内部再虚调用 `vf`。

## 六、Door 与 AlarmDoor（12 分）

第一问可让 `AlarmDoor` 继承 `Door` 并组合一个 `Alarm`，因为“报警门是门”且“一扇报警门拥有一个报警器”。第二问两维独立变化，应用策略/桥接而非为每种组合建子类。

```cpp
#include <memory>
struct LockBehavior { virtual ~LockBehavior()=default; virtual void lock()=0; virtual void unlock()=0; };
struct Alarm { virtual ~Alarm()=default; virtual void ring()=0; };

class Door {
    std::unique_ptr<LockBehavior> lock_;
public:
    explicit Door(std::unique_ptr<LockBehavior> l) : lock_(std::move(l)) {}
    virtual ~Door()=default;
    void lock() { lock_->lock(); }
    void unlock() { lock_->unlock(); }
};
class AlarmDoor : public Door {
    std::unique_ptr<Alarm> alarm_;
public:
    AlarmDoor(std::unique_ptr<LockBehavior> l, std::unique_ptr<Alarm> a)
      : Door(std::move(l)), alarm_(std::move(a)) {}
    void alarm() { alarm_->ring(); }
};
```

新增锁型或报警器时仅新增策略实现，并在组装对象时注入任意组合。

## 七、用子类型化重设向量的模（10 分）

把“如何计算模”作为多态变化点；公共 `Standard()` 调用无参数虚函数 `NormalValue()`。常用 1、2、∞ 阶用具体子类，罕见 k 阶用带 `order` 状态的子类。

```cpp
#include <algorithm>
#include <array>
#include <cmath>
class Vector {
protected: std::array<double,3> v;
public:
    explicit Vector(const double a[3]) : v{a[0],a[1],a[2]} {}
    virtual ~Vector()=default;
    virtual double NormalValue() const=0;
    Vector& Standard() { double n=NormalValue(); for(double& x:v)x/=n; return *this; }
};
class L1Vector : public Vector {
public: using Vector::Vector;
    double NormalValue() const override { double s=0; for(double x:v)s+=std::abs(x); return s; }
};
class L2Vector : public Vector {
public: using Vector::Vector;
    double NormalValue() const override { double s=0; for(double x:v)s+=x*x; return std::sqrt(s); }
};
class InfinityVector : public Vector {
public: using Vector::Vector;
    double NormalValue() const override { double m=0; for(double x:v)m=std::max(m,std::abs(x)); return m; }
};
class LpVector : public Vector {
    int p;
public: LpVector(const double a[3],int order):Vector(a),p(order){}
    double NormalValue() const override { double s=0; for(double x:v)s+=std::pow(std::abs(x),p); return std::pow(s,1.0/p); }
};
```

注意数学上的 p-范数是 `(Σ|xi|^p)^(1/p)`，原扫描代码中的 `/N` 会变成均值型度量，不是题面给出的模。
