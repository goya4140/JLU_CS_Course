## 一、判断对错并说明理由（共 20 分）

原卷说明：共十题，以下仅为回忆者记得的五题，其余五题原题未被回忆记录。

### 1. 如果一个类不能实例化为对象，那么它一定是抽象类

**答案：错误。**

抽象类确实不能实例化，但“不能实例化”还有其他原因。例如构造函数全为私有且没有可访问的创建接口、构造函数被删除，或者类只提供静态功能。因此“抽象类”是充分条件，不是必要条件。

### 2. 一个类中的数据成员的类型不能是该类的类型

**答案：基本正确，但应准确表述。**

非静态数据成员不能以当前类的完整对象作为类型，否则对象大小会无限递归；但可以是当前类的指针或引用，静态数据成员也可以是当前类类型。

```cpp
class Node {
    // Node next;            // 错误：需要无限大小
    Node* next = nullptr;    // 正确
    static Node sentinel;    // 正确：不属于每个对象
};
```

### 3. 基类中的数据成员可以由派生类初始化

**答案：错误。**

基类子对象由基类构造函数初始化。派生类只能在初始化列表中选择要调用的基类构造函数，不能直接初始化基类的数据成员。

```cpp
class Base { public: explicit Base(int x) : x_(x) {} private: int x_; };
class Derived : public Base {
public: Derived(int x) : Base(x) {} // 调用基类构造函数
};
```

### 4. `void f(int *p)` 和 `void f(int *p) const` 可以构成重载

**答案：有条件正确。**

若二者是非静态成员函数，则可重载，末尾的 `const` 修饰隐含的 `this` 参数；常对象只能调用常版本，普通对象优先调用非常版本。若它们是普通全局函数，则语法上不存在末尾 `const`。

### 5. 某个类中若其所有构造函数都设为私有成员，那么它不能被实例化

**答案：错误。**

类外普通代码不能直接构造它，但类的成员函数和友元仍能调用私有构造函数，典型用途是单例或工厂方法。

```cpp
class A {
    A() = default;
public:
    static A create() { return A{}; }
};
```

## 二、简答题（30 分）

### 1. 说明 `<>` 在 C++ 中的全部作用以及它和 `()` 的关系

**参考答案：**

`<>` 不是一个可独立重载的二元运算符组合，而是若干语法的定界符：

1. `#include <iostream>` 中界定系统头文件名；编译器通常按系统包含路径查找，而 `"x.h"` 一般先查当前工程路径。
2. `template<class T>` 中界定模板形参表。
3. `vector<int>`、`f<int>(x)` 中界定模板实参表。
4. `static_cast<T>(x)`、`dynamic_cast<T>(x)`、`const_cast<T>(x)`、`reinterpret_cast<T>(x)` 中界定目标类型。

它和 `()` 最典型的关系出现在函数模板调用：`f<int>(x)` 中 `<>` 给出编译期模板实参，`()` 给出运行函数调用的实参。二者属于不同层次，不能互相替代。尖括号还可能与关系运算符 `<`、`>` 在词法上相同，但由语法上下文消歧。

### 2. 函数类型都是确定的，为什么还需要虚函数表

静态类型只说明“允许通过该表达式调用什么接口”，并不总能确定运行时对象的动态类型。基类指针或引用可能实际指向任意派生类对象；虚函数表把每个多态类的动态类型映射到相应虚函数入口，使同一调用表达式能在运行时选择最终覆盖函数。

```cpp
Animal& a = getAnimal(); // 静态类型 Animal&，动态类型可能是 Cat 或 Dog
a.speak();               // 需按动态类型分派
```

没有虚函数表（或等价动态分派机制），编译器只能按静态类型固定调用 `Animal::speak`，无法实现运行时多态。

### 3. 分析全局变量、局部动态变量、局部静态变量、全局静态变量的生命周期

| 对象 | 存储期与生命周期 | 可见范围 |
|---|---|---|
| 全局变量 | 静态存储期；进入 `main` 前初始化，程序结束时析构 | 从声明处到文件末尾；可用 `extern` 跨文件引用 |
| 局部动态对象 | 动态存储期；`new` 成功时开始，`delete` 时结束 | 指针变量通常只在所在块可见，但对象可由指针传出 |
| 局部静态变量 | 静态存储期；首次执行到声明时初始化，程序结束时析构 | 仅在声明所在块可见 |
| 全局静态变量 | 静态存储期；进入 `main` 前初始化，程序结束时析构 | 仅当前翻译单元（内部链接） |

### 4. C++ 如何支持“值、类型、空间、代码”的变化

- **值的变化**：赋值、算术与逻辑运算、输入、对象状态修改等。
- **类型的变化**：隐式转换、转换构造函数、类型转换运算符及四种显式 cast。
- **空间的变化**：自动对象进入/离开作用域，`new/delete` 动态申请和释放，容器扩容，RAII 管理资源。
- **代码的变化**：函数重载和模板在编译期选择/生成代码；虚函数在运行时选择不同覆盖实现；函数对象和策略对象也可替换行为。

### 5. 举例说明如何禁止类被拷贝构造和赋值

```cpp
class NonCopyable {
public:
    NonCopyable() = default;
    NonCopyable(const NonCopyable&) = delete;
    NonCopyable& operator=(const NonCopyable&) = delete;
};
```

现代 C++ 应使用 `= delete`；旧式写法是把二者声明为私有且不实现。

### 6. 为什么拷贝构造函数的参数必须是引用类型

若按值接收 `A(A other)`，为了把实参传给形参 `other`，必须先拷贝构造 `other`；这次拷贝又要按值传参，于是无限递归。使用 `const A&` 不复制实参，并允许复制常对象和临时对象。

### 7. `A(int i) : f(i) {}` 中的 `f` 可能是什么语言成分

`f(i)` 是构造函数初始化列表中的初始化器，`f` 可能是：

1. 类 `A` 的非静态数据成员；
2. 类 `A` 的直接基类；
3. 在多重继承中由 `A` 负责初始化的虚基类；
4. 委托构造时的类名 `A`（若写成 `A(i)`，且不能再列其他初始化器）。

它不能是普通局部变量、静态数据成员或普通成员函数。

## 四、改错题

### 1. 动态数组未释放

```cpp
class A {
    int k;
    int* pa;
public:
    A(int k = 9) : k(k), pa(new int[k]) {}
    ~A() { delete[] pa; }
};
```

原类申请了数组却没有析构函数，`delete s` 只释放 `A` 对象本身，造成泄漏。进一步应按“三/五法则”实现或禁止复制；更推荐 `std::vector<int>`。

### 2. 原代码本身没有语法错误

```cpp
class A {
    int x{};
public:
    void f() const { std::cout << x << '\n'; }
    void g()       { std::cout << x << '\n'; }
};
```

常成员函数可以读取数据成员，只是不能通过 `this` 修改普通成员；非常成员函数当然也可以读取。若题目要求指出问题，则最合理的改进是初始化 `x`，避免读取未初始化值。

### 3. 抽象类不能作为对象成员，且动态内存会泄漏

```cpp
class A {
public:
    virtual void f() = 0;
    virtual ~A() = default;
};

class B : public A {
    A* pa = nullptr;          // 可指向抽象基类
public:
    void f() override {
        delete pa;
        pa = new B;
    }
    ~B() override { delete pa; }
};
```

原 `A a;` 试图实例化抽象类，错误；`pa = new B` 若不释放则泄漏。实际代码应优先用 `std::unique_ptr<A>`，还要防止递归拥有结构被误用。

### 4. 静态成员函数无对象，且派生类不能访问基类私有成员

```cpp
class A {
protected:
    int x{};
public:
    void f() const { std::cout << x << '\n'; }
};
class B : public A {
    int y{};
public:
    void g() const { std::cout << x << y << '\n'; }
};
```

原 `static f()` 不能直接访问非静态成员 `x`；`B::g` 也不能访问 `A` 的 `private x`。此外原类 `B` 末尾缺少分号。

## 五、战斗机—导弹适配器设计（8 分）

把战斗机和导弹各自稳定的能力抽象为接口，让适配器负责机械装载、数据和控制协议的转换。新增机型或弹型只需增加实现类；若接口协议完全统一，适配器甚至不需要按每个组合派生一个类。

```cpp
#include <memory>

struct Missile {
    virtual ~Missile() = default;
    virtual void mechanicalLoad() = 0;
    virtual void readTelemetry() = 0;
    virtual void acceptControl() = 0;
};

struct Fighter {
    virtual ~Fighter() = default;
    virtual void mount() = 0;
    virtual void receiveData() = 0;
    virtual void sendControl() = 0;
};

class MissileAdapter {
    Fighter& fighter_;
    Missile& missile_;
public:
    MissileAdapter(Fighter& f, Missile& m) : fighter_(f), missile_(m) {}
    void load()    { fighter_.mount(); missile_.mechanicalLoad(); }
    void monitor() { missile_.readTelemetry(); fighter_.receiveData(); }
    void control() { fighter_.sendControl(); missile_.acceptControl(); }
};
```

## 六、实现 `Set` 集合类（10 分）

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

class Set {
    static unsigned nextId;
    std::vector<int> values;
public:
    const unsigned id;
    Set() : id(++nextId) {}
    Set(const Set& rhs) : values(rhs.values), id(++nextId) {}

    Set& operator=(const Set& rhs) {
        if (this != &rhs) values = rhs.values; // id 表示对象身份，不改变
        return *this;
    }
    void add(int x) { values.push_back(x); }
    friend Set operator+(const Set& a, const Set& b) {
        Set result;
        result.values = a.values;
        result.values.insert(result.values.end(), b.values.begin(), b.values.end());
        return result;
    }
    friend std::ostream& operator<<(std::ostream& os, const Set& s) {
        for (int x : s.values) os << x << ' ';
        return os;
    }
};
unsigned Set::nextId = 0;
```

`id` 在构造时生成，拷贝构造也获得新 ID；赋值只复制集合内容，不改变左对象身份。题目明确“不用考虑元素互异”，故直接拼接。

## 七、公司组织结构设计（8 分）

这是组合模式：总部、分公司、子公司和办事处都是可递归包含子实体的组合节点；人力部等职能部门是叶节点。统一接口后可完全遍历。

```cpp
#include <iostream>
#include <memory>
#include <string>
#include <utility>
#include <vector>

class Organization {
public:
    virtual ~Organization() = default;
    virtual void print(int depth = 0) const = 0;
};

class Department final : public Organization {
    std::string name_, duty_;
public:
    Department(std::string n, std::string d)
        : name_(std::move(n)), duty_(std::move(d)) {}
    void print(int d = 0) const override {
        std::cout << std::string(d * 2, ' ') << "部门：" << name_
                  << "，职责：" << duty_ << '\n';
    }
};

class CompanyEntity : public Organization {
    std::string name_, duty_;
    std::vector<std::unique_ptr<Organization>> children_;
public:
    CompanyEntity(std::string n, std::string d)
        : name_(std::move(n)), duty_(std::move(d)) {}
    void add(std::unique_ptr<Organization> node) {
        children_.push_back(std::move(node));
    }
    void print(int d = 0) const override {
        std::cout << std::string(d * 2, ' ') << "实体：" << name_
                  << "，职责：" << duty_ << '\n';
        for (const auto& child : children_) child->print(d + 1);
    }
};
```

## 八、阅读程序并写结果

### 1. 构造和析构顺序

`new B` 依次构造基类 `A`、成员 `a`、执行 `B` 构造函数体，再创建两个动态 `A`。计数变为 4。经虚析构删除时，先执行 `B` 析构函数体，删除动态数组（逆序析构两个 `A`），再析构成员 `a`，最后析构基类 `A`。

```text
A1
A2
B
A3
A4
B
A3
A2
A1
A0
```

### 2. 三张表的调用结果

主函数为：

```cpp
B s;
A& t = s;
s.g();
t.g();
```

**表一：**`g` 非虚，但其内部调用虚函数 `f`。`s.g()` 和 `t.g()` 都执行 `A::g`，其中 `this` 的动态类型为 `B`，故均调用 `B::f`。

```text
B::f
B::f
```

**表二：**`g`、`f` 均为虚函数，`s.g()` 与 `t.g()` 都动态分派到 `B::g`，其中再调用 `B::f`。

```text
B::f
B::f
```

**表三：**`g` 为虚函数、`f` 非虚。两次 `g()` 都动态分派到 `B::g`，在 `B::g` 的词法作用域中静态绑定到 `B::f`。

```text
B::f
B::f
```

易错点：虚分派看调用表达式对应函数是否为虚函数；进入某个函数体后，内部的非虚调用仍按静态规则绑定。
