# 《C++ 面向对象程序设计》模拟试题（9）：答案与解析

> 原卷 5 页；按标准 C++17 作答。

## 一、单选题（12 分，每题 2 分）

1. **C++ 解决命名冲突的机制？** A 友元 B 虚函数 C 重载 D 名字空间。  
   **答案：D。**名字空间隔离名字。
2. **不应出现在头文件中？** A `extern int count;` B `const int count=10;` C `void fun(){...}` D 类定义。  
   **答案：C。**普通非 `inline` 函数定义被多个翻译单元包含会违反单一定义规则。其余在相应语境可放头中（命名空间作用域 `const` 默认内部链接）。
3. **哪个不属于函数重载？** A `int fun(); float fun();` B `int fun(int); int fun(int,int=10);` C `int fun(int&); int fun(const int&);` D 指向可变/常量 int 的指针版本。  
   **答案：A。**不能只按返回类型重载。B 虽构成两个声明，但调用 `fun(1)` 会二义；C、D 参数类型不同。
4. **成员函数 `A* f(A a) const` 适合作为返回值？** A `&a` B A 型指针静态成员 C `this` D `dynamic_cast<A*>(&a)`。  
   **答案：B。**A、D 指向即将销毁的按值形参；`this` 类型是 `const A*`，不能隐式去 const；静态指针成员可返回。
5. **不同对象收到同一消息产生不同结果称为？** **答案：B，多态。**动态绑定是实现运行时多态的机制。
6. **A 只在成员函数局部定义 B 对象，关系最可能是？** **答案：A，依赖。**

## 二、判断正误（20 分）

1. `double dval; float* pi=&dval;` 会隐式转换——**错**，不兼容指针类型，必须明确转换且通常不应这样做。
2. `const A a; a.fun();` 合法则 `fun` 必为常成员——**错**，`fun` 也可能是静态成员函数。
3. B 继承 A，则 `sizeof(B)>sizeof(A)`——**错**，空基类优化等情形可相等。
4. 单参构造一定可隐式转换——**错**，可声明 `explicit`，且访问性/删除状态也会限制。
5. A 自身未显式声明虚函数就无虚表——**错**，可能继承基类虚函数。
6. 异常必须在产生它的当前函数捕获——**错**，可沿调用栈传播到匹配的外层处理器。
7. 抽象类构造和拷贝构造应该是 `protected`——**错**，这是设计选择；构造可 protected，拷贝可 public/protected/delete。
8. 虚函数可访问非虚函数，但非虚函数不能访问虚函数——**错**，普通函数可调用虚函数，且可能发生动态分派。
9. 重载析构与重载构造一一对应——**错**，一个类只有一个析构函数且不能重载。
10. 无指针/引用成员时默认复制也可能泄漏——**通常错。**值成员会递归复制并由 RAII 析构；若值成员自身实现错误则另当别论，题设通常按良构类型判断。

## 三、回答题（28 分）

### 1. `fun.h`、`fun.cpp`、`main.cpp` 的问题

头文件应有包含保护；`fun.cpp` 与 `main.cpp` 都应 `#include "fun.h"`；类定义末尾加分号；默认实参只在首次可见的声明（通常头文件）给出，定义写 `void A::fun(int num)`，不能再次给 `=0`。

### 2. `fun(string)`、`fun(string&)`、`fun(const string&)` 的区别

- 按值：复制/移动出独立形参，可修改副本，接受左值和右值。
- 非常量引用：不复制，可修改调用者对象，只接收可修改左值。
- 常量引用：不复制且承诺不修改，可接收常/非常左值和临时对象；只读大对象常首选。

这三个同时重载并不实用，许多调用会二义；应按所需语义择一。

### 3. 能否显式调用局部对象析构函数

语法允许 `obj.~T()`，但普通自动对象离开作用域还会再次自动析构，造成重复析构和未定义行为。显式析构只适合配合定位 `new` 手工管理对象生命周期等底层场景。

### 4. 可实例化但禁止被继承

现代 C++：`class A final { public: explicit A(int n):val(n){} private:int val; };`。`final` 禁止派生而不限制外部构造多个实例。

### 5. 订单系统类关系

- `Customer` 与 `Order`：一对多关联/客户聚合订单。
- `OrderList` 组合或聚合多个 `Order`。
- `Order` 组合多个 `OrderItem`，条目不能脱离订单独立存在。
- `OrderItem` 关联一个 `Product`，并保存数量、成交价等。
- `ProductList` 聚合多个 `Product`；订单条目引用目录中的产品，而不是拥有产品生命周期。

### 6. 必须用初始化列表的情形

`const` 成员、引用成员、无默认构造的成员对象、调用非默认基类构造、虚基类初始化；另外所有成员都推荐直接初始化以避免先构造后赋值。

### 7. B 的深拷贝与深赋值

```cpp
class A {
    int array[2];
public:
    A(int a,int b):array{a,b}{}
};
class B : public A {
    int* p;
public:
    B(int a,int b,int c):A(a,b),p(new int(c)){}
    B(const B& rhs):A(rhs),p(new int(*rhs.p)){}
    B& operator=(const B& rhs) {
        if(this!=&rhs){ A::operator=(rhs); int* q=new int(*rhs.p); delete p; p=q; }
        return *this;
    }
    ~B(){delete p;}
};
```

先申请成功再释放旧资源可提供较强异常安全保证。

## 四、适配第三方 `XTriangle`（5 分）

题目禁止从 `XTriangle` 派生，因此对象适配器让 `Triangle` 继承目标接口 `Shape` 并组合第三方对象。

```cpp
class Shape { public: virtual ~Shape()=default; virtual void Draw()=0; };
class XTriangle { public: void DrawIt(); };
class Triangle final : public Shape {
    XTriangle impl_;
public: void Draw() override { impl_.DrawIt(); }
};
```

## 五、旅游花费（5 分）

消费指数 A/B/C/D 为 120/80/70/100；线路 1 天数 7/6/5/4，线路 2 为 4/5/6/7。

```cpp
#include <iostream>
class City{int index;public:explicit City(int i):index(i){} int Spend(int d)const{return d*index;}};
int main(){
 City c[]{City(120),City(80),City(70),City(100)};
 int r1[]{7,6,5,4},r2[]{4,5,6,7},s1=0,s2=0;
 for(int i=0;i<4;++i){s1+=c[i].Spend(r1[i]);s2+=c[i].Spend(r2[i]);}
 std::cout<<s1<<' '<<s2<<'\n';
}
```

输出：线路 1 **2070**，线路 2 **2000**。

## 六、导弹发射与飞行策略（8 分）

发射方式和飞行特征是两条独立变化轴，分别抽象为策略并注入导弹，避免型号与行为组合爆炸。

```cpp
#include <memory>
struct LaunchMode{virtual~LaunchMode()=default;virtual void launch()=0;};
struct FlyBehavior{virtual~FlyBehavior()=default;virtual void fly()=0;};
class Missile{
 std::unique_ptr<LaunchMode> l; std::unique_ptr<FlyBehavior> f;
public: Missile(std::unique_ptr<LaunchMode>x,std::unique_ptr<FlyBehavior>y):l(std::move(x)),f(std::move(y)){}
 virtual~Missile()=default; void simulate(){l->launch();f->fly();}
};
```

`SeaLaunch/AirLaunch/LandLaunch` 实现发射接口，`SubSonicFly/SuperSonicFly` 实现飞行接口；具体型号只负责选取组合。

## 七、回调填空（10 分）

恢复后的核心代码及空格答案：

```cpp
class CallBackObject { public: virtual ~CallBackObject()=default; virtual int CallBackFunc(int v){return v;} };
class Server {
 int len; int* data;
public:
 Server(int n):len(n),data(new int[n]){for(int i=0;i<len;++i)data[i]=i+1;}
 ~Server(){delete[] data;}                         // 1/2：释放数组
 int Total(CallBackObject& obj){
   int sum=0; for(int i=0;i<len;++i) sum+=obj.CallBackFunc(data[i]); // 3、4
   return sum;
 }
};
class ClientA:public CallBackObject{
public:void RequestA(Server& s){std::cout<<s.Total(*this)<<'\n';}     // 5
};
class ClientB:public CallBackObject{
public:
 int CallBackFunc(int v)override{return v*v;}                         // 6
 void RequestB(Server& s){std::cout<<"平方和="<<s.Total(*this)<<'\n';}// 7
};
```

平方回调对 1,2 得 5，对 1,2,3 得 14。第三问将 `ClientB::CallBackFunc` 改成 `return v*v*v;`，`RequestB` 输出元素范围和“立方和”，结果为 9、36。

## 八、重构 `MyPic::SendTo`（12 分）

把“输出设备及其全部选项”抽象成一个目标对象，`MyPic` 只保留一个参数；由于第三方设备不可继承，具体目标类组合它们。

```cpp
class MyPic;
struct PicDestination{virtual~PicDestination()=default;virtual bool send(const MyPic&)=0;};
class MyPic{public:bool SendTo(PicDestination& d)const{return d.send(*this);} /* 原图形数据 */};
struct PrintOptions{int left{},top{},right{},bottom{},align{};bool landscape{};};
class PrinterDestination:public PicDestination{
 Printer& printer; PrintOptions opt;
public:PrinterDestination(Printer&p,PrintOptions o):printer(p),opt(o){}
 bool send(const MyPic& pic)override{/* 调第三方 printer */return true;}
};
struct BitmapOptions{int x{},y{},transparent{},mask{};};
class BitmapDestination:public PicDestination{
 Bitmap& bitmap; BitmapOptions opt;
public:BitmapDestination(Bitmap&b,BitmapOptions o):bitmap(b),opt(o){}
 bool send(const MyPic&)override{/* 调第三方 bitmap */return true;}
};
```

新增打印方向只扩充 `PrintOptions` 和打印目标实现，不改 `MyPic`；新增文件、窗口、晒图仪时增加新的 `PicDestination` 实现，原代码仍关闭修改、开放扩展。
