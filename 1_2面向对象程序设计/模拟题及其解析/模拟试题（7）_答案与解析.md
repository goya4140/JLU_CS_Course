# 《C++ 面向对象程序设计》模拟试题（7）：答案与解析

> 原卷 4 页。扫描中明显的 OCR 标点错误已按标准 C++ 恢复。

## 一、单选题（20 分，每题 2 分）

### 1. 下列哪个不是 C++ 标识符的作用域

A. 块作用域　B. 对象作用域　C. 类作用域　D. 名字空间作用域

**答案：B。** C++ 有块、函数、类、名字空间等作用域。“对象”具有生命周期，但“对象作用域”不是标准作用域类别。

### 2. 已知调用 `f(0)` 可编译，`f` 的原型不可能是

A. `void f(int&)`　B. `void f(A)`　C. `void f(A*)`　D. `void f(const A*)`

**答案：A。** 字面量 `0` 是右值，不能绑定到非常量左值引用 `int&`；它可作为空指针常量转换为两种指针。若 `A` 可由 `int` 转换构造，B 也可能成立，故只有 A 必不可能。

### 3. 下列函数原型正确的是

A. `float Volume(int x, y);`  
B. `float Volume(int x, int& y=0);`  
C. `const float Volume(int, float);`  
D. `const float Volume(int x=10, int y);`

**答案：C。** A 的 `y` 缺类型；B 的非常量引用不能绑定字面量 0；D 在有默认实参的形参后出现无默认实参。返回 `const float` 虽通常无意义，但语法正确。

### 4. 类 `A` 的非静态成员函数中隐含参数 `this` 的类型

A. `const A&`　B. `const A*`　C. `A* const`　D. `A&`

**答案：C。** 普通成员函数中可把 `this` 理解为不能改指向的指针 `A* const`；常成员函数中为 `const A* const`。

### 5. 关于静态成员，不正确的是

A. 静态成员函数可以直接访问所属类全部数据成员  
B. 静态数据成员类型可以是所属类  
C. 静态数据成员可作为成员函数的默认实参  
D. 静态成员可由类及派生类对象共享

**答案：A。** 静态成员函数没有 `this`，不能直接访问某个对象的非静态数据成员；B、C、D 均可成立。

### 6. 关于友元，不正确的是

A. 友元函数可直接访问私有成员  
B. 友元函数是成员函数，它被声明在类体内  
C. 嵌套类可以成为外围类的友元  
D. 友元类的全部成员函数均为友元函数

**答案：B。** 友元声明写在类体内，但友元函数不是该类成员。友元关系需显式授予，且不继承、不传递。

### 7. 局部变量隐藏同名全局变量时如何访问全局变量

A. 名字空间　B. 虚基类　C. 引用　D. 作用域限定符

**答案：D。** 使用 `::name`。

### 8. 关于动态联编，不正确的是

A. 以虚机制为基础　B. 编译时确定函数代码　C. 运行时确定函数代码　D. 经对象指针或引用调用虚函数可实现

**答案：B。** 动态联编的目标函数在运行时按对象动态类型确定。

### 9. `class A { B b; };` 中 A、B 最可能的关系

A. 依赖　B. 聚合　C. 组合　D. 泛化

**答案：C。** `B` 以值成员存在，生命周期由 `A` 管理，通常表示强拥有的组合。

### 10. 关于虚函数，正确的是

A. 有纯虚函数的类不能有数据成员  
B. 纯虚函数不能带 `const`  
C. 全部自定义成员为纯虚函数的类无意义  
D. 虚函数表保存函数入口地址而非代码本身

**答案：D。** 抽象类可以有数据和构造函数；`virtual void f() const = 0;` 合法；纯接口类很有价值。

## 二、判断正误（20 分，每题 2 分）

1. **“使用未初始化指针是语法错误”——错。**通常能编译，但读取其不确定值或解引用会导致未定义行为。
2. **“可通过重载改变运算符优先级”——错。**重载不能改变优先级、结合性和操作数个数。
3. **“`x=expression` 后 x 总等于右式的值”——错。**可能发生窄化或自定义赋值语义，如 `int x=3.8` 后为 3。
4. **“定义类时就为数据成员分配空间”——错。**类定义只确定布局；创建对象时才为非静态成员取得对象存储，静态成员另行定义。
5. **“私有成员只能由本类成员函数直接访问”——错。**友元函数、友元类也可直接访问。
6. **“静态成员函数不能为常函数，构造/析构也不能”——对。**三者都不能带成员函数尾部 `const`：静态函数无 `this`，构造/析构期间对象的常量语义不适用。
7. **“可以将基类对象看作派生类对象”——错。**派生对象含基类子对象，反向不成立；向下转换还需实际动态类型满足。
8. **“继承用于改进数据隐藏和封装”——错。**继承主要表达 `is-a` 和复用/扩展；封装依靠访问控制，继承反而增加耦合。
9. **“单参构造函数把自定义对象转换成内置类型”——错。**非 `explicit` 单参构造函数通常把参数类型转换为类类型；类到内置类型靠转换函数。
10. **“抽象类所有成员函数都必须是纯虚函数”——错。**只需仍有至少一个未实现纯虚函数；其他函数可普通、虚或已有实现。

## 三、回答题（15 分）

### 1. `fun(int,int)` 与 `fun(int,int) const` 是否重载

是非静态成员函数重载。非常对象调用时优先非常版本；常对象只能调用 `const` 版本。若通过显式成员函数指针，也可由指针类型选定。

### 2. 用程序说明浅复制只复制指针值

```cpp
#include <iostream>
struct Bad {
    int* p;
    explicit Bad(int v) : p(new int(v)) {}
    // 故意不写拷贝构造：编译器只复制地址
};
int main() {
    Bad a(10);
    Bad b = a;
    std::cout << std::boolalpha << (a.p == b.p) << '\n'; // true
    *b.p = 20;
    std::cout << *a.p << '\n';                           // 20
    delete a.p; // 只能释放一次，否则 double free
}
```

### 3. 必须使用初始化列表的情况（至少四种）

1. 初始化 `const` 数据成员；2. 初始化引用成员；3. 调用无默认构造函数的成员对象；4. 选择非默认基类构造函数；5. 初始化虚基类；6. 提升效率，避免“先默认构造再赋值”。

### 4. Animal、Tiger、Bird、Penguin、Pigeon、PigeonGroup、Fly 的关系

- `Tiger`、`Bird` 公有继承 `Animal`。
- `Penguin`、`Pigeon` 公有继承 `Bird`；企鹅不应被迫实现飞翔。
- 将 `Fly` 设计为可替换行为接口，`Pigeon` 组合一个飞翔策略，或令可飞者额外实现 `Flyable`。
- `PigeonGroup` 聚合/组合多个 `Pigeon`，不是 `Pigeon` 的子类。

### 5. “挤奶”职责分配与变化

把行为放在奶农一侧，新增/变化奶农类型时可通过覆盖奶农的 `milk(Cow&)` 局部扩展，适应变化 A；把行为放在奶牛一侧，新增奶牛品种时可覆盖 `beMilkedBy(Farmer&)`，适应变化 B。若两维都会独立变化，应把挤奶算法抽象成策略 `MilkingStrategy`，由服务对象组合，避免产生“奶农种类 × 奶牛种类”的子类爆炸。

## 四、设计 `Grid`（5 分）

`Grid` 本身是矩形，因此继承 `Rect`；又拥有若干矩形，因此组合矩形集合。构造时把基类文本固定为空。

```cpp
#include <memory>
#include <vector>
class Shape { public: virtual ~Shape() = default; virtual void Draw() = 0; };
class Rect : public Shape {
public:
    explicit Rect(const char* text) { /* 保存文本 */ }
    void Draw() override { /* 画矩形 */ }
};
class Grid final : public Rect {
    std::vector<std::unique_ptr<Rect>> cells_;
public:
    explicit Grid(std::size_t n) : Rect("") {
        for (std::size_t i=0; i<n; ++i)
            cells_.push_back(std::make_unique<Rect>(""));
    }
    void Draw() override {
        Rect::Draw();
        for (auto& r : cells_) r->Draw();
    }
};
```

## 五、程序运行结果（10 分）

### 1. 指针数组与复制

恢复后的关键流程是：`a1(1)`，`pa2=new A(a1)`；`p[0]=a1.SP()`、`p[1]=pa2`；分别执行一次、一次、再一次 `Add`，所以 `a1.n=2`，复制对象 `n=3`。输出：

```text
2
3
```

### 2. 基类、成员与拷贝构造顺序

`Child c1`：先 `Base()`，再成员 `Data()`，后 `Child()`。`Child c2(c1)` 使用隐式拷贝构造：先 `Base(const Base&)`，再 `Data(const Data&)`。销毁按 `c2`、`c1` 逆序，每个对象先析构 `Child` 函数体，再成员 `Data`；基类析构无输出。

```text
Base()
Data()
Child()
Base(const Base&)
Data(const Data&)
~Child()
~Data()
~Child()
~Data()
```

## 六、分油问题（10 分）

```cpp
#include <algorithm>
#include <iostream>
class Bottle {
    int capacity_, amount_;
public:
    Bottle(int capacity, int amount=0) : capacity_(capacity), amount_(amount) {}
    void pourTo(Bottle& to) {
        int moved = std::min(amount_, to.capacity_ - to.amount_);
        amount_ -= moved; to.amount_ += moved;
    }
    int amount() const { return amount_; }
};
int main() {
    Bottle a(10,10), b(7), c(3);
    a.pourTo(b); b.pourTo(c); c.pourTo(a);
    b.pourTo(c); c.pourTo(a); b.pourTo(c);
    a.pourTo(b); b.pourTo(c); c.pourTo(a);
    std::cout << a.amount() << ' ' << b.amount() << ' ' << c.amount() << '\n';
}
```

输出 `5 5 0`，证明过程正确。`pourTo` 的不变量是总油量不变，且两瓶容量范围始终合法。

## 七、连分数 `CFraction`（10 分）

```cpp
#include <iostream>
#include <stdexcept>
class CFraction {
    const unsigned count;
    unsigned* items;
public:
    CFraction(const unsigned data[], int n) : count(n), items(new unsigned[n]) {
        for (unsigned i=0;i<count;++i) items[i]=data[i];
    }
    ~CFraction() { delete[] items; }
    CFraction(const CFraction&) = delete;
    CFraction& operator=(const CFraction&) = delete;
    void GetFraction(int& num, int& den, int n) const {
        if (n<=0 || static_cast<unsigned>(n)>count) throw std::out_of_range("n");
        long long p0=0, p1=1, q0=1, q1=0;
        for (int i=0;i<n;++i) {
            long long p=items[i]*p1+p0, q=items[i]*q1+q0;
            p0=p1; p1=p; q0=q1; q1=q;
        }
        num=static_cast<int>(p1); den=static_cast<int>(q1);
    }
};
```

递推式为 `p_i=a_i p_{i-1}+p_{i-2}`、`q_i=a_i q_{i-1}+q_{i-2}`；前 2 项得 `22/7`，前 4 项得 `355/113`。

## 八、可扩展的 Copy（10 分）

依赖倒置：`Copy` 只依赖输入、输出抽象，不依赖键盘或打印机具体函数。

```cpp
#include <iostream>
struct Input { virtual ~Input()=default; virtual int read()=0; };
struct Output { virtual ~Output()=default; virtual void write(int)=0; };

void Copy(Input& in, Output& out) {
    for (int c; (c=in.read()) != EOF; ) out.write(c);
}
class KeyboardInput : public Input {
public: int read() override { return std::cin.get(); }
};
class PrinterOutput : public Output {
public: void write(int c) override { std::cout.put(static_cast<char>(c)); }
};
```

增加纸带输入或文件/屏幕输出时，仅新增接口实现类，`Copy` 保持不变，符合开闭原则。
