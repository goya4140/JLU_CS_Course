# 第十章 运算符重载 —— 考前速记版

## 知识结构导览（精简）

```
运算符重载
├─ 基本规则：可重载/不可重载、5条限定
├─ 二元重载：自由函数 vs 成员函数 ★★★
├─ 返回类型：值/引用、const与否 ★★★
```

---

## 1. 基本规则

**不可重载的运算符/操作**（★★★ 高频考点，常考选择/填空）：
```
::   .   .*   ?:   sizeof   new   delete   typeid
static_cast   dynamic_cast   const_cast   reinterpret_cast
```
判断依据：这些是**语言内建语法结构**，不是真正的"运算符函数"，无法被替换。

**5条限定条件**（判断依据速记）：
| 条件 | 一句话记忆 |
|---|---|
| ① 只能重载一元/二元 | `?:` 三元不能重载 |
| ② 操作数至少一个自定义类型 | 不能改内置类型语义（`int+int`不能被改） |
| ③ 不能改结合律/优先级 | `a+b+c` 重载后依然左结合 |
| ④ 不能造新符号 | 只能用已有符号，不能发明 `⊕` |
| ⑤ 见上方不可重载列表 | 硬背 |

**永远不要重载**（★★★）：`&&`、`\|\|`、`,`（逗号运算符）
- 判断依据：重载后会**丢失短路求值/顺序求值**的特殊语义，行为变得像普通函数调用（所有参数先求值）。

**一致性原则**：内置类型的运算符有什么"约定俗成的行为"（如 `a+b`==`b+a`、`a=b=c`、`a++`返回旧值），自定义类型重载后也应遵守。

## 2. 二元运算符重载：自由函数 vs 成员函数 ★★★

| 对比点 | 自由函数 | 成员函数 |
|---|---|---|
| 写法 | `T operator+(const T& a, const T& b)` | `T T::operator+(const T& rhs) const` |
| `a+b` 编译成 | `operator+(a,b)` | `a.operator+(b)` |
| 左操作数 | 可以不是自定义类型（如 `2*v1`） | 必须是本类对象（隐含this） |
| 访问私有成员 | 需要 `friend` | 不需要 |

**易混点**：结合律翻译方向——
- 左结合 `a+b+c` → `a.operator+(b).operator+(c)`
- 右结合 `a=b=c` → `a.operator=(b.operator=(c))`

---

## 3. 返回类型判断 ★★★（考试重点：给表达式判断该返回值还是引用、带不带const）

**判断依据：参照该运算符在内置类型上的语义。**

| 表达式 | 返回值/引用 | 是否加const | 原因 |
|---|---|---|---|
| `!a` | 值（`bool`） | — | 产生新值，无需链式操作 |
| `a*b` | 值（`T`） | 一般不加const | 产生新对象 |
| `a=b` | 引用（`T&`） | 不加const | 要支持 `(a=b)=c` |
| `a*=b` | 引用（`T&`） | 不加const | 要支持链式复合赋值 |

**记忆口诀**：**"产生新值 → 返回值；要链式操作（继续赋值/操作）→ 返回引用"**；引用一般不加const，值一般不加const。

**返回值优化（RVO）**：直接在return里构造对象（`return A(x,y);`），比先构造局部对象再return更省一次拷贝构造。★

---

## 4. 成对重载（+ 与 +=）

**核心结论**：
- 用 `+=` 实现 `+`：`return A(lhs) += rhs;`
- 好处：① 适应不同书写习惯 ② 可去掉 `friend` 声明 ③ 加法逻辑只写一处，便于维护

**易错点**：`A(lhs)` 是**拷贝**了一份lhs再操作，不会影响原始lhs。

---

## 5. 一元 `++`/`--`：前置 vs 后置 ★★★（高频考点）

| | 前置 `++a` | 后置 `a++` |
|---|---|---|
| 声明 | `A& operator++()` | `A operator++(int)` |
| 编译翻译 | `a.operator++()` | `a.operator++(0)` |
| 返回类型 | 引用 `A&` | 值 `A` |
| 语义 | 先自增，返回自增后的值 | 先记原值，自增，返回自增前的值 |
| 实现要点 | `num+=den; return *this;` | `A temp(*this); num+=den; return temp;` |

**判断依据/记忆法**：后置版本多一个**没有实际意义的 int 参数**，仅用于让编译器区分重载版本，调用时该参数写 `0`（编译器自动填）。

**易错点**：前置返回**引用**（支持`++(++a)`链式），后置返回**值**（因为返回的是即将销毁的临时副本，不能返回引用）。

## 6. `[ ]`、`( )`、`->` 重载 ★★★

### `[ ]` 下标运算符
- **必须是成员函数**
- 常见双版本：`int operator[](int) const`（只读，配const对象）+ `int& operator[](int)`（可写，配非const对象，返回引用）
- 判断依据：const对象只能调const版本；非const对象优先调非const版本

### `( )` 函数调用运算符（仿函数/Functor）
- **必须是成员函数**
- 可以重载多个参数版本（如无参、双参）
- 用途：STL算法自定义策略；C++11后可用**lambda表达式**替代

### `->` 成员访问运算符 ★★★
- **必须是成员函数**
- **硬性规定（二选一）**：
  1. `operator->()` 返回**指针类型**
  2. `operator->()` 返回**自定义类型**，且该类型**自身也重载了** `operator->()`
- 应用：智能指针（unique_ptr/shared_ptr）实现原理
- 易错点：`b->f()` 编译成 `(b.operator->())->f()`；多层包装会连续调用直到拿到真正指针

---

## 7. `<<`、`>>` 定向输入输出重载 ★★★

**结论：必须写成自由函数**（不能是成员函数）

**判断依据**：`cout << a` 中左操作数是 `ostream`（标准库类型），我们无法往标准库类里加成员函数，所以只能用自由函数（通常配合 `friend` 访问私有成员）。

```cpp
ostream& operator<<(ostream& out, const A& a) { ...; return out; }
istream& operator>>(istream& in, A& a) { ...; return in; }
```

**易错点**：返回类型必须是 `ostream&`/`istream&`（流的引用），否则无法支持链式写法 `cout << a1 << a2`。

---

## 8. 重载方针总表 ★★★（考试重点，务必背熟）

| 运算符 | 成员 or 自由函数 |
|---|---|
| 所有一元运算符（操作数自定义类型） | 成员（建议） |
| `=`、`( )`、`[ ]`、`->` | **必须**成员 |
| `+=、-=、*=、/=、^=、&=、\|=、%=、>>=、<<=` | 成员（建议） |
| 所有其他二元运算符（左操作数不一定自定义类型） | 非成员（建议），典型如 `<<`、`>>`、`+` |

**两条铁律**：
1. 永远不要重载 `&&`、`\|\|`、`,`
2. 保持内置类型该运算符的使用习惯
