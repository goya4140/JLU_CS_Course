## 6.1 类型的抽象

### 是什么
"抽象数据类型"（Abstract Data Type，简称 **ADT**）指的是：**一个数学模型 + 可以施加在这个模型上的一组操作**。换句话说，我们不关心某个类型内部到底是怎么存储、怎么实现的，只关心"它有哪些数据、数据之间满足什么关系、能对它做哪些操作"。

一个 ADT 通常可以用如下方式表示：

```
a ADT :
name {
  数据：
  关系：
  操作：
}
```

### 为什么需要抽象
现实世界的事物极其复杂，如果不做抽象，程序员会被无穷的细节淹没。抽象的作用是**只保留与当前任务相关的特征，忽略无关的细节**，从而让复杂问题变得可以被建模、被编程处理。

ADT 有三个重要特性：

1. **与具体表示无关**：不规定底层用什么数据结构实现（数组、链表都可以）。
2. **与现实世界无关**：抽象出来的模型是数学化的，不依赖某个具体现实场景才能成立。
3. **任意性和无穷性**：同一个现实实体，可以有无数种不同的抽象方式，没有"唯一正确"的抽象。

### 怎么用（例子）

**例1：Person（人）的两种抽象**

| 抽象角度 | 数据 | 关系 | 操作 |
|---|---|---|---|
| 关注年龄 | age | age >= 0 | birth, grow, dead |
| 关注学习状态 | knowledge, fatigue | knowledge > 0, fatigue >= 0 | study, sleep, play |

同一个"人"，因为关注点不同，抽象出的数据和操作完全不同——**这说明抽象没有唯一答案，取决于你要解决什么问题**。

**例2：地球的两种抽象**

| 抽象角度 | 数据 | 行为 |
|---|---|---|
| 社会经济角度 | 人口数据、GDP数据、财富数据 | 增加人口、计算总人口、增加GDP…… |
| 天体运动角度 | 经纬度、赤道角、与太阳距离、线速度 | 指定年份的位置信息、与其他行星的位置关系 |

**例3：书 vs 水杯**

- 书的抽象：数据是"书名、总页数、当前页码"；行为是"翻页、放书签、添加批注……"
- 水杯的抽象：数据是"容量、水量"；行为是"倒入N毫升水、被喝掉M毫升、倒掉……"

> 通俗理解：抽象就像给事物"画像"——你想强调它哪方面的特征，画像的重点就不一样。程序设计中"类的设计"，本质就是先做好这一步抽象。

## 6.2 类型的表示及定义

### 是什么
有了抽象的模型（ADT）之后，还需要用某种编程语言把它**表示**出来。不同语言表示 ADT 的语法不同（比如 C 语言常用 struct + 函数，Java/C++ 用 class）。

**在 C++ 中，用 `class` 关键字表示类型的抽象**，这个过程称为"类的定义"。

### 对应关系
- ADT 中的"操作" → C++ 中的**成员函数**（一个行为往往由一个或多个操作/函数共同完成）
- ADT 中的"数据" → C++ 中的**数据成员**

### 怎么用（例子）

```cpp
class ClassName {
public:
    void f() { mVal = 6; }   // 成员函数：具体实现
    void g();                 // 成员函数：只声明，实现写在类外
private:
    int mVal;                 // 数据成员
};
```

类定义的组成非常简单，只有两类东西：**数据成员**和**成员函数**。后面 6.4 节会展开细讲。

## 6.3 类定义

### 是什么
C++ 中定义一个类的基本格式：

```cpp
class <类名> {
    // 成员声明
};
```

注意结尾的**分号不能漏**，这是新手最常犯的错误之一。

### 几个要点

1. **成员定义顺序随意**：数据成员和成员函数谁先谁后都可以，不影响编译。
2. **类通常放入头文件（.h）**：因为一个类可能被多个 .cpp 文件使用，放在头文件里方便通过 `#include` 共享。
3. **class 与 struct 的区别**：C++ 中两者几乎等价，唯一区别是默认访问权限——`class` 默认 `private`，`struct` 默认 `public`。

### 头文件包含警戒（Include Guard）

**是什么**：当一个头文件可能被多次 `#include` 时（比如 A.h 包含了 B.h，而某个 .cpp 又同时包含 A.h 和 B.h），如果没有保护，类会被**重复定义**，导致编译错误。

**怎么用**：用预处理宏包裹整个头文件内容：

```cpp
#ifndef DOGH
#define DOGH
// ... 类定义 ...
#endif
```

含义：如果 `DOGH` 这个宏还没定义过，就定义它并往下编译；如果已经定义过（说明这个文件已经被包含过一次了），就直接跳过，不再重复编译类定义。

### 反例说明：为什么一定要用包含警戒

| ❌ 反例（缺少包含警戒的风险场景） | ✅ 正确写法 |
|---|---|
| `dog.h` 中如果没有 `#ifndef/#define/#endif`，直接写 `class Dog {...};` | `dog.h` 中用 `#ifndef DOGH / #define DOGH / ... / #endif` 包裹 |
| `cat.h` 中 `#include "dog.h"`（cat 依赖 dog） | 同上，cat.h 也要有自己的包含警戒 |
| `b.cpp` 中同时 `#include "dog.h"` 和 `#include "cat.h"` → dog.h 被间接包含了两次 → **"重复定义 Dog"编译错误** | 有了包含警戒后，第二次包含时宏已定义，内容被跳过，不会重复定义 |

> 类比理解：包含警戒就像是一张"门票核销"机制——同一张门票（同一个头文件）只能生效一次，第二次再刷就会被识别为"已使用过"，直接放行不再重复入场。

### 前置声明（Forward Declaration）

**是什么**：当类 A 只是在成员函数的参数/返回值/指针类型中用到类 B（而不是把 B 的对象直接作为数据成员），可以不必 `#include` B 的完整定义，只需要写一句"这里有一个叫 B 的类"：

```cpp
class Bone;   // 前置声明，不需要#include "bone.h"

class Dog {
public:
    void eat(Bone & aBone);  // 只用到 Bone 的引用/指针，不需要知道 Bone 内部细节
};
```

**为什么要用前置声明**：

1. **防止循环定义**：如果 dog.h 里 `#include "cat.h"`，而 cat.h 里又 `#include "dog.h"`，会出现相互包含的死循环问题。用前置声明可以打破这个循环。
2. **降低文件间依赖性**：修改 Bone 类内部实现细节时，只要 Dog 类没有直接用到 Bone 的完整定义（只用了指针/引用），dog.h 就不需要重新编译，减少了编译依赖链。

### 循环包含问题对照

| ❌ 反例（互相 #include，循环定义） | ✅ 正确写法（互相前置声明） |
|---|---|
| `dog.h` 中 `#include "cat.h"` | `dog.h` 中只写 `class Cat;` |
| `cat.h` 中 `#include "dog.h"` | `cat.h` 中只写 `class Dog;` |
| 结果：两个头文件互相展开，陷入死循环，编译失败 | 结果：两个类都能正常引用对方的指针/引用类型，无循环依赖 |

> 判断标准：如果类里只是把另一个类当"指针"或"引用"使用（不需要知道它占多大内存、有哪些成员），用前置声明就够了；如果需要用到这个类的**对象本身**（比如作为数据成员，需要知道大小），就必须 `#include` 完整定义。

## 6.4 类的成员

类的成员只有两大类：**数据成员**和**成员函数**。

### 6.4.1 数据成员

**是什么**：类内部用来存储状态的变量。可以是：

- 普通类型：`int`、指针、数组、引用等
- `enum` 类型
- `const` 类型
- `static` 类型

**关键限制**：class/struct 类型的数据成员**不能递归定义自身**（比如 `Dog` 类里不能直接放一个 `Dog` 类型的成员），因为这样会导致"无限嵌套、大小无法确定"的矛盾。但**可以用自身类型的指针**，因为指针的大小是固定的（不管指向什么类型都占固定字节数）。

### 对照表：合法 vs 非法的数据成员

| 写法 | 是否合法 | 原因 |
|---|---|---|
| `Person & mOwner;` | 合法（但不推荐） | 引用类型大小固定，合法；但引用不能重新绑定，使用上不够灵活，一般不推荐作为数据成员 |
| `Leg mLegs[4];` | 合法 | 数组是普通类型的组合 |
| `Ring * mpRing;` | 合法 | 指针，大小固定 |
| `Dog mParter;` | **非法** | 递归定义自身，编译器无法确定 Dog 类的大小（无限嵌套） |
| `Dog * mpParter;` | 合法 | 自身类型的指针，指针大小固定，可以 |

### enum / const / static 数据成员示例

```cpp
enum class DogColor {
    WHITE = 1, BLACK = 2, GRAY = 3
};

class Dog {
    ...
private:
    const DogColor mColor = DogColor::WHITE;  // const类型，类内初始化
    const int mAge = 30;                       // const int，类内初始化
    float mPi = 3.14;                          // C++11起普通成员也可类内初始化

    static const int sV = 50;      // 合法：static const 整型，可以类内初始化
    static int mK = 60;             // 非法：非const的static不能类内初始化
    static const float scvv = 2.5;  // 非法：static const 但不是整型，也不能类内初始化
};
```

### 对照表：static 数据成员的类内初始化规则

| 写法 | 是否合法 | 原因 |
|---|---|---|
| `static const int sV = 50;` | ✅ 合法 | C++11(1z) 规定：**只有 const 且为整型**的静态数据成员才允许类内初始化 |
| `static int mK = 60;` | ❌ 非法 | 缺少 const，静态数据成员默认要在类外单独定义和初始化 |
| `static const float scvv = 2.5;` | ❌ 非法 | 虽然是 const，但不是整型（是float），不满足"整型"条件 |

> 记忆口诀：**"静态成员想在类内直接赋初值，必须同时满足 const + 整型"**，否则一律要在类外定义（例如 `int A::mK = 60;` 写在 .cpp 文件里）。

### 6.4.2 成员函数——行为的抽象和表示

成员函数就是把 6.1 节中抽象出来的"操作/行为"，用 C++ 语法具体写出来。

**例1：双向整数链表 IntList**

```cpp
class IntList {
public:
    void add(int n);            // 从后添加整数
    void preAdd(int n);         // 从前添加整数
    int  at(int pos) const;     // 取得某个位置的整数
    void setInt(int pos, int n);// 设置某个位置的整数
    ...
};
```

**例2：模拟赛车 Car**

```cpp
class Car {
public:
    void start();
    void speedUp();
    void speedDown();
    void shiftGear(int gear);
    void brake();
    void hit(Car & otherCar);   // 撞车：注意参数是另一个Car对象的引用
private:
    ....
};
```

**例3：分油问题中的 Bottle 类（综合练习）**

题目：有10斤、7斤、3斤三个油瓶，10斤瓶初始是满的，要求把油平分成两个5斤。要求先定义 Bottle 类。

```cpp
class Bottle {
public:
    Bottle(int maxCapacity, int iniUsed);  // 构造：容量、初始使用量
    void pour(Bottle & other);              // 把油倒向另一个瓶子
    int  getUsed() const;                   // 获取当前使用量
private:
    const int mCapacity;  // 最大容量（一旦确定不能改，故用const）
    int mUsed;             // 当前使用量（会随倒油操作改变）
};
```

> 这个例子非常典型：它展示了"如何把一句自然语言描述的问题（分油问题），转化为类的数据成员和成员函数设计"——这正是 6.1 节"抽象"思想在实际编程中的落地应用。

## 6.5 类和对象

### 是什么
- **类（class）**：是一种类型的定义，好比"图纸"，描述了这一类事物应该有什么数据、能做什么操作。
- **对象（object）**：是类的**实例化结果**，好比按图纸造出来的"实物"。

关键点：
- 一个对象**必然属于某个类型**（有类型才能创造对象）
- 一个类型可以实例化出 **0 个或多个**对象（类只是"图纸"，可以不造，也可以造很多个）

### 生活化例子

| 类（图纸/概念） | 对象（具体实例） |
|---|---|
| 学生 | 张三 |
| 学校 | 计算机学院 |
| 菜单（某道菜的概念） | 清蒸鳜鱼 |
| 书店中"图书"这个概念 | 一本具体的书 |

### 对象的定义（实例化）语法

```cpp
[class] ClassName ObjectName;              // 在栈上创建对象
[class] ClassName * pObj = new ClassName;  // 在堆上创建对象，返回指针
```

### 对象的访问——调用函数 / 发送消息

面向对象编程里，"调用一个对象的成员函数"常被形象地称为"向对象**发送消息**"。有三种访问方式：

```cpp
class My {
public:
    void f(int n);
};

void func(My & aObj) {
    aObj.f(10);       // 通过引用参数访问对象
}

int main() {
    My obj;
    obj.f(20);          // 1. 直接向对象发送消息（用 . 运算符）

    My & obj2 = obj;
    obj2.f(99);          // 2. 向引用对象发送消息（引用是对象的别名，用法与对象本身相同，也用 .）

    My * p1 = &obj;
    p1->f(5);             // 3. 向指针指向的对象发送消息（用 -> 运算符）

    func(obj);    // 传对象本身（会以引用方式传给func）
    func(obj2);   // 传引用，效果和传obj相同
    func(*p1);    // *p1 解引用得到对象本身，再传入
}
```

### 对照表：三种访问方式速查

| 访问方式 | 变量类型 | 使用的运算符 | 例子 |
|---|---|---|---|
| 直接访问 | `My obj;` | `.` | `obj.f(20);` |
| 引用访问 | `My & obj2 = obj;` | `.` | `obj2.f(99);` |
| 指针访问 | `My * p1 = &obj;` | `->` | `p1->f(5);` |

> 记忆技巧：**"是不是指针"决定用 `.` 还是 `->`**——普通对象和引用都用点号 `.`；指针必须用箭头 `->`（也可以先解引用 `(*p1).f(5)`，效果相同，但箭头写法更常用）。

### 综合实例：Bottle 类的实例化与调用（分油问题实战）

```cpp
int main() {
    Bottle b10(10,10), b7(7,0), b3(3,0);   // 实例化三个对象
    b10.pour(b7);   // 10斤倒7斤 → (3,7,0)
    b7.pour(b3);    // 7斤倒3斤  → (3,4,3)
    b3.pour(b10);   // 3斤倒10斤 → (6,4,0)
    b7.pour(b3);    // → (6,1,3)
    b3.pour(b10);   // → (9,1,0)
    b7.pour(b3);    // → (9,0,1)
    b10.pour(b7);   // → (2,7,1)
    b7.pour(b3);    // → (2,5,3)
    b3.pour(b10);   // → (5,5,0)   ← 此时10斤瓶和7斤瓶各5斤，问题解决！

    cout << "B10 = " << b10.getUsed() << endl;
    cout << "B7  = " << b7.getUsed()  << endl;
}
```

这个例子很好地展示了：**对象一旦创建出来，就通过反复"发送消息"（调用成员函数）来改变自身状态**，最终解决实际问题。

## 6.6 对象的存储

### 是什么
一个对象在内存中要占用一定的空间，这个空间大小由什么决定？PPT 给出了几个关键结论：

### 决定因素对照表

| 因素 | 是否影响对象大小 |
|---|---|
| 非静态数据成员的**个数、类型** | ✅ **有关**（这是最主要的决定因素） |
| 成员函数的个数 | ❌ 无关（函数代码只存一份，不占用每个对象的空间） |
| 静态数据成员的多少、类型 | ❌ 无关（static 数据属于类，不属于每个对象，全类共享一份） |
| 访问控制（public/private/protected） | ❌ 无关（访问权限只是编译期的检查规则，不影响内存布局） |
| 是否含有虚函数 | ✅ 有关（含虚函数会多出一个"虚函数表指针"，占用额外空间） |
| 编译器的字节对齐（alignment）设置 | ✅ 有关（编译器可能会为了对齐而填充额外的字节） |

### 例子

```cpp
class A {
public:
    void f();          // 成员函数，不占对象空间
    int mV1;            // 占对象空间
private:
    int g();             // 成员函数，不占对象空间
    int mV2;               // 占对象空间
    char mC;                 // 占对象空间
    int mva[2];                // 占对象空间
    Person mPerson;              // 占对象空间（Person对象整体嵌入）
    Car * mpCar;                   // 占对象空间（指针大小固定）
    Person & mObj;                   // 占对象空间（引用底层实现类似指针，不推荐用）
    static int sNum;                   // 不占对象空间（属于类，全类共享）
};
```

**唯一恒定的结论：一个对象的大小一定非0**（即使一个类没有任何数据成员，C++ 也会给对象分配至少1字节，以保证每个对象都有独立的地址）。

## 本章小结

1. **抽象数据类型（ADT）** = 数学模型 + 操作集合；同一实体因关注点不同可以有多种不同的抽象结果，抽象没有唯一答案。
2. C++ 用 **`class`** 来表示类型的抽象：ADT 中的"数据"对应**数据成员**，ADT 中的"操作/行为"对应**成员函数**。
3. 类定义的基本语法是 `class <类名> { ... };`（注意结尾分号），类通常放在头文件中。
4. 头文件必须使用**包含警戒**（`#ifndef/#define/#endif`）防止重复定义；当类之间只需要用到指针/引用而非完整对象时，应优先使用**前置声明**（`class Xxx;`）来防止循环包含、降低文件依赖。
5. 数据成员可以是普通类型、enum、const、static 类型；**类不能递归包含自身对象，但可以包含自身指针**；static 数据成员只有同时满足 **const + 整型**才能在类内直接初始化。
6. **对象是类的实例化结果**：一个对象总有类型，一个类型可以实例化 0 个或多个对象。
7. 对象的访问（发送消息）有三种方式：直接访问用 `.`，引用访问用 `.`，指针访问用 `->`。
8. 对象占用的存储空间主要取决于**非静态数据成员**的个数和类型，与成员函数个数、静态数据成员、访问控制无关；对象大小**一定非0**；含虚函数或编译器字节对齐设置也会影响对象大小。
