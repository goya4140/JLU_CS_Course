---

## 1. 函数声明

- 格式：`[extern] [调用约定] <返回类型><函数名>(<参数表>) [const];`
- ★★★ **返回类型、缺省参数值都不能作为区分函数的标志**

---

## 2. 函数的缺省参数

| 易错点 | 结论 |
|---|---|
| 仅返回类型不同 | 判为重复定义，不是重载 |
| 缺省值匹配时机 | ★★★ **编译期静态匹配**，不是运行期 |
| 跨文件风险 | 不同 .cpp 对同一函数写不同缺省值 → 各文件按自己看到的声明匹配，结果不一致 |

**例**：a.cpp 中 `func(int n=6)`，调用 `func()` → 预编译替换为 `func(6)`；b.cpp 中若声明 `func(int=8)`，则该文件里 `func()` → `func(8)`。

---

## 3. 函数的调用过程

**流程口诀**：压参数入栈 → call（压返回地址）→ 记录调用现场（保存寄存器）→ 建立局部变量 → 执行/return → 恢复调用现场 → 清栈

- 清栈由谁做 → 看调用约定（见下节）

---

## 4. 调用约定

| 调用约定 | 清栈责任方 | 压栈顺序 | 函数名内部表示 |
|---|---|---|---|
| `__cdecl` | 调用者 | 从右至左 | `_MyFuncName` |
| `__stdcall` | 被调用者 | 从右至左 | `MyFuncName` |
| `__pascal` | 被调用者 | 从左到右 | `MYFUNCNAME` |
| `__fastcall` | 被调用者 | 左到右(VC6.0)/右到左(BCB6.0) | `@MyFuncName` |
| `__thiscall` | 调用者 | 从右至左 | `_MyFuncNameXXX` |

★★★ **判断依据**：能处理变参函数（参数个数不固定）→ 必须调用者清栈；只能处理确定参数个数 → 可以被调用者清栈。

---

## 5. 函数重载

### 判定标准（★★★ 高频考点）

| 不能作为区分标志 | 能作为区分标志 |
|---|---|
| 返回值类型 | 参数个数/类型/顺序 |
| 缺省参数 | const成员函数 vs 非const成员函数 |
| 值类型参数的 const（`int` vs `const int`） | 引用/指针参数的 const性（是否可改实参） |

**易混示例**：

| 是否合法 | 示例 |
|---|---|
| ❌ 非法 | `int fun(); void fun();`（仅返回值不同） |
| ❌ 非法 | `int fun(int); int fun(int=5);`（仅缺省参数不同） |
| ❌ 非法 | `int fun(int); int fun(const int);`（值类型const不算区分） |
| ❌ 非法 | `int fun(int*); int fun(int* const);`（指针本身const不算区分） |
| ✅ 合法 | `void fun(); void fun() const;` |
| ✅ 合法 | `int fun1(int); int fun1(int*);`（值 vs 指针） |
| ✅ 合法 | `int fun2(int&); int fun2(const int&);`（引用const性不同） |
| ✅ 合法 | `int fun3(int*); int fun3(const int*);`（指向内容是否可改） |

> ⚠️ PPT原例 `int fun(int); int fun(int&);` 按C++标准实为二义性错误，注意结合具体题目语境判断。

### 名字重整（Name Mangling）

- 编译器给重载函数生成带参数信息的内部名字，用于区分
- ★★★ `extern "C"` **关闭名字重整** → 其内部**禁止函数重载**

---

## 6. 函数的参数表

- 声明中的参数表（函数原型）与定义中的参数表是两回事
- ★★★ **缺省参数应写在函数原型（声明）中**
- 定义中的形参**可以不起名字**

---

## 7. 实参与形参的匹配

### 7.1 求值顺序

- 压栈顺序由调用约定确定，但★★★ **多个实参表达式的求值顺序不确定**
- 避免 `f(++a,++a,++a)` 这类同一变量被多次修改的写法

### 7.2 缺省参数匹配

1. 编译时匹配
2. ★★★ **第一个带缺省值的参数，其右侧所有参数也必须有缺省值**（不能中间断档）

| 非法 | 正确 |
|---|---|
| `void f(int, char='c', int);` | `void f(int, char='c', int=9);` |

### 7.3 类型转换

- 先找精确匹配，找不到再尝试隐式转换，且**每个参数只转换一次**

### 7.4 传递方式的 const 规则（★★★ 核心考点）

| 传递方式 | 匹配规则 |
|---|---|
| 值传递 | const/非const 实参都能传给 const 或非const 值形参（反正是拷贝） |
| 指针传递 | 非const指针可传给const指针形参（降级安全）；**const指针不能传给非const指针形参** |
| 数组传递 | 退化为指针；`[3]`、`[5]` 等数字**不做长度检查**，不带长度信息 |
| 引用传递 | 见下表 |

**引用传递匹配表**（设 `int a=1; const int& b=a; const int c=2;`）：

| 重载声明 | 能匹配的调用 |
|---|---|
| `void f(int, int);` | `f(a,a) f(a,b) f(a,c) f(a,3)` |
| `void f(int&, int&);` | `f(a,a) f(a,b) f(a,c) f(a,3)` |
| `void f(int, const int&);` | 以上 + `f(b,3)` |
| `void f(int&, const int&);` | 以上 + `f(b,b)` |
| `void f(const int&, const int&);` | 以上 + `f(3,3)` |

★★★ **记忆口诀**：`const T&`（或按值）几乎能接受一切（变量/常量/字面量/临时对象）；非const引用 `T&` 只能接受左值，且不能是const或字面量。

---

## 8. 函数的返回（★★★ 核心考点）

| 返回方式 | 规则 |
|---|---|
| 按值返回内置类型 | 结果自动带 const：`unsigned int f();` 等价于 `const unsigned int f();` |
| 返回指针 | `T* f();` 等价于 `T* const f();`，**不等价于** `const T* f();` |
| 返回引用 | `T& f();` **不等价于** `const T& f();`；必须返回**有效对象**的引用 |

### 返回引用的安全性判断

★★★ **口诀**：函数结束后，被引用的对象还在不在？
- 全局变量、static局部变量、外部传入的引用/指针指向的对象 → ✅ 安全
- 普通局部变量（非static）→ ❌ 危险（悬空引用）

### max2 系列对照（返回引用的经典例子）

```cpp
int max21(int a,int b)                        { return a>b?a:b; }
int& max22(int& a,int& b)                     { return a>b?a:b; }
const int& max23(int& a,int& b)               { return a>b?a:b; }
const int& max24(const int& a,const int& b)   { return a>b?a:b; }
```

| 版本 | 形参能否传字面量/const | 返回结果能否被赋值 |
|---|---|---|
| max21 (按值) | 都行（拷贝） | 不能（值不是左值） |
| max22 (T&, 返回T&) | 只能传左值、非const | ✅ 能：`max22(a,b)=5;` |
| max23 (T&, 返回const T&) | 只能传左值、非const | ❌ 不能：`max23(a,b)=6;` 错误 |
| max24 (const T&, 返回const T&) | 都行（含字面量） | ❌ 不能：`max24(a,b)=7;` 错误 |

## 三、考前速记 Checklist

- [ ] 返回类型、缺省参数值 —— **不能**用于区分函数（声明/重载均适用）
- [ ] 缺省参数是**编译期**匹配，注意跨文件不一致的坑
- [ ] 调用约定判断依据：能处理变参 → 调用者清栈；确定参数个数 → 被调用者可清栈
- [ ] 重载合法性：个数/类型/顺序/const成员/引用指针const性 → 能区分；返回值/缺省值/值类型const → 不能区分
- [ ] `extern "C"` 关闭名字重整，内部不能重载
- [ ] 缺省参数应写在**声明**里；第一个有缺省值的参数右侧必须全部有缺省值
- [ ] 多实参表达式的**求值顺序不确定**，避免同变量多次自增/自减
- [ ] 值传递：const/非const 随便传；指针/引用传递：非const可降级传const，反之不行
- [ ] 数组传参退化为指针，长度不检查
- [ ] 引用传递匹配表：`const T&`几乎全能匹配，非const `T&`只认左值
- [ ] 按值返回内置类型自动带const；`T* f()`≠`const T* f()`；`T& f()`≠`const T& f()`
- [ ] 返回引用绝不能是**非static局部变量**；全局变量/static局部变量/外部传入引用可以安全返回
- [ ] max2系列：形参是否为const决定能传什么实参；返回类型是否为const决定调用结果能否被赋值
