## 一、转换函数 ★★★

| 类型 | 定义位置 | 语法 | 方向 |
|---|---|---|---|
| 转换构造函数 | 目标类型类中 | 单参构造函数（其余参数有默认值） | 别的类型 → 本类 |
| 转换运算符 | 源类型类中 | `operator DestType() [const]` | 本类 → 别的类型 |

**易错点 ★★★：`explicit` 的隐式调用规则**
- `explicit` 修饰的转换函数**只能显式调用**（`(float)fra` / `float(fra)`），不能被编译器隐式选用。
- 若一个类同时有隐式的 `operator int()` 和 `explicit operator float()`，传参给 `float` 形参时：
  - 编译器**不会**用 explicit 的 float 版本，而是先隐式调 `operator int()` 转成 int，再自动提升为 float。
  - 例：`b.useFloat(fra)` → 走 int 路径，输出 **1**（不是 1.5）；`b.useFloat((float)fra)` 才输出 1.5。

**判断依据**：看是否加了 `explicit`——没加 = 参与隐式转换选择；加了 = 只能显式调用。

**其它规则**：
- 转换函数必须有 `return`；
- 一个类可以有多个转换运算符，只要目标类型不同；
- class ↔ class 转换要避免二义性（两条路径都行不通判断时会报错）。

## 二、名字空间 ★★★

| 概念 | 要点 |
|---|---|
| 命名冲突起因 | 多文件/多人代码用了相同的函数名/类名，不加隔离直接编译报错 |
| namespace 解决方式 | `namespace X { ... }` 包裹，引用时 `X::name` |
| `::` 全局作用域符 | `::name` 表示"去全局空间找"，常用于被局部同名变量遮蔽时 |
| 嵌套命名空间 | `my::my1::efg`，逐层 `::` |
| 同一命名空间可分多处书写 | 编译器自动合并（标准库大量使用此特性） |
| 别名 | `namespace me = my;` 之后 `me::x` ≡ `my::x` |
| 匿名命名空间 ★★★ | `namespace { ... }`，效果≈C语言 `static` 全局变量：**只在当前文件（翻译单元）内可见**，不同 .cpp 各自独立一份 |

## 三、名字汇入 using ★★★

| 写法 | 引入范围 | 风险 |
|---|---|---|
| `using namespace X;` | X 中**所有**名字 | 易冲突，不建议写在头文件 |
| `using X::name;` | 仅**单个**名字 | 更安全精确 |

**易错点 ★★★**：作用域内已经 `using first::x;` 引入了 x，再 `using second::x;` → **编译错误**（同一作用域二义性冲突，即使 x 类型不同也不行）。

## 四、友员 ★★★

**问题起因**：私有成员默认外部不可访问；friend 是类主动授权的"白名单"机制。

| 友元种类 | 声明写法（写在类内） | 授权范围 |
|---|---|---|
| 自由函数友元 | `friend void Func(A&);` | 该自由函数 |
| 类的某个成员函数友元 | `friend void B::f(A&);` | B 类中该成员函数 |
| 友元类 | `friend class C;` | C 的**全部**成员函数 |
| 嵌套类做友元 | `friend class D;`（D 是自己的嵌套类） | 同上 |

**四条核心性质 ★★★（高频考点）**：
1. 友元的本质都是**友元函数**，**没有友元数据成员**（不能把变量声明成友元）；
2. 友元函数**不是**类的成员（无 this 指针，不受该类访问权限约束本身）；
3. 友元关系**单向**：A 把 B 设为友元 ≠ B 把 A 设为友元；
4. 友元关系**没有传递性**：A 是 B 的友元、B 是 C 的友元 ≠ A 是 C 的友元。

**辩证认识**：局部看破坏封装；全局看因为是"精确授权"而非全public，反而保护了信息。

## 五、嵌套类 ★★★

```cpp
class Outer {
public:
    class InnerPub { ... };   // 公有嵌套类
    void F();
private:
    class InnerPri;           // 私有嵌套类
};
```

| 判断 | 结论 |
|---|---|
| `Outer::InnerPub c1;`（外部代码） | ✅ 合法，InnerPub 在 public 区 |
| `Outer::InnerPri c2;`（外部代码） | ❌ 错误，InnerPri 在 private 区，外部不可见 |
| 类外定义嵌套类成员 | 需要完整限定名：`Outer::InnerPub::F1()` |

**互访规则 ★★★（易混淆点）**：
- 嵌套类的成员函数 **可以** 访问外围类的**私有**成员；
- 外围类的成员函数 **不能** 访问嵌套类的**私有**成员（除非该成员是 public，或显式声明友元关系）。
- 判断依据：嵌套类被视为外围类的"成员"享有其访问权，但反过来不成立——嵌套类对外围类而言只是普通类。

**使用意义**：封装归属关系 + 一定程度隐藏嵌套类，避免污染外部命名空间。

## 六、流

| 对比项 | `"\n"` | `endl` |
|---|---|---|
| 本质 | 普通换行字符 | 换行 + 强制刷新缓冲区 |
| 性能 | 快 | 慢（每次都flush） |
| 适用场景 | 大量/循环输出 ★★★ | 需要立即看到输出（如调试打印、崩溃前信息） |

- `istream`（`cin`）负责输入，`ostream`（`cout`）负责输出；
- 文件流：二进制方式 = 字节流；文本方式 = 字符流。
