# 04_3 线索二叉树

含 $n$ 个结点的二叉链表共有 $2n$ 个孩子指针，而边只有 $n-1$ 条，因此有 $n+1$ 个空指针。线索二叉树利用这些空位保存某种遍历次序下的前驱和后继。

## 结点与标志

```cpp
struct ThreadNode {
    int value;
    ThreadNode* left;
    ThreadNode* right;
    bool leftIsThread;
    bool rightIsThread;
};
```

标志不可省略：`left` 可能指向真正的左孩子，也可能指向遍历前驱。访问孩子前必须先判断指针的含义。

## 中序线索化

中序遍历的访问次序为“左子树—根—右子树”。遍历时维护 `previous`，表示刚访问的结点：

- 当前结点没有左孩子时，把 `left` 指向 `previous`，作为中序前驱。
- `previous` 没有右孩子时，把它的 `right` 指向当前结点，作为中序后继。

每个结点处理一次，时间为 $O(n)$，递归版本的辅助空间为 $O(h)$。

## 不使用栈的中序遍历

从根开始不断沿真正的左孩子走到最左结点。访问结点后：若右指针是线索，就直接到后继；若右指针是孩子，就进入右子树并再次寻找其最左结点。

```text
p = leftmost(root)
while p != null:
    visit(p)
    if p.rightIsThread: p = p.right
    else: p = leftmost(p.right)
```

遍历总时间仍为 $O(n)$，但不再需要递归栈。

## 代价与适用场景

线索提高了按固定次序找前驱、后继的效率，但修改树时必须同步维护线索和标志。若结构频繁更新，维护成本可能高于收益；若树较稳定且经常顺序遍历，线索化更有价值。

线索依赖具体遍历次序。“中序线索”不能直接当作“先序后继”，这是理解和实现时最重要的边界。
