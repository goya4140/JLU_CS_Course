# 04_7 哈夫曼树与编码

若字符出现频率不同，用相同位数编码每个字符会浪费空间。前缀编码要求任何字符的码字都不是另一字符码字的前缀，因此可以从左到右唯一解码。哈夫曼树在已知权重时构造带权路径长度最小的前缀编码。

## 带权路径长度

叶结点 $i$ 的权重为 $w_i$，深度为 $d_i$，整棵树的带权路径长度为

$$WPL=\sum_i w_i d_i.$$

频率高的字符应靠近根，频率低的字符可以更深。

## 贪心构造

1. 每个权重建立一棵单结点树。
2. 反复取出根权重最小的两棵树。
3. 建立新根，把它们作为左右子树，新根权重为二者之和。
4. 将新树放回集合，直到只剩一棵树。

用最小堆维护候选树时，共执行 $n-1$ 次合并，时间为 $O(n\log n)$。

```cpp
while (heap.size() > 1) {
    Node* a = heap.top(); heap.pop();
    Node* b = heap.top(); heap.pop();
    heap.push(new Node(a->weight + b->weight, a, b));
}
```

每次合并会使两棵被选子树中的所有叶深度增加 1，因此增加的代价恰是两棵树的总权重。优先合并最小权重可把新增代价控制到最小，这一局部选择可递归形成全局最优结构。

## 编码与解码

约定左边为 `0`、右边为 `1`，从根到叶的路径就是该字符码字。编码时查表拼接码字；解码时从根按比特移动，抵达叶结点便输出字符并回到根。

只有叶结点代表字符，所以不会在一个字符码字尚未结束时误认出另一个字符，这正是前缀性质。

## 并列权重

相同权重可能产生不同形状和不同码字，但最小带权路径长度相同。若编码结果需要跨系统稳定复现，还要额外规定并列时的排序规则，或采用规范哈夫曼编码。
