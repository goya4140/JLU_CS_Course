# 04_8 表达式树与并查集

树不仅描述层次，也可以承载计算过程或集合关系。本页展示两种方向不同的应用：表达式树从叶到根求值，并查集则用森林维护不断合并的分组。

## 表达式树

表达式树的叶结点是操作数，内部结点是运算符。中序遍历对应中缀形式，后序遍历对应后缀形式；对树做后序求值，能保证运算符在两个操作数之后执行。

从后缀表达式构造时，扫描每个符号：操作数建立单结点树并入栈；二元运算符弹出右、左两棵子树，建立新根后重新入栈。最终栈中唯一的树就是完整表达式。

```text
for token in postfix:
    if operand: push(new leaf(token))
    else:
        right = pop(); left = pop()
        push(new operator(token, left, right))
```

弹出顺序不能交换，因为减法和除法不满足交换律。

## 并查集的森林

并查集维护若干互不相交集合，支持：创建单元素集合、查找元素所属集合的代表、合并两个集合。每个集合用一棵父指针树表示，根作为代表。

```cpp
int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}
```

路径压缩在查找根后，让路径上的结点直接指向根。按秩合并则总把较浅的树挂到较深的树下。这两个策略共同使用时，连续操作的均摊代价非常接近常数。

## 不变量与应用

每个元素沿父指针最终到达唯一根；两个元素属于同一集合，当且仅当它们的根相同。合并只改变一个根的父指针，不会拆散已有集合。

并查集适合处理动态连通性、等价类和 Kruskal 算法中的环判断。它能快速回答“是否属于同一组”，但不保存两点间的具体路径；需要路径信息时仍应使用图结构。
