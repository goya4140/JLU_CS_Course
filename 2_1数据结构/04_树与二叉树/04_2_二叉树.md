# 04_2 二叉树

## 二叉树的定义

**二叉树**是 $n$（$n \geq 0$）个结点的有限集合。当 $n = 0$ 时称为**空二叉树**；当 $n > 0$ 时，它由一个根结点和两棵互不相交的、分别称为左子树和右子树的二叉树组成。

二叉树的五种基本形态：

```
(1) 空树    (2) 只有根    (3) 根+左子树    (4) 根+右子树    (5) 根+左右子树

   ∅           ○              ○                ○                 ○
              /              \               / \
             ○                ○             ○   ○
```

## 二叉树的性质

### 性质 1：第 $i$ 层最多有 $2^{i-1}$ 个结点

```
第 1 层：最多 1 = 2⁰ 个
第 2 层：最多 2 = 2¹ 个
第 3 层：最多 4 = 2² 个
...
```

### 性质 2：深度为 $k$ 的二叉树最多有 $2^k - 1$ 个结点

这是性质 1 的求和：$1 + 2 + 4 + \cdots + 2^{k-1} = 2^k - 1$

### 性质 3：叶子结点数 = 度为 2 的结点数 + 1

设 $n_0$ 为叶子结点数，$n_1$ 为度为 1 的结点数，$n_2$ 为度为 2 的结点数。

- 总结点数：$n = n_0 + n_1 + n_2$
- 分支数：$n - 1 = n_1 + 2n_2$（每个结点有一个父结点，除了根）

联立得：$n_0 = n_2 + 1$

### 性质 4：完全二叉树的深度

具有 $n$ 个结点的完全二叉树的深度为 $\lfloor \log_2 n \rfloor + 1$。

## 特殊二叉树

### 满二叉树

深度为 $k$ 且有 $2^k - 1$ 个结点的二叉树。每一层都"满"了。

```
        ○
       / \
      ○   ○
     / \ / \
    ○  ○○  ○
```

### 完全二叉树

深度为 $k$ 的二叉树，前 $k-1$ 层是满的，第 $k$ 层的结点都集中在左侧。

```
满二叉树：              完全二叉树：            非完全二叉树：

      ○                     ○                       ○
     / \                   / \                     / \
    ○   ○                 ○   ○                   ○   ○
   / \ / \               / \  /                  /    /
  ○  ○○  ○             ○  ○ ○                 ○    ○
```

**完全二叉树的重要性**：可以用顺序存储高效表示，支持快速定位父结点和子结点。

## 二叉树的存储结构

### 顺序存储

按完全二叉树的编号顺序，将结点依次存入数组。

```
数组下标 i 的结点：
  - 父结点下标：⌊i/2⌋
  - 左孩子下标：2i
  - 右孩子下标：2i + 1
```

```cpp
// 顺序存储二叉树（下标从 1 开始，0 位置闲置）
template <typename T>
class SeqBinaryTree {
private:
    T* data;
    int capacity;
    int n;  // 结点数

public:
    explicit SeqBinaryTree(int cap) : capacity(cap), n(0) {
        data = new T[cap + 1];  // 下标 0 不用
    }
    
    bool add(const T& e) {
        if (n >= capacity) return false;
        data[++n] = e;
        return true;
    }
    
    T getParent(int i) const {
        if (i <= 1 || i > n) throw std::out_of_range("越界");
        return data[i / 2];
    }
    
    T getLeftChild(int i) const {
        if (2 * i > n) throw std::out_of_range("无左孩子");
        return data[2 * i];
    }
    
    T getRightChild(int i) const {
        if (2 * i + 1 > n) throw std::out_of_range("无右孩子");
        return data[2 * i + 1];
    }
};
```

**优点**：存储紧凑，父子结点关系通过计算得到，不需要额外空间。

**缺点**：对于非完全二叉树，需要用虚拟结点填充，造成空间浪费。

### 链式存储

每个结点包含数据域和左右孩子指针。

```cpp
template <typename T>
struct BiTNode {
    T data;
    BiTNode<T>* lchild;
    BiTNode<T>* rchild;
    BiTNode(const T& val) : data(val), lchild(nullptr), rchild(nullptr) {}
};
```

```
      [A|*|*]
       /   \
      ↓     ↓
  [B|*|*]  [C|*|*]
   /   \
  ↓     ↓
[D|/|/] [E|/|/]
```

链式存储是最常用的二叉树存储方式，n 个结点的二叉链表有 $n+1$ 个空指针域。

## 二叉树的遍历

**遍历**是指按某种顺序访问二叉树中的每个结点，且每个结点只访问一次。

### 递归遍历框架

```cpp
// 前序遍历：根 -> 左 -> 右
void preOrder(BiTNode<T>* node) {
    if (!node) return;
    visit(node);           // 访问根
    preOrder(node->lchild); // 遍历左
    preOrder(node->rchild); // 遍历右
}

// 中序遍历：左 -> 根 -> 右
void inOrder(BiTNode<T>* node) {
    if (!node) return;
    inOrder(node->lchild);
    visit(node);
    inOrder(node->rchild);
}

// 后序遍历：左 -> 右 -> 根
void postOrder(BiTNode<T>* node) {
    if (!node) return;
    postOrder(node->lchild);
    postOrder(node->rchild);
    visit(node);
}
```

### 遍历示例

```
        1
       / \
      2   3
     / \   \
    4   5   6
```

| 遍历方式 | 序列 |
|---|---|
| 前序 | 1, 2, 4, 5, 3, 6 |
| 中序 | 4, 2, 5, 1, 3, 6 |
| 后序 | 4, 5, 2, 6, 3, 1 |

### 递归遍历的本质

递归遍历的核心是**分治思想**：

```
遍历(树) = 处理(根) + 遍历(左子树) + 遍历(右子树)
```

三种遍历的区别仅在于"处理根"的步骤放在哪里：
- 前序：先处理根，再处理子树
- 中序：先处理左子树，再处理根，再处理右子树
- 后序：先处理子树，最后处理根

### 非递归遍历（借助栈）

递归遍历虽然简洁，但函数调用有开销，且深度大时可能栈溢出。可以用显式栈改写为非递归版本。

**中序遍历非递归实现**：

```cpp
void inOrderNonRec(BiTNode<T>* root) {
    std::stack<BiTNode<T>*> s;
    BiTNode<T>* p = root;
    
    while (p || !s.empty()) {
        if (p) {
            s.push(p);          // 根入栈
            p = p->lchild;      // 向左走
        } else {
            p = s.top(); s.pop(); // 弹出栈顶
            visit(p);            // 访问
            p = p->rchild;       // 转向右子树
        }
    }
}
```

**理解**：一路向左，把经过的结点全部入栈。当无法继续左走时，弹出栈顶（此时该结点的左子树已处理完），访问它，然后转向右子树。

### 层次遍历（借助队列）

按从上到下、从左到右的顺序访问结点。

```cpp
void levelOrder(BiTNode<T>* root) {
    if (!root) return;
    std::queue<BiTNode<T>*> q;
    q.push(root);
    
    while (!q.empty()) {
        BiTNode<T>* node = q.front(); q.pop();
        visit(node);
        if (node->lchild) q.push(node->lchild);
        if (node->rchild) q.push(node->rchild);
    }
}
```

## 由遍历序列恢复二叉树

### 前序 + 中序 → 二叉树

**原理**：前序的第一个元素是根；在中序中找到根的位置，左边是左子树，右边是右子树。递归构造。

```
前序：A B D E C F
中序：D B E A F C

根 = A
中序中 A 左边 "D B E" 是左子树，右边 "F C" 是右子树

前序中：B D E 对应左子树，C F 对应右子树
递归构造...
```

### 后序 + 中序 → 二叉树

**原理**：后序的最后一个元素是根，其余同理。

### 前序 + 后序？

**不能唯一确定**。例如单支树（每个结点只有左孩子或只有右孩子），前序和后序相同。

```
    ○        ○
   /          \
  ○            ○
 /              \
○                ○

两棵不同的树，前序都是 [A,B,C]，后序都是 [C,B,A]
```

## 遍历的时间复杂度

无论递归还是非递归，每个结点被访问一次，时间复杂度都是 $O(n)$。

- 递归版本：空间复杂度 $O(h)$（$h$ 为树高，递归栈深度）
- 非递归版本：空间复杂度 $O(h)$（显式栈/队列的最大长度）

## 小结

- 二叉树是每个结点最多有两个孩子的树结构。
- 二叉树的五种形态：空、只有根、根+左、根+右、根+左右。
- **性质 3**（$n_0 = n_2 + 1$）在计算题中经常用到。
- 存储方式：顺序存储适合完全二叉树，链式存储最通用。
- 遍历是二叉树的核心操作，递归实现简洁，非递归实现更可控。
- **前序+中序**或**后序+中序**可以唯一恢复二叉树。
