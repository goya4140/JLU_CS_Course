# 数据结构

> 理解数据的组织方式，掌握算法的设计与分析。

> [试读 StudyMate 版数据结构样例](../study-mate-数据结构/index.html)：链表、Dijkstra 最短路径与快速排序三节课，可与下方完整自学笔记对照。

## 课程定位

这是一套完全以**理解和学习**为目的的数据结构自学资料，面向零基础或基础薄弱的学习者。

课程目标是帮助你真正理解每种数据结构**为什么存在**、**如何工作**、**在什么场景下适用**，并能够独立阅读、调试和实现相关代码。

## 适合人群

- 正在学习数据结构课程，希望深入理解而非死记结论的学生
- 已完成 C++ 程序设计基础，希望巩固编程与算法思维的学习者
- 准备学习操作系统、数据库、编译原理等后续课程，需要补齐数据结构基础的同学

## 先修知识

- **C++ 程序设计基础**：变量、函数、数组、指针、引用、类与对象
- **基本数学素养**：对数、指数、求和符号、简单递推关系
- **离散数学 I**（有帮助但非必需）：集合、关系、映射、图的基本概念

## 推荐使用方式

### 第一次学习

1. 先阅读[00_课程导览](00_课程导览.md)，了解数据结构课程解决什么问题，以及各章节的依赖关系。
2. 按章节顺序阅读，每个知识点按照"问题背景 → 抽象数据类型 → 存储实现 → 核心操作 → 复杂度分析"的逻辑展开。
3. 配合 `code/` 目录下的 C++ 参考实现，在本地编译运行，单步调试观察算法执行过程。
4. 遇到排序、查找、图遍历等章节时，使用页面内嵌的交互式演示观察算法的完整运行过程。

### 复习与查缺补漏

1. 通过左侧目录或页面搜索定位具体知识点。
2. 查看知识正文中的例题和示意图，快速回顾核心思想。
3. 回到对应代码文件，重新运行和调试以加深印象。

## 代码与交互演示

### 代码

各章 `code/` 目录包含该章知识点的 C++ 参考实现：

- 代码使用现代、清晰的 C++ 风格，命名准确，注释完整。
- 每个文件可独立编译运行，明确处理了空结构、越界等边界情况。
- 代码分为"数据结构实现"和"使用示例"两部分，便于对照阅读。

**编译示例：**

```bash
cd 02_线性表栈与队列/code
g++ -std=c++17 -o linked_list linked_list.cpp && ./linked_list
```

### 交互式演示

部分章节（排序、查找、图遍历、树遍历）内嵌了基于浏览器的交互式可视化组件：

- 支持**上一步 / 下一步**逐步观察算法执行
- 支持**播放 / 暂停**自动演示，可调整播放速度
- 实时显示当前数据状态、正在执行的伪代码行和本步骤的文字解释

交互组件直接嵌入在知识正文中，与讲解内容紧密结合，不作为独立章节存在。
