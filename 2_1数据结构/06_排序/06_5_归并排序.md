# 06_5 归并排序

归并排序把数组分成两半，分别排好后再线性合并。它的关键操作不是交换，而是利用两个子数组已经有序这一不变量。

## 合并

两个指针分别指向左右有序段的首个未处理元素。每次把较小者复制到辅助数组；一侧耗尽后复制另一侧剩余元素。

若相等时优先取左侧元素，原相对次序得以保持，因此归并排序稳定。合并长度为 $n$ 的两段需要 $O(n)$ 时间。

## 递归结构

递推式为

$$T(n)=2T(n/2)+O(n),$$

共有 $O(\log n)$ 层，每层合并总工作量为 $O(n)$，所以总时间始终为 $O(n\log n)$。数组实现通常需要 $O(n)$ 辅助空间；链表归并可通过改接指针降低额外空间。

## 自底向上实现

也可以先合并长度 1 的相邻段，再合并长度 2、4、8 的段。迭代版本避免递归栈，并适合按块处理数据。

```text
width = 1
while width < n:
    merge every adjacent pair of runs of length width
    width *= 2
```

## 外排序

当数据无法全部装入内存时，可分块读入、在内存中分别排序形成有序段，再进行多路归并。归并过程以顺序读写为主，能有效减少昂贵的随机外存访问。

归并排序提供稳定的最坏情况保证，代价是数组版本需要线性辅助空间。它也是“分解—递归解决—合并结果”这一分治模式的典型实例。
