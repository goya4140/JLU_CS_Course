# 06_2 插入类排序

## 排序的基本概念

**排序**是将一组数据按某个关键字的大小，重新排列成递增（或递减）序列的操作。

**稳定性**：如果排序前 $a_i$ 在 $a_j$ 之前，且 $a_i.key = a_j.key$，排序后 $a_i$ 仍然在 $a_j$ 之前，则称该排序是**稳定的**。

> 稳定性的意义：当按多个关键字排序时（如先按年龄、再按姓名），稳定性保证第一次排序的结果不会被第二次排序破坏。

## 插入排序的思想

插入排序的核心思想类似于打扑克牌时整理手牌：

> 每次从无序区取一个元素，插入到有序区的合适位置，使有序区始终保持有序。

```
初始: [3] | 1 4 1 5 9 2 6    无序区
      有序

第 1 步: [1 3] | 4 1 5 9 2 6   取 1，插入到 3 前面

第 2 步: [1 3 4] | 1 5 9 2 6   取 4，插入到 3 后面

第 3 步: [1 1 3 4] | 5 9 2 6   取 1，插入到 1 后面

...
```

## 直接插入排序

### 算法步骤

1. 认为第 1 个元素是有序区
2. 从第 2 个元素开始，依次将每个元素插入到前面有序区的正确位置
3. 插入时，从有序区尾部向前比较，找到插入位置，将比它大的元素后移

### 代码实现

```cpp
void insertSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];        // 待插入元素
        int j = i - 1;
        
        // 将比 key 大的元素后移
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        
        a[j + 1] = key;        // 插入到正确位置
    }
}
```

### 手动模拟

```
数组: [3, 1, 4, 1, 5]

i=1, key=1:
  j=0, a[0]=3 > 1, 后移: [3, 3, 4, 1, 5]
  j=-1, 结束
  插入到 j+1=0: [1, 3, 4, 1, 5]

i=2, key=4:
  j=1, a[1]=3 < 4, 不后移
  插入到 j+1=2: [1, 3, 4, 1, 5]（不变）

i=3, key=1:
  j=2, a[2]=4 > 1, 后移: [1, 3, 4, 4, 5]
  j=1, a[1]=3 > 1, 后移: [1, 3, 3, 4, 5]
  j=0, a[0]=1 == 1, 不后移（稳定性）
  插入到 j+1=1: [1, 1, 3, 4, 5]

i=4, key=5:
  j=3, a[3]=4 < 5, 不后移
  插入到 j+1=4: [1, 1, 3, 4, 5]（不变）
```

### 复杂度分析

| 情况 | 比较次数 | 移动次数 | 时间复杂度 |
|---|---|---|---|
| 最好（已有序） | $n - 1$ | $0$ | $O(n)$ |
| 最坏（逆序） | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$ | $O(n^2)$ |
| 平均 | $\frac{n^2}{4}$ | $\frac{n^2}{4}$ | $O(n^2)$ |

**空间复杂度**：$O(1)$（原地排序）

**稳定性**：✅ 稳定。当 $a[j] > key$ 时才后移，相等时不移动，保持了相对顺序。

## 折半插入排序

直接插入排序中，查找插入位置的过程是从后往前顺序查找。由于前面的元素已经有序，可以用**二分查找**来定位插入位置。

### 算法步骤

1. 用二分查找在有序区中找到插入位置
2. 将插入位置之后的元素统一后移
3. 放入待插入元素

```cpp
void binaryInsertSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        
        // 二分查找插入位置
        int left = 0, right = i - 1;
        while (left <= right) {
            int mid = (left + right) / 2;
            if (a[mid] > key) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        
        // left 就是插入位置
        // 将 [left, i-1] 的元素后移
        for (int j = i - 1; j >= left; j--) {
            a[j + 1] = a[j];
        }
        a[left] = key;
    }
}
```

### 复杂度分析

- **比较次数**：$O(n \log n)$（二分查找减少了比较次数）
- **移动次数**：与直接插入相同，$O(n^2)$
- **总时间复杂度**：仍为 $O(n^2)$（移动操作占主导）

折半插入排序在**比较操作代价较高**的场景（如数据量大、比较复杂的对象）有一定优势，但整体提升有限。

## 希尔排序（Shell Sort）

### 基本思想

希尔排序是插入排序的改进版。它发现插入排序在**元素基本有序**时效率很高（$O(n)$），于是试图通过预处理让数组"大致有序"，再用插入排序收尾。

**方法**：先将整个待排序序列分割成若干**子序列**，分别进行直接插入排序。子序列的间隔（增量）逐渐缩小，最后当增量为 1 时，整个序列已基本有序，此时直接插入排序的效率接近 $O(n)$。

### 算法步骤

1. 选择一个增量序列 $d_1, d_2, \cdots, d_k$，其中 $d_k = 1$
2. 对每个增量 $d_i$，将序列分成 $d_i$ 个子序列，对每个子序列进行插入排序
3. 重复直到增量为 1

### 代码实现

```cpp
void shellSort(int a[], int n) {
    // 增量序列：n/2, n/4, ..., 1
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个子序列进行插入排序
        for (int i = gap; i < n; i++) {
            int key = a[i];
            int j = i - gap;
            
            while (j >= 0 && a[j] > key) {
                a[j + gap] = a[j];
                j -= gap;
            }
            
            a[j + gap] = key;
        }
    }
}
```

### 手动模拟

```
数组: [9, 1, 5, 8, 3, 7, 4, 6, 2]

gap = 4:
  子序列 0: [9, 3, 2] → 排序后 [2, 3, 9]
  子序列 1: [1, 7]    → 排序后 [1, 7]
  子序列 2: [5, 4]    → 排序后 [4, 5]
  子序列 3: [8, 6]    → 排序后 [6, 8]
  结果: [2, 1, 4, 6, 3, 7, 5, 8, 9]

gap = 2:
  子序列 0: [2, 4, 3, 5, 9] → [2, 3, 4, 5, 9]
  子序列 1: [1, 6, 7, 8]    → [1, 6, 7, 8]
  结果: [2, 1, 3, 6, 4, 7, 5, 8, 9]

gap = 1:
  直接插入排序: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

### 复杂度分析

希尔排序的时间复杂度与**增量序列的选择**密切相关。

| 增量序列 | 最坏时间复杂度 |
|---|---|
| $n/2, n/4, \cdots, 1$ | $O(n^2)$ |
| $2^k - 1$ | $O(n^{3/2})$ |
| 最优增量序列 | 接近 $O(n \log n)$ |

**空间复杂度**：$O(1)$

**稳定性**：❌ 不稳定。不同子序列的排序可能打乱相等元素的相对顺序。

> 希尔排序的增量序列选择是一个研究课题。实际中，$n/2$ 的简单序列已经能取得不错的效果，更好的序列（如 Sedgewick 增量序列）可以进一步提升性能。

## 三种插入排序的比较

| 特性 | 直接插入 | 折半插入 | 希尔排序 |
|---|---|---|---|
| 时间复杂度 | $O(n^2)$ | $O(n^2)$ | $O(n^{1.3} \sim n^2)$ |
| 空间复杂度 | $O(1)$ | $O(1)$ | $O(1)$ |
| 稳定性 | ✅ 稳定 | ✅ 稳定 | ❌ 不稳定 |
| 适用场景 | 数据量小、基本有序 | 比较代价高 | 中等数据量 |

## 小结

- **插入排序**的核心思想是维护一个有序区，将新元素插入到正确位置。
- **直接插入排序**：简单直观，数据基本有序时效率很高。
- **折半插入排序**：用二分查找减少比较次数，但移动次数不变。
- **希尔排序**：通过增量分组预处理，让数组"大致有序"，最后增量为 1 时直接插入排序效率接近线性。
