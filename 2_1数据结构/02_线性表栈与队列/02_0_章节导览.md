# 02 线性表、栈与队列

## 本章内容概述

线性结构是最基本、最常用的数据组织形式：数据元素之间是**一对一**的线性关系。本章从通用的"线性表"出发，讨论两种存储方式（顺序存储和链式存储），然后在此基础上引入两种受限的线性结构——栈和队列，最后介绍链表中的经典技巧——双指针。

## 学习建议

- **重点理解**：链表指针操作的本质——修改的是引用关系，不是移动数据。插入和删除的关键是找到"前一个结点"。
- **必须掌握**：单链表的插入、删除；栈和队列的基本操作；循环队列的判满/判空条件。
- **代码实现**：`code/` 目录给出各结构的完整实现，可直接编译并用 Valgrind 观察内存所有权是否正确。
