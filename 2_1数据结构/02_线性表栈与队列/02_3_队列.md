# 02_3 队列

## 从问题出发

想象以下场景：

1. **排队买票**：先来的人先买票，后到的人排在队尾。
2. **打印任务调度**：多个用户提交打印任务，打印机按提交顺序依次处理。
3. **树的层次遍历**：从上到下、从左到右逐层访问树的每个结点。

这些场景的共性是：**先进入的元素最先被处理**。这种"先进先出"（FIFO）的结构就是**队列**。

## 队列的定义

**队列**是只允许在一端进行插入、在另一端进行删除的线性表。允许插入的一端称为**队尾**（Rear），允许删除的一端称为**队头**（Front）。

```
    出队 ←                    ← 入队
         ↓                    ↓
    ┌───┬───┬───┬───┬───┐
    │ A │ B │ C │   │   │    入队顺序：A, B, C
    └───┴───┴───┴───┴───┘
      ↑               ↑
    队头(Front)     队尾(Rear)

出队顺序：A, B, C（先进先出）
```

## 队列的 ADT

```text
ADT Queue {
    数据对象：D = {a_i | a_i ∈ ElemSet, i = 1, 2, ..., n, n ≥ 0}
    数据关系：R = {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n}
    
    基本操作：
        InitQueue(&Q)      // 初始化空队列
        DestroyQueue(&Q)   // 销毁队列
        QueueEmpty(Q)      // 判空
        QueueLength(Q)     // 求队列长度
        GetHead(Q, &e)     // 取队头元素（不出队）
        EnQueue(&Q, e)     // 入队
        DeQueue(&Q, &e)    // 出队
        ClearQueue(&Q)     // 清空队列
}
```

## 顺序队列与假溢出

### 简单的顺序队列

用数组 `data[0..MAX-1]` 存储队列，两个指针 `front` 和 `rear` 分别指示队头和队尾。

```cpp
template <typename T>
class SimpleQueue {
private:
    T* data;
    int capacity;
    int front;  // 队头位置
    int rear;   // 队尾位置的下一个位置

public:
    SimpleQueue(int cap = 64) {
        data = new T[cap];
        capacity = cap;
        front = rear = 0;
    }
    
    bool empty() const { return front == rear; }
    
    bool enQueue(const T& e) {
        if (rear >= capacity) return false;  // "满了"
        data[rear++] = e;
        return true;
    }
    
    bool deQueue(T& e) {
        if (empty()) return false;
        e = data[front++];
        return true;
    }
};
```

### 假溢出

上面的实现有一个严重问题：**假溢出**。

```
初始：front=0, rear=0

操作：
  A 入队：front=0, rear=1    [A][_][_][_]
  B 入队：front=0, rear=2    [A][B][_][_]
  A 出队：front=1, rear=2    [_][B][_][_]
  C 入队：front=1, rear=3    [_][B][C][_]
  B 出队：front=2, rear=3    [_][_][C][_]
  D 入队：front=2, rear=4    [_][_][C][D]
  
此时 rear == capacity，无法继续入队！
但数组前面有两个空位——这就是"假溢出"。
```

## 循环队列

解决假溢出的方法是把数组首尾相连，形成**循环队列**。当指针到达数组末尾时，绕回到数组开头。

```
        rear
          ↓
    ┌───┬───┬───┬───┬───┐
    │ D │   │   │ A │ B │    ← rear 绕回数组开头
    └───┴───┴───┴───┴───┘
              ↑
            front
```

指针移动：

```cpp
front = (front + 1) % capacity;
rear = (rear + 1) % capacity;
```

### 循环队列的实现

循环队列需要解决一个关键问题：**如何区分队空和队满？**

| 条件 | front == rear | (rear + 1) % capacity == front |
|---|---|---|
| 含义 | **队空** | **队满**（牺牲一个存储单元） |

**方案：牺牲一个存储单元**。约定 `rear` 指向队尾元素的下一个位置，当 `(rear + 1) % capacity == front` 时认为队列已满。这样队列中最多存储 `capacity - 1` 个元素。

```cpp
template <typename T>
class CircularQueue {
private:
    T* data;
    int capacity;  // 总容量
    int front;     // 队头
    int rear;      // 队尾的下一个位置

public:
    CircularQueue(int cap = 64) {
        data = new T[cap];
        capacity = cap;
        front = rear = 0;
    }
    
    ~CircularQueue() {
        delete[] data;
    }
    
    bool empty() const { return front == rear; }
    
    bool full() const { return (rear + 1) % capacity == front; }
    
    int size() const { return (rear - front + capacity) % capacity; }
    
    bool enQueue(const T& e) {
        if (full()) return false;
        data[rear] = e;
        rear = (rear + 1) % capacity;
        return true;
    }
    
    bool deQueue(T& e) {
        if (empty()) return false;
        e = data[front];
        front = (front + 1) % capacity;
        return true;
    }
    
    bool getHead(T& e) const {
        if (empty()) return false;
        e = data[front];
        return true;
    }
};
```

> **为什么用 `size() const` 中那样的计算？**
> 因为 `rear` 可能小于 `front`（绕圈了），直接相减会得到负数。` (rear - front + capacity) % capacity` 可以正确处理两种情况。

### 另一种方案：设置 size 变量

也可以不牺牲存储单元，额外维护一个 `size` 变量来记录当前元素个数：

```cpp
bool full() const { return size == capacity; }
bool empty() const { return size == 0; }
```

这种方式空间利用率更高，但需要多维护一个变量。

## 链队列

用链表实现队列，在链表尾部入队，在链表头部出队。

```cpp
template <typename T>
class LinkedQueue {
private:
    struct Node {
        T data;
        Node* next;
        Node(const T& val, Node* p = nullptr) : data(val), next(p) {}
    };
    Node* front;   // 队头指针（指向头结点）
    Node* rear;    // 队尾指针
    int count;

public:
    LinkedQueue() : count(0) {
        front = rear = new Node(T());  // 头结点
    }
    
    ~LinkedQueue() {
        while (front) {
            Node* temp = front;
            front = front->next;
            delete temp;
        }
    }
    
    bool empty() const { return front == rear; }  // 或 count == 0
    int size() const { return count; }
    
    void enQueue(const T& e) {
        rear->next = new Node(e);
        rear = rear->next;
        count++;
    }
    
    bool deQueue(T& e) {
        if (empty()) return false;
        Node* temp = front->next;  // 要删除的结点
        e = temp->data;
        front->next = temp->next;
        if (rear == temp) rear = front;  // 最后一个元素被删除
        delete temp;
        count--;
        return true;
    }
    
    bool getHead(T& e) const {
        if (empty()) return false;
        e = front->next->data;
        return true;
    }
};
```

**时间复杂度**：所有操作都是 $O(1)$。

## 双端队列（Deque）

双端队列允许在两端进行插入和删除操作。

```
  入队/出队 ←  ┌───┬───┬───┬───┬───┐  → 入队/出队
               │ A │ B │ C │ D │ E │
               └───┴───┴───┴───┴───┘
```

双端队列结合了栈和队列的特性，是一种更通用的线性结构。C++ STL 中的 `std::deque` 就是双端队列的实现。

## 队列的应用

### 1. 树的层次遍历

使用队列实现二叉树的层次遍历（广度优先）：

```cpp
void levelOrder(TreeNode* root) {
    if (!root) return;
    
    LinkedQueue<TreeNode*> queue;
    queue.enQueue(root);
    
    while (!queue.empty()) {
        TreeNode* node;
        queue.deQueue(node);
        visit(node);  // 访问当前结点
        
        if (node->left) queue.enQueue(node->left);
        if (node->right) queue.enQueue(node->right);
    }
}
```

**原理**：队列保证了每一层的结点按从左到右的顺序被访问。

### 2. 图的广度优先搜索（BFS）

```cpp
void BFS(Graph& g, int start) {
    bool visited[MAX_VERTEX] = {false};
    LinkedQueue<int> queue;
    
    visited[start] = true;
    queue.enQueue(start);
    
    while (!queue.empty()) {
        int v;
        queue.deQueue(v);
        visit(v);
        
        for (int w : g.neighbors(v)) {
            if (!visited[w]) {
                visited[w] = true;
                queue.enQueue(w);
            }
        }
    }
}
```

### 3. 缓冲区与任务调度

操作系统中的进程调度、网络数据包的缓冲、打印任务队列等，都是队列的典型应用。"先来先服务"（FCFS）是最基本的调度策略。

## 小结

- 队列是一种**先进先出**（FIFO）的线性结构，在队尾插入、队头删除。
- 顺序队列需要处理**假溢出**问题，通常使用**循环队列**解决。
- 循环队列区分队空和队满有两种方案：牺牲一个存储单元，或维护 `size` 变量。
- 链队列不存在溢出问题（除非内存不足）。
- 队列的核心应用场景：需要按顺序处理、公平调度的场景（层次遍历、BFS、任务调度）。
