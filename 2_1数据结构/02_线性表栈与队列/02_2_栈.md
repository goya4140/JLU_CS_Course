# 02_2 栈

## 从问题出发

考虑以下几个场景：

1. **浏览器后退功能**：你依次访问了网页 A → B → C → D，点击"后退"时，应该依次回到 C → B → A。
2. **Undo 操作**：在编辑器中依次执行了操作 1、2、3、4，按 Ctrl+Z 时，应该依次撤销 4、3、2、1。
3. **括号匹配**：检查 `({[]})` 是否括号匹配，需要记录最近遇到的左括号。

这些场景的共性是：**最后进入的元素最先被处理**。这种"后进先出"（LIFO）的结构就是**栈**。

## 栈的定义

**栈**是只允许在一端进行插入和删除操作的线性表。允许操作的一端称为**栈顶**，另一端称为**栈底**。

```
        栈顶（Top）
           ↓
    ┌───┬───┬───┬───┬───┐
    │   │   │ C │ B │ A │    入栈顺序：A, B, C
    └───┴───┴───┴───┴───┘
              ↑
            栈底（Bottom）

出栈顺序：C, B, A（后进先出）
```

## 栈的 ADT

```text
ADT Stack {
    数据对象：D = {a_i | a_i ∈ ElemSet, i = 1, 2, ..., n, n ≥ 0}
    数据关系：R = {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n}
    
    基本操作：
        InitStack(&S)      // 初始化空栈
        DestroyStack(&S)   // 销毁栈
        StackEmpty(S)      // 判空
        StackLength(S)     // 求栈深
        GetTop(S, &e)      // 取栈顶元素（不出栈）
        Push(&S, e)        // 入栈
        Pop(&S, &e)        // 出栈
        ClearStack(&S)     // 清空栈
}
```

## 顺序栈的实现

用数组实现，栈顶指针 `top` 指向栈顶元素（或栈顶元素的下一个位置）。

```cpp
template <typename T>
class SeqStack {
private:
    T* data;
    int capacity;
    int top;    // top 指向栈顶元素的下一个位置（空栈时 top = 0）

public:
    SeqStack(int cap = 64) {
        data = new T[cap];
        capacity = cap;
        top = 0;
    }
    
    ~SeqStack() {
        delete[] data;
    }
    
    bool empty() const { return top == 0; }
    int size() const { return top; }
    
    bool push(const T& e) {
        if (top >= capacity) return false;  // 栈满
        data[top++] = e;
        return true;
    }
    
    bool pop(T& e) {
        if (empty()) return false;  // 栈空
        e = data[--top];
        return true;
    }
    
    bool getTop(T& e) const {
        if (empty()) return false;
        e = data[top - 1];
        return true;
    }
};
```

**时间复杂度**：所有操作都是 $O(1)$。

## 链栈的实现

用链表实现，只在链表头部进行插入和删除（头结点作为栈顶）。

```cpp
template <typename T>
class LinkedStack {
private:
    struct Node {
        T data;
        Node* next;
        Node(const T& val, Node* p = nullptr) : data(val), next(p) {}
    };
    Node* top;   // 栈顶指针
    int count;

public:
    LinkedStack() : top(nullptr), count(0) {}
    
    ~LinkedStack() {
        while (top) {
            Node* temp = top;
            top = top->next;
            delete temp;
        }
    }
    
    bool empty() const { return top == nullptr; }
    int size() const { return count; }
    
    void push(const T& e) {
        top = new Node(e, top);  // 新结点插入栈顶
        count++;
    }
    
    bool pop(T& e) {
        if (empty()) return false;
        Node* temp = top;
        e = temp->data;
        top = top->next;
        delete temp;
        count--;
        return true;
    }
    
    bool getTop(T& e) const {
        if (empty()) return false;
        e = top->data;
        return true;
    }
};
```

**时间复杂度**：所有操作都是 $O(1)$。链栈不存在栈满的问题（除非内存耗尽）。

## 共享栈（双栈）

两个栈共享一个数组空间，一个栈的栈底在数组头部，另一个栈的栈底在数组尾部，两个栈的栈顶向中间增长。

```
    栈 1                    栈 2
      ↓                      ↓
    ┌───┬───┬───┬───┬───┬───┬───┬───┐
    │ A │ B │   │   │   │   │ Y │ X │
    └───┴───┴───┴───┴───┴───┴───┴───┘
          ↑                 ↑
        top1              top2

栈 1 入栈：top1++
栈 2 入栈：top2--
栈满条件：top1 + 1 == top2
```

这样可以提高空间利用率，减少溢出风险。

## 栈的应用

### 1. 括号匹配

检查一个字符串中的括号是否配对。遇到左括号就入栈，遇到右括号就与栈顶左括号匹配。

```cpp
bool isMatch(const std::string& s) {
    LinkedStack<char> stack;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            char top;
            if (!stack.getTop(top)) return false;  // 栈空，右括号多余
            
            if ((c == ')' && top == '(') ||
                (c == ']' && top == '[') ||
                (c == '}' && top == '{')) {
                stack.pop(top);  // 匹配成功，出栈
            } else {
                return false;    // 括号类型不匹配
            }
        }
    }
    return stack.empty();  // 栈空则全部匹配
}
```

**核心思想**：最近遇到的左括号应该与最近的右括号匹配——这正是栈"后进先出"的特性。

### 2. 表达式求值

将中缀表达式（如 `3 + 5 * 2`）转换为后缀表达式（`3 5 2 * +`），然后用栈求值。

**后缀表达式（逆波兰式）求值**：

1. 从左到右扫描表达式
2. 遇到操作数，入栈
3. 遇到运算符，弹出两个操作数，运算后将结果入栈
4. 最后栈中只剩一个数，就是结果

```
后缀表达式：3 5 2 * +

步骤：
  1. 3 入栈        栈：[3]
  2. 5 入栈        栈：[3, 5]
  3. 2 入栈        栈：[3, 5, 2]
  4. *：弹出 2, 5   5*2=10  入栈    栈：[3, 10]
  5. +：弹出 10, 3  3+10=13 入栈    栈：[13]
  
结果：13
```

### 3. 递归与栈

程序在执行递归函数时，系统使用**调用栈**来保存每层递归的局部变量和返回地址。

```cpp
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

调用 `factorial(3)` 时的调用栈：

```
factorial(1) returns 1
factorial(2) returns 2 * 1 = 2
factorial(3) returns 3 * 2 = 6
```

每次递归调用都会在调用栈上新增一帧，保存参数 `n` 和返回地址。递归返回时，栈帧依次弹出。

> **尾递归优化**：如果递归调用是函数的最后一步操作，编译器可能将其优化为循环，避免栈溢出。但 C++ 标准不保证尾递归优化。

### 4. 进制转换

将十进制数 $N$ 转换为 $d$ 进制：

```cpp
void convert(int N, int d) {
    SeqStack<int> stack;
    while (N > 0) {
        stack.push(N % d);  // 余数入栈
        N /= d;
    }
    while (!stack.empty()) {
        int digit;
        stack.pop(digit);
        std::cout << digit;  // 倒序输出
    }
}
```

**原理**：最先得到的余数是最低位，最后得到的余数是最高位，需要用栈倒序输出。

## 小结

- 栈是一种**后进先出**（LIFO）的线性结构，只允许在栈顶进行插入和删除。
- 顺序栈和链栈的所有基本操作都是 $O(1)$。
- 栈的核心应用场景：需要"回溯"或"逆序处理"的问题（括号匹配、表达式求值、递归实现、进制转换）。
- 理解栈与递归的关系：递归的底层实现依赖于调用栈；任何递归算法都可以改写为使用显式栈的非递归版本。
