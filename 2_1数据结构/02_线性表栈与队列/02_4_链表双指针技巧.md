# 02_4 链表中的双指针

单链表只能沿 `next` 向前走。许多看似需要长度、前驱或额外存储的问题，都可以转化为“让两个指针保持某种距离关系”。关键不在于使用两个变量，而在于维护一个稳定的不变量。

## 固定间距：倒数第 k 个结点

令 `fast` 先走 `k` 步，再让 `slow` 与 `fast` 同速前进。循环中二者始终相距 `k` 条边；当 `fast` 到达空指针时，`slow` 正好位于倒数第 `k` 个结点。

```cpp
ListNode* kthFromEnd(ListNode* head, int k) {
    if (k <= 0) return nullptr;
    ListNode* fast = head;
    for (int i = 0; i < k; ++i) {
        if (fast == nullptr) return nullptr;
        fast = fast->next;
    }
    ListNode* slow = head;
    while (fast != nullptr) {
        fast = fast->next;
        slow = slow->next;
    }
    return slow;
}
```

一次遍历完成，时间为 $O(n)$，额外空间为 $O(1)$。`k<=0` 或 `k` 大于链表长度时返回空指针。

## 速度差：中间结点

`slow` 每轮走一步，`fast` 每轮走两步。当快指针到达末尾时，慢指针走过的距离约为一半。若长度为偶数，下面的写法返回两个中间结点中靠后的一个。

```cpp
ListNode* middle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

## 反转链表：改变边的方向

反转时必须先保存原来的后继，否则修改 `current->next` 后会失去未处理部分。

```cpp
ListNode* reverse(ListNode* head) {
    ListNode* previous = nullptr;
    ListNode* current = head;
    while (current != nullptr) {
        ListNode* following = current->next;
        current->next = previous;
        previous = current;
        current = following;
    }
    return previous;
}
```

循环不变量是：`previous` 指向已经反转好的前缀，`current` 指向尚未处理的后缀。每个结点只被处理一次，因此时间为 $O(n)$。

## 共享后缀：两条链表的交点

若两条无环单链表相交，从交点开始一定共享同一后缀。令指针 `a` 走完 A 后转到 B，`b` 走完 B 后转到 A；两者都走过 $|A|+|B|$ 步，因此会在交点相遇，或同时到达空指针。

```cpp
ListNode* intersection(ListNode* a, ListNode* b) {
    ListNode *p = a, *q = b;
    while (p != q) {
        p = (p == nullptr) ? b : p->next;
        q = (q == nullptr) ? a : q->next;
    }
    return p;
}
```

这里比较的是结点地址，不是数据值。

## 判环与环入口

快慢指针若在环中相遇，说明链表有环。设入口前长度为 $a$，相遇点距入口为 $b$，环长为 $c$。相遇时快指针比慢指针多走整数圈，可推出从头结点与从相遇点各出发一个慢指针，它们会在入口相遇。

```cpp
ListNode* cycleEntry(ListNode* head) {
    ListNode *slow = head, *fast = head;
    do {
        if (fast == nullptr || fast->next == nullptr) return nullptr;
        slow = slow->next;
        fast = fast->next->next;
    } while (slow != fast);

    slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
    return slow;
}
```

## 回文与重排

回文链表可以分三步完成：快慢指针找到后半段、原地反转后半段、从两端同步比较。链表重排 `L0→Ln→L1→Ln-1…` 也复用同一组合，只是在最后交替合并两个半链表。

这些算法共同展示了一个方法：先明确需要保持的相对位置，再选择“固定距离”“速度差”或“路径等长化”。
