# 02_1 线性表

## 从问题出发

假设你需要管理一个班级的学生名单，支持以下操作：

- 在名单末尾添加新学生
- 在某个学生前面插入一位转学生
- 某位学生退学，需要将其从名单中删除
- 查找某个学生是否在名单中
- 按顺序打印所有学生

这些操作的核心特征是：**数据元素之间是一对一的关系**。这种结构就是**线性表**。

## 线性表的定义

**线性表**是 $n$（$n \geq 0$）个数据元素的有限序列。线性表中的元素具有相同的特性（属于同一数据对象），元素之间的关系是线性的。

线性表的形式定义：

$$
L = (a_1, a_2, \cdots, a_n)
$$

其中 $a_1$ 是表头元素，$a_n$ 是表尾元素。对任意 $a_i$（$1 < i < n$），有且仅有一个直接前驱 $a_{i-1}$ 和一个直接后继 $a_{i+1}$。

## 线性表的 ADT

```text
ADT List {
    数据对象：D = {a_i | a_i ∈ ElemSet, i = 1, 2, ..., n, n ≥ 0}
    数据关系：R = {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n}
    
    基本操作：
        InitList(&L)           // 初始化
        DestroyList(&L)        // 销毁
        ClearList(&L)          // 清空
        ListEmpty(L)           // 判空
        ListLength(L)          // 求长度
        GetElem(L, i, &e)      // 取第 i 个元素
        LocateElem(L, e)       // 查找
        PriorElem(L, cur, &pre) // 前驱
        NextElem(L, cur, &next) // 后继
        ListInsert(&L, i, e)   // 插入
        ListDelete(&L, i, &e)  // 删除
        TraverseList(L)        // 遍历
}
```

## 顺序表

### 存储结构

用一段**地址连续**的存储单元依次存储线性表的数据元素。通常使用数组实现。

```cpp
template <typename T>
class SeqList {
private:
    T* data;        // 存储空间基址
    int capacity;   // 当前分配的容量
    int length;     // 当前长度

public:
    SeqList(int initCapacity = 16) {
        data = new T[initCapacity];
        capacity = initCapacity;
        length = 0;
    }
    
    ~SeqList() {
        delete[] data;
    }
    // ...
};
```

**地址计算**：假设每个元素占用 $C$ 个存储单元，第 $i$ 个元素的存储地址为：

$$
\text{LOC}(a_i) = \text{LOC}(a_1) + (i - 1) \times C
$$

这说明顺序表可以**随机存取**——通过下标直接计算地址，访问任意元素的时间都是 $O(1)$。

### 插入操作

在第 $i$ 个位置（$1 \leq i \leq length + 1$）插入元素 $e$：

1. 检查插入位置是否合法
2. 如果表满，扩容（通常扩大到原来的 2 倍）
3. 将第 $i$ 个位置及之后的所有元素后移一位
4. 在位置 $i$ 放入新元素
5. 表长加 1

```cpp
bool insert(int i, const T& e) {
    if (i < 1 || i > length + 1) return false;  // 位置非法
    
    if (length >= capacity) {
        // 扩容
        T* newData = new T[capacity * 2];
        for (int j = 0; j < length; j++) {
            newData[j] = data[j];
        }
        delete[] data;
        data = newData;
        capacity *= 2;
    }
    
    // 元素后移
    for (int j = length - 1; j >= i - 1; j--) {
        data[j + 1] = data[j];
    }
    
    data[i - 1] = e;
    length++;
    return true;
}
```

**移动次数分析**：

| 插入位置 | 移动次数 |
|---|---|
| 表尾（$i = length + 1$） | 0 |
| 表头（$i = 1$） | $n$ |
| 平均 | $\frac{n}{2}$ |

**时间复杂度：$O(n)$**（主要开销来自元素移动）

### 删除操作

删除第 $i$ 个位置的元素：

1. 检查删除位置是否合法
2. 保存被删除的元素（可选）
3. 将第 $i+1$ 个位置及之后的所有元素前移一位
4. 表长减 1

```cpp
bool remove(int i, T& e) {
    if (i < 1 || i > length) return false;  // 位置非法
    
    e = data[i - 1];
    
    // 元素前移
    for (int j = i; j < length; j++) {
        data[j - 1] = data[j];
    }
    
    length--;
    return true;
}
```

**移动次数分析**：

| 删除位置 | 移动次数 |
|---|---|
| 表尾（$i = length$） | 0 |
| 表头（$i = 1$） | $n - 1$ |
| 平均 | $\frac{n-1}{2}$ |

**时间复杂度：$O(n)$**

### 顺序表的优缺点

| 优点 | 缺点 |
|---|---|
| 随机存取，访问任意位置 $O(1)$ | 插入、删除需要移动大量元素 |
| 存储密度高（不需要额外空间存储关系） | 需要预先分配空间，可能造成浪费或溢出 |
| 实现简单，易于理解 | 扩容时需要复制全部元素 |

## 单链表

### 为什么需要链表

顺序表的插入和删除需要移动大量元素。如果我们能直接修改元素之间的"连接关系"，而不是物理移动数据，效率就会提高。

链表的核心思想：**用指针（引用）来表示元素之间的逻辑关系，不要求物理存储连续**。

### 结点结构

```cpp
template <typename T>
struct Node {
    T data;           // 数据域
    Node<T>* next;    // 指针域，指向下一个结点
    
    Node(const T& val, Node<T>* p = nullptr) : data(val), next(p) {}
};
```

每个结点包含两部分：
- **数据域**：存储数据元素本身
- **指针域**：存储后继结点的地址

### 链表的存储结构

```
逻辑顺序：A → B → C → D

物理存储（不连续）：
  [A | *]      [B | *]      [C | *]      [D | /]
  0x100  │      0x200       0x300        0x400
         └──────┘            └────────────┘
```

### 头结点的意义

通常会在链表第一个元素之前附加一个**头结点**（不存储实际数据）。

**引入头结点的好处**：
1. **统一操作**：插入和删除第一个元素的操作与其他位置相同，不需要额外判断
2. **空表处理**：空链表只有一个头结点，头指针永远不为空，简化边界情况处理

```
有头结点的链表：
  [head | *] → [A | *] → [B | *] → [C | /]

空链表：
  [head | /]
```

### 单链表的基本操作

```cpp
template <typename T>
class LinkedList {
private:
    Node<T>* head;   // 头结点
    int length;

public:
    LinkedList() {
        head = new Node<T>(T());  // 头结点，数据域无意义
        length = 0;
    }
    
    ~LinkedList() {
        Node<T>* p = head;
        while (p) {
            Node<T>* temp = p;
            p = p->next;
            delete temp;
        }
    }
    
    // 按位查找：返回第 i 个结点（包含头结点则 i 从 0 开始）
    Node<T>* get(int i) {
        if (i < 0 || i > length) return nullptr;
        Node<T>* p = head->next;
        int j = 1;
        while (p && j < i) {
            p = p->next;
            j++;
        }
        return p;
    }
    
    // 按值查找
    Node<T>* locate(const T& e) {
        Node<T>* p = head->next;
        while (p && p->data != e) {
            p = p->next;
        }
        return p;  // 找不到返回 nullptr
    }
    
    // 插入：在第 i 个位置插入元素 e
    bool insert(int i, const T& e) {
        if (i < 1 || i > length + 1) return false;
        
        Node<T>* p = head;
        int j = 0;
        while (p && j < i - 1) {  // 找到第 i-1 个结点
            p = p->next;
            j++;
        }
        
        if (!p) return false;
        
        Node<T>* newNode = new Node<T>(e);
        newNode->next = p->next;
        p->next = newNode;
        length++;
        return true;
    }
    
    // 删除：删除第 i 个元素
    bool remove(int i, T& e) {
        if (i < 1 || i > length) return false;
        
        Node<T>* p = head;
        int j = 0;
        while (p && j < i - 1) {  // 找到第 i-1 个结点
            p = p->next;
            j++;
        }
        
        if (!(p->next)) return false;
        
        Node<T>* q = p->next;     // q 指向要删除的结点
        e = q->data;
        p->next = q->next;        // 绕过 q
        delete q;
        length--;
        return true;
    }
};
```

### 链表插入和删除的核心思想

**插入**：关键在于找到**插入位置的前一个结点**，然后修改两个指针。

```
插入前：... → [p] → [r] → ...

步骤 1：newNode->next = p->next    // newNode 指向 r
步骤 2：p->next = newNode          // p 指向 newNode

结果：... → [p] → [newNode] → [r] → ...
```

> 注意：两个赋值语句的顺序不能颠倒！如果先执行 `p->next = newNode`，就会丢失 `r` 的地址。

**删除**：关键在于找到**要删除结点的前一个结点**，然后绕过要删除的结点。

```
删除前：... → [p] → [q] → [r] → ...

步骤：p->next = q->next   // p 直接指向 r
      delete q            // 释放 q 的内存

结果：... → [p] → [r] → ...
```

### 时间复杂度分析

| 操作 | 顺序表 | 单链表 |
|---|---|---|
| 按位访问 | $O(1)$ | $O(n)$ |
| 按值查找 | $O(n)$ | $O(n)$ |
| 插入 | $O(n)$（移动元素） | $O(n)$（查找位置） + $O(1)$（修改指针） |
| 删除 | $O(n)$（移动元素） | $O(n)$（查找位置） + $O(1)$（修改指针） |

> 链表的插入和删除一旦找到位置，修改指针的操作是 $O(1)$。但如果需要按位置查找，查找本身就需要 $O(n)$。

## 双向链表

单链表的每个结点只存储了后继的地址，找前驱需要从头遍历。双向链表在每个结点中同时存储**前驱**和**后继**指针。

```cpp
template <typename T>
struct DNode {
    T data;
    DNode<T>* prev;
    DNode<T>* next;
    
    DNode(const T& val) : data(val), prev(nullptr), next(nullptr) {}
};
```

```
[head] ←→ [A] ←→ [B] ←→ [C] ←→ [tail]
```

**双向链表的优点**：
- 可以双向遍历
- 插入和删除时不需要找前驱（已知当前结点即可）

**双向链表的缺点**：
- 每个结点多一个指针域，空间开销增加
- 指针操作更复杂，容易出错

## 循环链表

循环链表将最后一个结点的 next 指针指向头结点（或第一个结点），形成一个环。

```
单循环链表：
  [head] → [A] → [B] → [C] ─┐
   ↑─────────────────────────┘
```

**循环链表的优点**：
- 从任意结点出发都可以遍历整个链表
- 适合需要周期性访问的场景

## 顺序表与链表的比较

| 比较维度 | 顺序表 | 链表 |
|---|---|---|
| 存取方式 | 随机存取 $O(1)$ | 顺序存取 $O(n)$ |
| 插入删除 | 需要移动元素 $O(n)$ | 只需修改指针 $O(1)$（找到位置后） |
| 空间利用 | 预分配，可能浪费或溢出 | 动态分配，按需使用 |
| 存储密度 | 高（只存数据） | 低（额外存储指针） |
| 适用场景 | 查询频繁、很少增删 | 频繁增删、长度变化大 |

## 静态链表

用数组来模拟链表，数组的每个元素包含数据域和"游标"（下一个元素在数组中的下标）。

```cpp
struct SNode {
    int data;
    int next;  // 游标，-1 表示结束
};

SNode space[MAX_SIZE];  // 静态链表空间
```

静态链表在没有指针类型的语言（如早期 BASIC、FORTRAN）中使用，现代 C++ 中很少使用。

## 小结

- 线性表是最基本的线性结构，元素之间是一对一的关系。
- **顺序表**用连续的存储空间实现，支持随机存取，但插入删除效率低。
- **链表**用指针连接不连续的结点，插入删除效率高，但只能顺序存取。
- 链表操作的核心是**指针的修改**——插入和删除都只需要修改少量指针，不需要移动数据。
- 选择哪种存储结构取决于具体操作的需求：查询多用顺序表，增删多用链表。
