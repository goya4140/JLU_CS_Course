# 05_3 拓扑排序与关键路径

当任务之间存在先后依赖时，可用有向图表示：顶点是任务，边 `u→v` 表示 `u` 必须先于 `v`。只有有向无环图（DAG）才存在满足全部依赖的线性次序。

## Kahn 拓扑排序

维护每个顶点的入度，并把所有入度为 0 的顶点放入队列。反复取出一个顶点，输出它，删除其出边并减少后继入度；新出现的零入度顶点入队。

```text
enqueue all vertices with indegree 0
while queue not empty:
    u = dequeue
    output u
    for each edge u -> v:
        indegree[v]--
        if indegree[v] == 0: enqueue v
```

若最终输出数小于顶点数，剩余部分存在有向环。邻接表实现的时间为 $O(|V|+|E|)$。

拓扑序通常不唯一；队列中同时存在多个零入度顶点时，选择不同顶点会得到不同但都合法的序列。

## AOE 网与关键路径

若边表示活动、权值表示持续时间，顶点表示事件，便得到活动在边上的网络。完成整个工程的最短时间由最长路径决定，因为并行分支必须等最慢分支完成。

按拓扑序计算事件最早发生时间：

$$ve[v]=\max_{u\to v}(ve[u]+w(u,v)).$$

再按逆拓扑序计算事件最迟发生时间。对活动 `u→v`，其最早开始时间是 `ve[u]`，最迟开始时间由 `vl[v]-w(u,v)` 给出。两者相等的活动没有可延迟余量，构成关键路径。

关键路径可能不止一条。缩短一条关键路径上的某个活动，也未必缩短整体工期，因为另一条同长度路径可能仍决定完成时间。

拓扑排序提供了处理 DAG 动态关系的顺序；关键路径是在这个顺序上进行的最长路径动态计算。
