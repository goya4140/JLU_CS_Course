# 05_5 最小生成树

给定连通无向带权图，生成树包含全部 $n$ 个顶点和恰好 $n-1$ 条边。边权之和最小的生成树称为最小生成树（MST），常用于以最低总成本连接网络。

## 切分性质

把顶点分为两个非空集合便形成一个切分。跨越某个切分的最轻边一定可以属于某棵最小生成树。这一性质支撑了 Prim 和 Kruskal 的贪心选择。

## Prim 算法

从任意顶点开始维护已连接顶点集合。每次选择一条连接集合内外的最轻边，把新顶点加入。最小堆实现配合邻接表时，时间约为 $O(|E|\log |V|)$。

Prim 的状态围绕“顶点到当前树的最小连接代价”组织，适合从一个连通块向外生长。

## Kruskal 算法

将所有边按权值递增处理。若一条边的两个端点位于不同连通分量，就选取它并合并分量；否则跳过，以免形成环。

并查集维护连通分量，提供近似常数时间的 `find` 与 `unite`。主要开销来自排序，因此时间为 $O(|E|\log |E|)$。

```text
sort edges by weight
for edge (u,v) in order:
    if find(u) != find(v):
        choose edge
        unite(u,v)
```

## 与最短路径的区别

最小生成树最小化整棵树的边权总和，不保证任意两点在树上的路径最短。最短路径算法优化的是指定点对或指定源点的路径。两者目标不同，即使输入图相同，结果也通常不同。

若图不连通，同样的过程会得到最小生成森林。边权相等时 MST 可能不唯一，但所有 MST 的总权值相同。
