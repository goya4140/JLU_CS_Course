# 05_2 图的遍历

## 图的遍历问题

给定一个图 $G = (V, E)$ 和其中一个顶点 $v$，**图的遍历**是指从 $v$ 出发，访问图中所有可达的顶点，且每个顶点只访问一次。

图的遍历是图算法的基础，许多图问题（连通性、最短路径、拓扑排序）都建立在遍历之上。

## 深度优先搜索（DFS）

### 基本思想

**DFS** 类似于树的**前序遍历**：

1. 访问起始顶点 $v$，标记为已访问
2. 从 $v$ 的邻接点中，选择一个**未访问**的顶点 $w$，递归对 $w$ 进行 DFS
3. 如果 $v$ 的所有邻接点都已访问，回溯到上一层

### 算法过程示例

```
图：
    0 —— 1
    |    |
    2 —— 3

从 0 开始 DFS：
  访问 0
    邻接点有 1, 2。选 1。
    访问 1
      邻接点有 0, 3。0 已访问，选 3。
      访问 3
        邻接点有 1, 2。1 已访问，选 2。
        访问 2
          邻接点有 0, 3。都已访问，回溯。
        回溯到 3，所有邻接点已访问，回溯。
      回溯到 1，所有邻接点已访问，回溯。
    回溯到 0，所有邻接点已访问，结束。

遍历序列：0 → 1 → 3 → 2
```

### 代码实现

```cpp
class Graph {
    // 邻接表表示的图
    std::vector<std::vector<int>> adj;  // adj[v] 是 v 的所有邻接点
    int n;

public:
    Graph(int vertices) : n(vertices) {
        adj.resize(n);
    }
    
    void addEdge(int u, int v) {
        adj[u].push_back(v);
        adj[v].push_back(u);  // 无向图
    }
    
    // DFS 递归实现
    void DFS(int start) {
        std::vector<bool> visited(n, false);
        dfsHelper(start, visited);
        std::cout << std::endl;
    }
    
    void dfsHelper(int v, std::vector<bool>& visited) {
        visited[v] = true;
        std::cout << v << " ";
        
        for (int w : adj[v]) {
            if (!visited[w]) {
                dfsHelper(w, visited);
            }
        }
    }
    
    // DFS 非递归实现（使用栈）
    void DFSIterative(int start) {
        std::vector<bool> visited(n, false);
        std::stack<int> s;
        s.push(start);
        
        while (!s.empty()) {
            int v = s.top(); s.pop();
            
            if (!visited[v]) {
                visited[v] = true;
                std::cout << v << " ";
                
                // 将所有未访问的邻接点入栈
                for (int i = adj[v].size() - 1; i >= 0; i--) {
                    int w = adj[v][i];
                    if (!visited[w]) {
                        s.push(w);
                    }
                }
            }
        }
        std::cout << std::endl;
    }
};
```

### DFS 的时间复杂度

- **邻接矩阵**：$O(n^2)$（需要扫描整行来找邻接点）
- **邻接表**：$O(n + e)$（每个顶点和边都只被访问一次）

## 广度优先搜索（BFS）

### 基本思想

**BFS** 类似于树的**层次遍历**：

1. 访问起始顶点 $v$，标记为已访问，入队
2. 当队列非空时，队头顶点 $u$ 出队
3. 访问 $u$ 的所有**未访问**邻接点，标记并入队
4. 重复步骤 2-3

### 算法过程示例

```
图：
    0 —— 1
    | ＼ |
    2 —— 3

从 0 开始 BFS：
  队列：[0]
  出队 0，访问。邻接点 1, 2, 3 入队。
  队列：[1, 2, 3]
  出队 1，访问。邻接点 0, 3 都已访问。
  队列：[2, 3]
  出队 2，访问。邻接点 0, 3 都已访问。
  队列：[3]
  出队 3，访问。邻接点 0, 1, 2 都已访问。
  队列：[]

遍历序列：0 → 1 → 2 → 3
```

### 代码实现

```cpp
void BFS(int start) {
    std::vector<bool> visited(n, false);
    std::queue<int> q;
    
    visited[start] = true;
    q.push(start);
    
    while (!q.empty()) {
        int v = q.front(); q.pop();
        std::cout << v << " ";
        
        for (int w : adj[v]) {
            if (!visited[w]) {
                visited[w] = true;
                q.push(w);
            }
        }
    }
    std::cout << std::endl;
}
```

### BFS 的时间复杂度

- **邻接矩阵**：$O(n^2)$
- **邻接表**：$O(n + e)$

## DFS 与 BFS 的比较

| 特性 | DFS | BFS |
|---|---|---|
| 数据结构 | 栈（递归/显式） | 队列 |
| 访问顺序 | 先深入到底，再回溯 | 一层一层扩展 |
| 路径特性 | 找到的路径可能不是最短的 | 第一次找到的路径就是最短路径（无权图） |
| 适用场景 | 连通性、拓扑排序、全排列 | 最短路径、层次遍历、最小步数 |
| 空间复杂度 | $O(h)$（$h$ 为递归深度） | $O(w)$（$w$ 为最大宽度） |

## DFS 与 BFS 的应用

### 1. 判断图的连通性

```cpp
bool isConnected() {
    std::vector<bool> visited(n, false);
    dfsHelper(0, visited);
    
    for (bool v : visited) {
        if (!v) return false;  // 有顶点未被访问
    }
    return true;
}
```

### 2. 求连通分量

```cpp
int countComponents() {
    std::vector<bool> visited(n, false);
    int count = 0;
    
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            count++;
            dfsHelper(i, visited);  // 访问整个连通分量
        }
    }
    return count;
}
```

### 3. 判断图中是否有环

无向图：DFS 中如果遇到已访问且不是父结点的邻接点，说明有环。

```cpp
bool hasCycleUndirected(int v, int parent, std::vector<bool>& visited) {
    visited[v] = true;
    for (int w : adj[v]) {
        if (!visited[w]) {
            if (hasCycleUndirected(w, v, visited)) return true;
        } else if (w != parent) {
            return true;  // 遇到已访问的非父结点，有环
        }
    }
    return false;
}
```

有向图：DFS 中如果遇到当前递归栈中的结点，说明有环。

```cpp
bool hasCycleDirected(int v, std::vector<bool>& visited, 
                       std::vector<bool>& recStack) {
    visited[v] = true;
    recStack[v] = true;
    
    for (int w : adj[v]) {
        if (!visited[w]) {
            if (hasCycleDirected(w, visited, recStack)) return true;
        } else if (recStack[w]) {
            return true;  // w 在当前递归路径上，有环
        }
    }
    
    recStack[v] = false;  // 回溯时从递归栈中移除
    return false;
}
```

### 4. 无权图的最短路径（BFS）

BFS 天然适合求无权图中两点之间的最短路径，因为 BFS 是按层扩展的，第一次到达目标时经过的边数最少。

```cpp
std::vector<int> shortestPath(int start, int end) {
    std::vector<bool> visited(n, false);
    std::vector<int> parent(n, -1);  // 记录每个结点的父结点
    std::queue<int> q;
    
    visited[start] = true;
    q.push(start);
    
    while (!q.empty()) {
        int v = q.front(); q.pop();
        if (v == end) break;
        
        for (int w : adj[v]) {
            if (!visited[w]) {
                visited[w] = true;
                parent[w] = v;
                q.push(w);
            }
        }
    }
    
    // 回溯构造路径
    std::vector<int> path;
    if (!visited[end]) return path;  // 不可达
    
    for (int v = end; v != -1; v = parent[v]) {
        path.push_back(v);
    }
    std::reverse(path.begin(), path.end());
    return path;
}
```

## 小结

- **DFS**：用栈（递归/显式）实现，"一条路走到黑"，适合探索、回溯类问题。
- **BFS**：用队列实现，"层层扩展"，适合最短路径、最小步数问题。
- 两种遍历在邻接表实现下都是 $O(n + e)$。
- 掌握遍历是理解所有图算法的基础。
