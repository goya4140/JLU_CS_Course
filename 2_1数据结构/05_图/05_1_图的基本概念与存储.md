# 05_1 图的概念与存储

图用顶点表示对象、用边表示对象间的关系，记为 $G=(V,E)$。树强调层次，图则允许任意连接、回路和多条可选路径。

## 基本概念

无向边没有方向，记作 $(u,v)$；有向边从起点指向终点，记作 $\langle u,v\rangle$。顶点的度是与它关联的边数；有向图还区分入度和出度。边可带权，用来表示距离、费用或容量。

顶点序列若相邻项间都有边便构成路径；首尾相同的非空路径形成回路。任意两点间存在路径称为连通；有向图中任意两点互相可达称为强连通。

## 邻接矩阵

用 $n\times n$ 数组记录边：无权图中 `matrix[u][v]` 表示边是否存在，带权图中保存权值并用特殊值表示无边。

- 空间始终为 $O(n^2)$。
- 判断一条边是否存在为 $O(1)$。
- 枚举一个顶点的邻居为 $O(n)$。

它适合稠密图或频繁查询任意两点连接关系的场景。无向图矩阵关于主对角线对称。

## 邻接表

每个顶点保存由它出发的边列表。

```cpp
struct Edge { int to; int weight; };
std::vector<std::vector<Edge>> graph(vertexCount);
```

空间为 $O(|V|+|E|)$，枚举顶点 `u` 的邻居只需 $O(\deg(u))$。无向边通常以两个方向各存一次；有向边只存实际方向。

## 表示与算法的契合

遍历和多数稀疏图算法需要反复枚举邻边，邻接表通常更自然。需要快速更新边、保留边对象身份时，还可使用十字链表或邻接多重表。

图的顶点常以整数下标表示。若输入是字符串名称，可先建立名称到编号的映射，让核心算法保持紧凑。无论使用哪种表示，都要明确：是否有向、是否允许重边和自环、无边与零权边如何区分。
