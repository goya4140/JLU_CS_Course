# 05 图

## 本章内容概述

图是表示**多对多**关系的最通用数据结构，广泛应用于网络路由、社交网络分析、依赖关系管理等场景。图的算法是数据结构课程中最具挑战性也最有价值的部分之一。

## 学习建议

- **重点理解**：图的存储方式决定了遍历和算法的实现方式。邻接矩阵适合稠密图，邻接表适合稀疏图。
- **必须掌握**：DFS 和 BFS 的完整执行过程（能手动模拟）、Dijkstra 的贪心策略、Prim 和 Kruskal 的设计思想。
- **手动模拟**：图算法的代码通常较短但逻辑密集，强烈建议用具体图例手动模拟每一步的执行过程。
