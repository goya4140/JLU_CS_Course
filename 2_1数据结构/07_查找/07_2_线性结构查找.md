# 07_2 线性结构上的查找

## 顺序查找

从一端逐个比较，发现相等元素即返回。它不要求有序，也适用于链表，最坏时间为 $O(n)$。在数组末端设置哨兵可把每轮的边界判断合并到关键词比较中，但不会改变渐近复杂度。

## 二分查找

有序数组支持通过中点比较每次排除一半范围。推荐使用半开区间 `[low, high)`：

```cpp
int lowerBound(const std::vector<int>& a, int key) {
    int low = 0, high = static_cast<int>(a.size());
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (a[mid] < key) low = mid + 1;
        else high = mid;
    }
    return low; // 第一个不小于 key 的位置
}
```

循环不变量是答案始终位于 `[low, high]` 的边界意义中；循环结束时二者相等。写成“下界”比只返回是否命中更通用，也能清楚处理重复元素和插入位置。

二分查找需要随机访问，因此不适合普通链表。它的查询时间为 $O(\log n)$，但维持数组有序的插入删除仍为 $O(n)$。

## 插值与斐波那契查找

插值查找根据关键词在值域中的比例估计位置，数据近似均匀时可能减少比较；分布偏斜时会退化。斐波那契查找用黄金分割附近的位置划分区间，历史上可减少某些访问代价，但现代通用实现通常优先使用简单可靠的二分查找。

## 分块查找

把数据划分为若干块，建立块级索引；先定位可能的块，再在块内顺序查找。它位于纯顺序表与完整有序表之间：块间有序，块内可以无序，适合分层存储和批量更新。
