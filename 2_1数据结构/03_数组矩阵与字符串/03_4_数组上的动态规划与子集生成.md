# 03_4 数组上的状态计算与子集生成

数组不仅保存原始数据，也常保存“已经计算出的子问题结果”。动态规划把重复出现的子问题结果记录下来，让后续状态直接复用。

## 状态、转移与初值

使用动态规划时，需要明确三件事：状态代表什么、较大状态如何由较小状态得到、最小状态的答案是什么。以网格中从左上角到 `(i,j)` 的路径数为例，若只能向右或向下移动：

$$dp[i][j]=dp[i-1][j]+dp[i][j-1].$$

第一行和第一列都只有一种到达方式，构成初值。按行或按列填表时，右侧状态依赖的上方、左方状态已经计算完成。

二维数组可压缩为一维：更新 `dp[j] += dp[j-1]` 时，旧 `dp[j]` 仍代表上方状态，新 `dp[j-1]` 已代表左方状态。空间由 $O(mn)$ 降为 $O(n)$。

## 网格路径中的障碍

若某位置不可通过，把它的路径数设为 0；其余位置仍由可达前驱累加。数组索引天然对应网格位置，这正是数据表示与状态定义吻合的例子。

动态规划有效的条件是子问题重复且较大问题的最优结果可由较小问题结果组合。若状态依赖成环或缺少明确次序，就需要重新设计状态或使用图算法。

## 子集的二进制表示

含 `n` 个元素的集合共有 $2^n$ 个子集。用 `n` 位二进制数表示选择状态：第 `i` 位为 1 表示选择第 `i` 个元素。

```cpp
for (unsigned mask = 0; mask < (1u << n); ++mask) {
    for (unsigned i = 0; i < n; ++i) {
        if (mask & (1u << i)) use(elements[i]);
    }
}
```

该方法按掩码生成全部子集，时间为 $O(n2^n)$。它没有减少输出规模，因为仅输出所有子集本身就需要指数级信息量。

也可递归处理每个元素“选或不选”两条分支。二进制枚举强调状态编码，递归强调决策树；二者描述的是同一个组合空间。
