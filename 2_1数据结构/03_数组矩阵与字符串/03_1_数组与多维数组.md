# 03_1 数组与多维数组

数组把相同类型的元素放在连续存储空间中。连续性带来两个重要结果：给定下标可以直接计算地址，遍历时也能良好利用缓存。

## 一维数组的地址

若首元素地址为 $B$，每个元素占 $C$ 字节，下标从 0 开始，则

$$\operatorname{LOC}(A[i])=B+iC$$

因此按下标访问的时间为 $O(1)$。这个结论依赖元素等长且连续存放。

## 多维数组的线性化

内存仍是一维的，多维下标必须映射为一个偏移。对大小为 $m_1\times m_2\times\cdots\times m_d$ 的数组，行优先存储下

$$
\operatorname{offset}(i_1,\ldots,i_d)=
\sum_{k=1}^{d} i_k\prod_{j=k+1}^{d}m_j
$$

最右一维变化最快。以 `A[3][5][11][3]` 为例，`A[i][j][k][l]` 的元素偏移为

$$i(5\cdot11\cdot3)+j(11\cdot3)+k\cdot3+l.$$

列优先存储则让最左一维变化最快。理解“哪一维连续”比背公式更重要：从最内层循环连续访问的维度开始累积跨度即可。

## 遍历顺序与局部性

C++ 的原生多维数组采用行优先布局。下面两段循环完成相同工作，但第一段按连续地址前进，通常具有更好的缓存局部性。

```cpp
for (int row = 0; row < rows; ++row)
    for (int col = 0; col < cols; ++col)
        consume(matrix[row][col]);
```

当数组很大时，逻辑复杂度相同并不意味着实际耗时相同；存储布局会影响缓存未命中次数。

## 动态二维数组

用一维 `std::vector<T>` 保存矩阵，可以同时得到连续存储和动态尺寸：

```cpp
template<class T>
class Matrix {
    std::size_t rows_, cols_;
    std::vector<T> data_;
public:
    Matrix(std::size_t r, std::size_t c, const T& value = T{})
        : rows_(r), cols_(c), data_(r * c, value) {}

    T& at(std::size_t r, std::size_t c) {
        if (r >= rows_ || c >= cols_) throw std::out_of_range("matrix index");
        return data_[r * cols_ + c];
    }
};
```

这里的核心不变量是 `data_.size() == rows_ * cols_`，元素 `(r,c)` 的偏移始终为 `r * cols_ + c`。

## 与后续内容的联系

矩阵压缩存储是在“下标到偏移”的映射上继续做文章；动态规划常用数组保存子问题状态；字符串本质上也是字符的连续序列，因此同样受益于随机访问和缓存局部性。
